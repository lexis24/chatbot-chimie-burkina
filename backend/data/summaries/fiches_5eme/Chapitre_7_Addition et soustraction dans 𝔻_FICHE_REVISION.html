Addition et soustraction dans 𝔻

Leçon 1 : les ensembles ℕ, ℤ, 𝔻 et la commutativité · Leçon 2 : associativité et simplification d'écritures · Leçon 3 : opposé et soustraction · Leçon 4 : somme algébrique et suppression des parenthèses
L'ESSENTIEL

Leçon 1 : Les ensembles ℕ, ℤ, 𝔻 ; commutativité

  • ℕ : les entiers naturels (0, 1, 2, 3, …), ceux qui servent à compter ;
  • ℤ : les entiers relatifs (…, −2, −1, 0, +1, +2, …), les entiers naturels et leurs opposés ;
  • 𝔻 : les décimaux relatifs (−3,5 ; +0,75 ; −12), tous les nombres à virgule, positifs ou négatifs.

Chaque ensemble contient le précédent : ℕ ⊂ ℤ ⊂ 𝔻.

ADDITION DE DEUX RELATIFS : LE SIGNE D'ABORD
Mêmes signes : on additionne les distances à zéro, on garde le signe
Signes contraires : on retranche la petite de la grande, on prend le signe du plus éloigné de zéro
(−5) + (−3) = −8     (−5) + (+3) = −2
COMMUTATIVITE (CHANGER L'ORDRE) ET ROLE DE ZERO
a + b = b + a     a + 0 = a     a + (−a) = 0
Sur la droite graduée. Ajouter un positif, c'est aller vers la droite ; un négatif, vers la gauche.

Leçon 2 : Associativité ; simplification d'écritures

ASSOCIATIVITE (CHANGER LES REGROUPEMENTS)
(a + b) + c = a + (b + c)
  • Longue somme : on regroupe les positifs ensemble et les négatifs ensemble, puis on combine les deux totaux.
  • Deux termes opposés s'annulent : dans (−84,5) + (+13,7) + (+84,5), il ne reste que +13,7. Premier réflexe : chercher ces paires avant de trier.
Attention. Ces propriétés valent pour l'addition, pas pour la soustraction : 5 − 3 ne vaut pas 3 − 5.

Leçon 3 : Opposé d'un nombre relatif ; soustraction

L'opposé d'un relatif a est le nombre noté −a tel que a + (−a) = 0 : on change le signe. Opposé de +5 : −5 ; de −3,2 : +3,2 ; de 0 : 0. Changer deux fois le signe ramène au nombre de départ.

SOUSTRAIRE, C'EST AJOUTER L'OPPOSE
a − b = a + (opposé de b)
(−7) − (+8) = (−7) + (−8) = −15

Seul le second nombre est retourné : il ne reste alors que des additions, et la leçon 2 redevient utilisable.

VARIATION ET DISTANCE
variation = valeur d'arrivée − valeur de départ
distance = plus grande abscisse − plus petite abscisse

La variation est positive si la grandeur a augmenté, négative si elle a diminué ; la distance est toujours positive : entre les abscisses −4 et +3, elle vaut (+3) − (−4) = 7 unités.

Leçon 4 : Somme algébrique ; suppression des parenthèses

Une somme algébrique est une suite d'additions et de soustractions de relatifs ; on peut toujours l'écrire sans parenthèses, chaque terme précédé de son signe.

SUPPRESSION DES PARENTHESES
un + devant : on ne change rien   a + (b − c) = a + b − c
un − devant : on change tous les signes   a − (b − c) = a − b + c
  • Crochets emboîtés : on supprime la parenthèse la plus intérieure, puis on remonte vers l'extérieur un niveau à la fois.
  • Toutes les parenthèses supprimées, on calcule en regroupant positifs et négatifs (leçon 2).
PIEGES ET ERREURS FREQUENTES
✗ (−5) + (−3) = −2  ·  (−5) + (+3) = +8
✓ Mêmes signes : on additionne les distances à zéro, donc −8. Signes contraires : on retranche, 5 − 3 = 2, et on garde le signe du plus éloigné de zéro, celui de −5, donc −2. Ne confonds pas le signe d'un nombre et celui de l'opération : dans (−5) + (−3), le + est l'opération, les deux − appartiennent aux nombres.
✗ (−7) − (−4) = −11  ·  « une soustraction rend toujours plus petit »
✓ Soustraire −4, c'est ajouter +4 : (−7) + (+4) = −3, qui est plus grand que −7. Retrancher un nombre négatif fait augmenter.
✗ « L'opposé de −40 est −40 »  ·  dans une soustraction, on retourne les deux nombres
✓ « Opposé » ne veut pas dire « négatif » : l'opposé de −40 est +40. Et dans a − b, seul b change de signe ; a est le point de départ, il ne bouge pas.
✗ 8 − (3 − 5) = 8 − 3 − 5 = 0
✓ La parenthèse est précédée d'un − : tous ses signes changent, pas seulement le premier. 8 − 3 + 5 = 10.
✗ On réorganise (−3) − (+8) en (+8) − (−3)  ·  on commence par le crochet extérieur
✓ La soustraction n'est ni commutative ni associative : le premier vaut −11, le second +11. On transforme d'abord les soustractions en additions ; dans des parenthèses emboîtées, on part de la plus intérieure.
✗ « 4 − 9 est impossible »  ·  un terme oublié pendant le tri
✓ Dans ℤ la soustraction est toujours possible : 4 − 9 = 4 + (−9) = −5. Et compte tes termes avant et après le tri : leur nombre doit être le même.
A SAVOIR PAR COEUR AVANT LE DEVOIR
  1. ℕ ⊂ ℤ ⊂ 𝔻 : entiers naturels, entiers relatifs, décimaux relatifs.
  2. Addition : mêmes signes, on additionne les distances à zéro et on garde le signe ; signes contraires, on retranche la petite de la grande et on prend le signe du plus éloigné de zéro.
  3. Opposé de a : le nombre −a tel que a + (−a) = 0 ; l'opposé d'un négatif est positif.
  4. Soustraire, c'est ajouter l'opposé : a − b = a + (−b). Seul le second nombre change de signe.
  5. Commutativité et associativité : pour l'addition seulement. On supprime les paires d'opposés, puis on regroupe positifs et négatifs.
  6. Parenthèse précédée de + : rien ne change. Précédée de − : tous les signes changent. Crochets : de l'intérieur vers l'extérieur.
  7. Variation = arrivée − départ, avec son signe. Distance = plus grande abscisse − plus petite, toujours positive.
