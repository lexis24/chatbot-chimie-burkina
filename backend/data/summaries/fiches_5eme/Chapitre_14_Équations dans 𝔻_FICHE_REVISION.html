Equations dans 𝔻

Leçon 1 : équation, membres, solution · Leçon 2 : résoudre x + a = b et a − x = b · Leçon 3 : résoudre a × x = b et x ÷ a = b · Leçon 4 : mise en équation
L'ESSENTIEL

Leçon 1 : Qu'est-ce qu'une équation ?

Une équation est une égalité dans laquelle figure un nombre inconnu, représenté par une lettre, le plus souvent x. A gauche du signe = : le premier membre ; à droite : le second membre.

Une solution est une valeur de l'inconnue qui rend l'égalité vraie. Résoudre une équation, c'est trouver toutes ses solutions. La lettre est libre (p pour un prix, d pour une distance), mais on dit avant tout calcul ce qu'elle représente.

TESTER UNE VALEUR : DEUX CALCULS, PUIS UNE COMPARAISON
3x + 4 = 19  avec  x = 5
1er membre : 3 × 5 + 4 = 19  ·  2e membre : 19
19 = 19 : 5 est solution
Une équation n'est ni vraie ni fausse : c'est une question. On dit qu'un nombre est solution, ou ne l'est pas. Vérifier : calculer chaque membre séparément, puis comparer.

Leçon 2 : Résoudre x + a = b et a − x = b

On applique aux deux membres l'opération inverse de celle qui accompagne l'inconnue (Chapitre 13).

LES TROIS CAS ADDITIFS
x + a = b → x = b − a  (on retranche a)
x − a = b → x = b + a  (on ajoute a)
a − x = b → x = a − b  (on ajoute x, puis on retranche b)
  • Une égalité se lit dans les deux sens : 47 = x + 11 se traite comme x + 11 = 47.
  • La solution peut être négative, ce qui est légitime dans 𝔻 : x + 15 = 4 donne x = −11.
Equations équivalentes. Ces transformations ne changent pas les solutions. On peut donc écrire les équations les unes sous les autres, jusqu'à la plus simple de toutes : x = … La vérification dans l'équation de départ repère les erreurs de calcul.

Leçon 3 : Résoudre a × x = b et x ÷ a = b

LES DEUX CAS MULTIPLICATIFS
a × x = b → x = b ÷ a  (a ≠ 0 ; on divise par a)
x ÷ a = b → x = b × a  (on multiplie par a)

Le coefficient (nombre placé devant l'inconnue) s'enlève par une division, jamais par une soustraction. Signes : −3x = 12 donne x = 12 ÷ (−3) = −4. Dans 𝔻, la solution est un décimal relatif : 4x = 22 donne x = 5,5.

DEUX OPERATIONS : D'ABORD LE TERME, ENSUITE LE COEFFICIENT
3x + 4 = 19  →  3x = 15  →  x = 5
ax + b = c → x = (c − b) ÷ a
Aucune solution. 0 × x = b, avec b ≠ 0, n'a aucune solution : 0 × x vaut 0 quelle que soit la valeur de x.

Leçon 4 : Résoudre un problème par une équation

Démarche en cinq temps : 1. choisir l'inconnue, en disant ce qu'elle représente et avec quelle unité ; 2. écrire l'équation qui traduit l'énoncé ; 3. résoudre (leçons 2 et 3) ; 4. vérifier dans l'énoncé, et pas seulement dans l'équation ; 5. interpréter : répondre par une phrase, avec l'unité.

LES MOTS QUI SE TRADUISENT
« augmenté de » → +   « diminué de » → −   « en tout » → le total
« le double » → 2x   « le triple » → 3x   « la moitié » → x ÷ 2   « le tiers » → x ÷ 3

Où porte l'opération ? « Le triple d'un nombre, augmenté de 5 » : 3x + 5 ; « le triple de la somme d'un nombre et de 5 » : 3 × (x + 5). Pour x = 2, la première écriture vaut 11 et la seconde 21. En cas de doute, on essaie une valeur simple.

Cette année, l'inconnue figure dans un seul membre : une équation comme 2x + 5 = x + 8 s'étudie en classe de 4ème.
PIEGES ET ERREURS FREQUENTES
✗ « L'équation x + 5 = 12 est fausse. »  ·  x = −4 est solution de 2x + 3 = 11
✓ Une équation est une question : un nombre est solution, ou non, après calcul des deux membres. Ici 2 × (−4) + 3 = −5 ≠ 11 : la solution est x = 4.
✗ De x + 15 = 4, écrire « x = 4 + 15 »  ·  de x − 7 = 5, écrire « x = 5 − 7 »
✓ On contrarie l'opération : x = 4 − 15 = −11 et x = 5 + 7 = 12. Dans 𝔻, −11 est une solution parfaitement acceptable.
✗ 0 × x = 5 donc x = 5
✓ 0 × x vaut 0 quel que soit x : cette équation n'a aucune solution.
✗ De 4x = 22, écrire « x = 22 − 4 »  ·  de 7x = 42, écrire « x = 42 × 7 »
✓ Un coefficient s'enlève par une division : x = 22 ÷ 4 = 5,5, et x = 42 ÷ 7 = 6.
✗ Dans 3x − 5 = 10, diviser d'abord par 3
✓ On enlève d'abord le terme, ensuite le coefficient : 3x = 15, puis x = 5.
✗ Traduire « le double d'un nombre, augmenté de 3 » par 2(x + 3)  ·  calculer sans avoir dit ce que représente x  ·  s'arrêter à « x = 9 »
✓ C'est 2x + 3. On écrit d'abord « x est …, en … », et l'on termine par une phrase avec l'unité : « le côté mesure 9 cm ».
A SAVOIR PAR COEUR AVANT LE DEVOIR
  1. Une équation est une égalité contenant une inconnue ; une solution est une valeur qui rend l'égalité vraie ; résoudre, c'est les trouver toutes.
  2. Tester une valeur : calculer les deux membres séparément, puis comparer, et conclure en toutes lettres.
  3. Même opération sur les deux membres : x + a = b → x = b − a ; x − a = b → x = b + a ; a − x = b → x = a − b.
  4. a × x = b (a ≠ 0) → x = b ÷ a ; x ÷ a = b → x = b × a. Un coefficient s'enlève par une division.
  5. ax + b = c : d'abord le terme, ensuite le coefficient, d'où x = (c − b) ÷ a.
  6. Signes : −2x = 6 donne x = −3 ; la solution peut être négative ou décimale ; 0 × x = 5 n'a aucune solution.
  7. Problème : choisir l'inconnue et son unité, écrire l'équation, résoudre, vérifier dans l'énoncé, répondre par une phrase.
  8. « augmenté de » = + ; « le double » = 2x ; « le tiers » = x ÷ 3. Attention à l'endroit où porte l'opération.
