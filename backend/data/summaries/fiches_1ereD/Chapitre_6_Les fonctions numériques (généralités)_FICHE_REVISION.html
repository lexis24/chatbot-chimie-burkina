Leçon 1 : Opérations sur les fonctions

EGALITE DE DEUX FONCTIONS
f = g ⇔ Df = Dg  et  f(x) = g(x) pour tout x
  • Les deux conditions sont exigées : même ensemble de définition, puis mêmes valeurs sur cet ensemble commun.
  • Si les valeurs coïncident seulement sur une partie E de ℝ, f et g coïncident sur E sans être égales : x ↦ x2 + xx et x ↦ x + 1 coïncident sur ℝ*, mais la première n'accepte pas 0.
  • Règle de conduite : écrire l'ensemble de définition avant toute simplification.

Opérations et ensembles de définition

POINT PAR POINT : λ REEL
(λf)(x) = λ f(x)   (f ± g)(x) = f(x) ± g(x)   (fg)(x) = f(x) g(x)   (f / g)(x) = f(x)g(x)
Dλf = Df    Df+g = Df−g = Dfg = Df ∩ Dg
Df/g = {x ∈ Df ∩ Dg tels que g(x) ≠ 0}

Ces règles se retrouvent en se demandant ce qu'il faut pour écrire le calcul : les deux images doivent exister, d'où l'intersection ; le quotient exige de plus le droit de diviser, d'où les zéros de g retirés. Et f − g = f + (−1)g n'est pas une opération nouvelle.

Déterminer un ensemble de définition

LES TROIS SOURCES D'INTERDICTION
dénominateur ≠ 0  ·  quantité sous un radical ≥ 0
radical au dénominateur : quantité > 0 (strictement)
  • Traduire chaque interdiction en équation ou inéquation, une contrainte à la fois ; tableau de signes pour un produit ou un quotient. Le domaine est l'intersection des ensembles obtenus.
  • Réponse en intervalles ou sous la forme ℝ ∖ {…}, contrôlée par une valeur interdite et une valeur autorisée.

Leçon 2 : Composition et restriction

COMPOSEE DE f SUIVIE DE g
(g∘f)(x) = g(f(x))
x ∈ Dg∘f ⇔ x ∈ Df et f(x) ∈ Dg
  • f agit d'abord, g ensuite : dans g∘f, la fonction écrite en dernier agit en premier ; lire de l'intérieur vers l'extérieur. Dg∘f est presque toujours plus petit que Df, la seconde fonction triant les nombres produits par la première.
  • Méthode : identifier l'intérieure f et l'extérieure g ; remplacer la variable de g par f(x) tout entière, entre parenthèses ; écrire les deux conditions d'existence, traduire la seconde en inéquation en x, résoudre, intersecter.

Restriction

Pour I inclus dans Df, la restriction de f à I a pour ensemble de définition I et y prend les mêmes valeurs que f : aucune valeur ne change, seul l'ensemble de départ. Ce n'est donc pas f (sauf si I = Df), mais une fonction qui coïncide avec f sur I. Utilité : x ↦ x2 n'est pas monotone sur ℝ, mais sa restriction à [0 ; +∞[ est strictement croissante.

Parité

Ensemble symétrique par rapport à 0 : pour tout x de D, le nombre −x appartient aussi à D. C'est le cas de ℝ, ℝ*, [−3 ; 3], ℝ ∖ {−2 ; 2} ; ce n'est pas le cas de [0 ; +∞[ ni de ℝ ∖ {1}.

PARITE : Df SYMETRIQUE PAR RAPPORT A 0
f paire : f(−x) = f(x)   ·   f impaire : f(−x) = −f(x)  (pour tout x de Df)
  • La symétrie du domaine se vérifie en premier : si −x n'est pas dans Df, l'écriture f(−x) n'a aucun sens. Toute puissance d'exposant pair est paire, d'exposant impair est impaire ; un polynôme qui mélange les deux, comme x2 + x, n'est en général ni l'un ni l'autre.
  • Méthode : calculer f(−x) en remplaçant chaque x par (−x), simplifier, comparer à f(x) et à −f(x). Un contre-exemple numérique suffit : si f(−1) n'est égal ni à f(1) ni à −f(1), la conclusion est acquise.

Interprétation graphique et symétries

Repère orthogonal (O, I, J), (C) courbe de f. f paire si et seulement si (C) est symétrique par rapport à l'axe des ordonnées (OJ) ; f impaire si et seulement si (C) est symétrique par rapport à l'origine O. On étudie alors f sur l'ensemble d'étude Df ∩ [0 ; +∞[, puis on complète par la symétrie. Si f est impaire et définie en 0, alors f(0) = 0 : la courbe passe par l'origine.

ELEMENTS DE SYMETRIE : POUR TOUT x DE Df, 2a − x RESTE DANS Df
axe (Δ) : x = a  ⇔  f(2a − x) = f(x), soit f(a + h) = f(a − h)
centre Ω(a ; b)  ⇔  f(2a − x) + f(x) = 2b, soit f(a + h) + f(a − h) = 2b

La parité en est le cas particulier : a = 0 donne l'axe des ordonnées, a = b = 0 l'origine. Méthode : vérifier que Df est symétrique par rapport à a, calculer f(2a − x) en réduisant complètement, comparer à f(x) pour un axe, former la somme pour un centre, conclure en toutes lettres.

Leçon 3 : Comparaison de fonctions

COMPARER, C'EST ETUDIER UN SIGNE : SUR UN INTERVALLE K
f ≥ g sur K ⇔ f(x) − g(x) ≥ 0 pour tout x de K
  • f ≥ 0 sur K : la courbe est au-dessus de l'axe des abscisses (ou sur cet axe). f ≥ g sur K : la courbe de f est au-dessus de celle de g ; là où f − g s'annule, les deux courbes se touchent.
  • Méthode : sur Df ∩ Dg ou l'intervalle imposé, former d(x) = f(x) − g(x), réduire, développer, factoriser, puis dresser le tableau de signes de d avec toutes les racines et valeurs interdites ; conclure en termes de courbes.

Fonction majorée, minorée, bornée

SUR UN ENSEMBLE K
majorée : il existe M tel que f(x) ≤ M sur K  ·  minorée : il existe m tel que f(x) ≥ m sur K
bornée : m ≤ f(x) ≤ M pour tout x de K
  • M est un majorant : la courbe reste sous la droite y = M ; m est un minorant : elle reste au-dessus de y = m.
  • Un majorant n'est pas unique (tout nombre plus grand convient) ni forcément atteint ; s'il est atteint, on l'appelle maximum.
  • Méthode : encadrer la partie variable (carré, valeur absolue, racine carrée sont positifs ou nuls), puis transformer l'encadrement pas à pas : ajouter conserve le sens, multiplier par un négatif le renverse, et passer à l'inverse le renverse aussi si les deux membres sont strictement positifs.

Leçon 4 : Sens de variation d'une fonction composée

  • f croissante sur l'intervalle I : pour tous a, b de I, a < b ⇒ f(a) ≤ f(b) (l'ordre est conservé).
  • f décroissante sur I : a < b ⇒ f(a) ≥ f(b) (l'ordre est renversé). f monotone sur I : croissante sur I ou décroissante sur I.
TAUX D'ACCROISSEMENT : x1 ET x2 DISTINCTS DANS I
T = f(x2) − f(x1)x2 − x1    croissante ⇔ T ≥ 0  ·  décroissante ⇔ T ≤ 0

Méthode : prendre x1 et x2 distincts quelconques dans I, factoriser f(x2) − f(x1) par x2 − x1, simplifier, puis déterminer le signe de T sur I.

Tableau de variation

  • Première ligne : les valeurs de x dans l'ordre croissant, avec celles où le sens change et les valeurs interdites, marquées d'une double barre : décroissante sur deux intervalles séparés par une valeur interdite ne veut pas dire décroissante sur leur réunion.
  • Seconde ligne : ↗ sur chaque intervalle de croissance, ↘ sur chaque intervalle de décroissance, avec les valeurs de f aux extrémités des flèches. Maximum au sommet d'une montante suivie d'une descendante, minimum au creux d'une descendante suivie d'une montante.

Variation d'une composée

REGLE DES SIGNES : f MONOTONE SUR I, A VALEURS DANS J, g MONOTONE SUR J
même sens → g∘f croissante sur I  ·  sens contraires → g∘f décroissante sur I
+ pour « croissante », − pour « décroissante » : règle des signes de la multiplication
  • « A valeurs dans J » n'est pas une formalité : g doit être monotone sur tout l'intervalle où arrivent les images de f. Pour x ↦ (2x − 1)2 sur [12 ; +∞[, vérifier que 2x − 1 reste positif, car x ↦ x2 n'est croissante que sur [0 ; +∞[.
  • Méthode : décomposer (intérieure f, extérieure g) ; sens de f sur I et intervalle image J ; sens de g sur cet intervalle J ; appliquer la règle ; conclure en nommant l'intervalle.

Fonctions associées (repère orthogonal)

FonctionCourbe déduite de (C) et variations
x ↦ f(x) + λtranslation verticale de vecteur λ j, vers le haut si λ > 0 ; variations inchangées.
x ↦ f(x − λ)translation horizontale de vecteur λ i, vers la droite si λ > 0 ; variations inchangées, intervalles décalés de λ.
x ↦ λ f(x)toutes les ordonnées multipliées par λ ; variations inchangées si λ > 0, renversées si λ < 0.
x ↦ −f(x)  et  x ↦ f(−x)symétriques de (C) par rapport à l'axe des abscisses et à l'axe des ordonnées ; variations renversées, intervalles symétriques dans le second cas.

Méthode : recopier la ligne des x (la transformer pour f(x − λ) et f(−x)), retourner les flèches si le sens est renversé, transformer les valeurs aux extrémités (ajouter λ, ou multiplier par λ) : un maximum reste un maximum si le sens est conservé, devient un minimum sinon. Le nombre d'intervalles de monotonie ne change jamais.

PIEGES ET ERREURS FREQUENTES
✗ x2 − 1x − 1 = x + 1 pour tout x  ·  Df/g = Df ∩ Dg
✓ L'égalité ne vaut que pour x ≠ 1 : domaines différents, fonctions non égales. Le domaine se lit sur l'expression telle qu'elle est donnée : dans x2 − 4x + 2, −2 reste exclue après simplification en x − 2. Et pour un quotient, retirer en plus les zéros de g ; ceux du numérateur ne gênent pas : dans x − 2x − 5, 2 est autorisée (image 0), seule 5 est interdite.
✗ g∘f = f∘g
✓ L'ordre compte. Pour f(x) = x − 1 et g(x) = √x : (g∘f)(x) = √x − 1, définie pour x ≥ 1, alors que (f∘g)(x) = √x − 1, définie pour x ≥ 0.
✗ f n'est pas paire, donc elle est impaire
✓ Les deux propriétés sont indépendantes, et « ni paire ni impaire » est le cas le plus fréquent. Pour f(x) = √x, le domaine [0 ; +∞[ n'est même pas symétrique par rapport à 0 : la question ne se pose pas. Seule la fonction nulle est à la fois paire et impaire.
✗ f(1) > g(1), donc f > g sur tout l'intervalle  ·  f est majorée par 10, donc f atteint 10
✓ Quelques points ne prouvent rien : il faut le signe de f − g sur tout l'intervalle, deux courbes pouvant se croiser juste après le bord de la figure. Et un majorant n'est pas un maximum : x ↦ x2x2 + 1 est majorée par 1 sans jamais valoir 1. Préciser aussi l'ensemble : x ↦ x2 est majorée par 4 sur [−2 ; 2], par aucun nombre sur ℝ.
✗ f et g croissantes, donc fg croissante  ·  x ↦ 1x est décroissante sur ℝ*
✓ La règle des signes vaut pour la composée ; la somme de deux croissantes est croissante, mais le produit et le quotient n'ont rien d'automatique : f(x) = g(x) = x croissantes, alors que x ↦ x2 ne l'est pas sur ℝ. La monotonie se déclare toujours sur un intervalle : l'inverse décroît sur ]−∞ ; 0[ et sur ]0 ; +∞[, mais −1 < 1 et pourtant 1−1 < 11.
A SAVOIR PAR COEUR AVANT LE DEVOIR
  1. Egalité et domaines : f = g exige même domaine et mêmes valeurs (domaine écrit avant toute simplification). Df+g = Dfg = Df ∩ Dg ; pour f/g, la même intersection privée des zéros de g. Interdictions : dénominateur ≠ 0, radical ≥ 0, radical au dénominateur > 0.
  2. Composée : (g∘f)(x) = g(f(x)) ; domaine : x ∈ Df et f(x) ∈ Dg ; g∘f ≠ f∘g. La restriction à I garde les valeurs et réduit le domaine.
  3. Parité et symétries : Df symétrique par rapport à 0, puis f(−x) = f(x) (paire, axe des ordonnées) ou f(−x) = −f(x) (impaire, centre O) ; ensemble d'étude Df ∩ [0 ; +∞[. Axe x = a si f(2a − x) = f(x) ; centre Ω(a ; b) si f(2a − x) + f(x) = 2b.
  4. Comparaison : signe de f − g ; f ≥ g = courbe de f au-dessus. Bornes : f ≤ M majorée, f ≥ m minorée, bornée les deux ; un majorant n'est pas forcément atteint.
  5. Variation : signe du taux f(x2) − f(x1)x2 − x1 ; tableau de variation avec les valeurs aux extrémités des flèches et une double barre sur chaque valeur interdite.
  6. Composée et associées : même sens → croissante, sens contraires → décroissante, chaque fonction monotone sur l'intervalle qui convient. f + λ et f(x − λ) conservent le sens ; λf le conserve si λ > 0, le renverse si λ < 0.
