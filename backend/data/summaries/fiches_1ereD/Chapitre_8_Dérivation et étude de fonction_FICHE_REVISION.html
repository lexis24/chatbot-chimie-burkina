L'ESSENTIEL

Leçon 1 : Dérivation en un point

Soit f définie sur un intervalle contenant a. Le taux de variation de f entre a et a + h (pour h ≠ 0) est T(h) = f(a + h) − f(a)h.

NOMBRE DERIVE : LIMITE FINIE EXIGEE
f′(a) = limh→0 f(a + h) − f(a)h = limx→a f(x) − f(a)x − a

f est dérivable en a si ce taux admet une limite finie ; cette limite est le nombre dérivé f′(a). Les deux écritures coïncident (poser x = a + h). On simplifie par h (licite car h ≠ 0) avant de faire tendre h vers 0.

Les deux lectures de f′(a)

  • Géométrique : f′(a) est la pente (coefficient directeur) de la tangente au point d'abscisse a, position limite des sécantes.
  • Cinématique : si f(t) est la position d'un mobile, f′(a) est la vitesse instantanée en a ; la dérivée de f′ décrit l'accélération.
  • La fonction qui, à chaque x où f est dérivable, associe f′(x) est la fonction dérivée f′.
APPROXIMATION AFFINE : POUR h PROCHE DE 0
f(a + h) ≈ f(a) + h f′(a)
(1 + h)2 ≈ 1 + 2h    (1 + h)3 ≈ 1 + 3h    (1 + h)n ≈ 1 + nh

Non-dérivabilité, deux cas. Tangente verticale : pour √x en 0, le taux 1√h tend vers +∞ : limite infinie, demi-tangente verticale. Point anguleux : pour |x| en 0, le taux |h|h vaut 1 si h > 0 et −1 si h < 0, les nombres dérivés à droite et à gauche diffèrent (un coin).

Leçon 2 : Equation de la tangente

Soit f dérivable en a. La tangente à sa courbe (C) au point A(a ; f(a)) a pour coefficient directeur f′(a).

EQUATION DE LA TANGENTE AU POINT D'ABSCISSE a
y = f′(a) (x − a) + f(a)

La pente f′(a) multiplie la parenthèse, l'ordonnée f(a) s'ajoute. Tangente horizontale si f′(a) = 0 : son équation est alors y = f(a).

Dans un repère orthonormé, face à la droite y = mx + p : parallèle ⇔ f′(a) = m  ·  perpendiculaire ⇔ f′(a) × m = −1, soit f′(a) = −1m. Chercher ces points, c'est résoudre une équation d'inconnue a puis calculer f(a). Si la tangente doit seulement passer par un point B extérieur à (C), le contact est inconnu : le nommer a, écrire (Ta), y reporter B.

Opérations : u, v dérivables sur un même intervalle, λ réel

OPERATIONS SUR LES DERIVEES
(u + v)′ = u′ + v′     (λu)′ = λu′     (uv)′ = u′v + uv′
(1v)′ = −v′v2     (uv)′ = u′v − uv′v2   (v ≠ 0)

Au numérateur du quotient, c'est u′v moins uv′ : l'ordre n'est pas interchangeable, l'échanger change le signe de la dérivée. Le dénominateur est au carré.

COMPOSEES : a, b REELS ET u > 0 POUR LA RACINE
(f(ax + b))′ = a f′(ax + b)
(un)′ = n u′ un−1     (√u)′ = u′2√u

On dérive comme d'habitude, puis on multiplie par a (ou par u′) : (sin(ax + b))′ = a cos(ax + b) · (cos(ax + b))′ = −a sin(ax + b) · (√ax + b)′ = a2√ax + b · (tan(ax + b))′ = a(1 + tan2(ax + b)). Préciser l'ensemble de dérivabilité avant tout calcul : retirer les valeurs qui annulent un dénominateur ou la quantité sous une racine. Laisser factorisée une dérivée dont on étudiera le signe.

Leçon 4 : Application à l'étude des variations

SIGNE DE f′ ET SENS DE VARIATION : SUR UN INTERVALLE I
f′ ≥ 0 ⇒ croissante  ·  f′ > 0 ⇒ strictement croissante
f′ ≤ 0 ⇒ décroissante  ·  f′ < 0 ⇒ strictement décroissante
f′ = 0 sur I tout entier ⇒ f constante sur I

Le mot intervalle est indispensable : si le domaine est une réunion d'intervalles, on conclut intervalle par intervalle, une double barre marquant la coupure qu'aucune flèche ne traverse.

Extremum local

  • Soit f dérivable sur un intervalle ouvert contenant a. Si f admet un extremum local en a, alors f′(a) = 0 : la tangente y est horizontale.
  • Réciproque à manier avec soin : f′(a) = 0 ne suffit pas. Il y a extremum en a si et seulement si f′ change de signe en a : de − à + pour un minimum, de + à − pour un maximum.
  • Si f′ s'annule sans changer de signe, pas d'extremum : ainsi x3 en 0, où la courbe traverse sa tangente horizontale : c'est un point d'inflexion. Toute courbe du troisième degré en possède un, et ce point est aussi son centre de symétrie.

Stricte monotonie, bijection, unicité

Soit f dérivable sur un intervalle I, avec f′ > 0 sur I (ou f′ < 0 sur I). Alors f est strictement monotone et réalise une bijection de I sur l'intervalle image f(I) : l'équation f(x) = λ admet au plus une solution dans I, et exactement une lorsque λ ∈ f(I). Sur [α ; β] où f croît strictement, f([α ; β]) = [f(α) ; f(β)] : il suffit que λ soit compris entre f(α) et f(β). La monotonie donne l'unicité, l'appartenance à f(I) l'existence.

Leçon 5 : Etude complète et fonctions associées

Plan d'une étude complète

1. Ensemble de définition Df, puis ensemble d'étude DE si une parité, une périodicité ou une symétrie le réduit.  2. Limites aux bornes de DE et asymptotes, avec la position de la courbe.  3. Dérivée f′ et son signe après factorisation.  4. Tableau de variation : limites aux bornes, extremums chiffrés.  5. Points particuliers : intersections avec les axes, quelques images, tangentes remarquables.  6. Tracé : asymptotes en pointillés, points remarquables, courbe conforme au tableau, puis symétrie.

Ensemble d'étude et symétries

Soit Df symétrique par rapport à 0. f est paire si f(−x) = f(x) pour tout x de Df : l'axe des ordonnées est axe de symétrie ; impaire si f(−x) = −f(x) : l'origine O est centre de symétrie. On étudie alors f sur Df ∩ [0 ; +∞[, puis on complète par symétrie. Si f(x + T) = f(x) pour tout x, f est périodique de période T : on l'étudie sur un intervalle de longueur T, puis on reproduit le motif par translations de vecteur T i.

ELEMENTS DE SYMETRIE : POUR TOUT h TEL QUE a + h ET a − h SOIENT DANS Df
I(a ; b) centre :  f(a + h) + f(a − h) = 2b
droite x = a axe :  f(a + h) = f(a − h)

Parité et imparité en sont les cas a = 0.

Asymptotes

Verticale x = x0 si limx→x0 f(x) = ±∞  ·  horizontale y = ℓ si limx→±∞ f(x) = ℓ.

ASYMPTOTE OBLIQUE EN +∞ OU EN −∞ : a ≠ 0
(Δ) : y = ax + b ⇔ lim (f(x) − (ax + b)) = 0
f(x) = ax + b + ε(x)  avec  limx→±∞ ε(x) = 0

Position relative : le signe de ε(x). Positif, la courbe est au-dessus de (Δ) ; négatif, en dessous ; nul, elle coupe (Δ). Quand le degré du numérateur dépasse de 1 celui du dénominateur, la division donne cette écriture : x2 + 1x = x + 1x.

Lecture graphique. Les solutions de f(x) = λ sont les abscisses des intersections avec la droite y = λ ; les valeurs de λ où leur nombre change sont les extremums locaux. f(x) > λ : portions au-dessus de cette droite ; un maximum M majore f sur tout l'intervalle.

PIEGES ET ERREURS FREQUENTES
✗ (uv)′ = u′v′  ·  (uv)′ = uv′ − u′vv2
✓ (uv)′ = u′v + uv′ ; contrôle : (x × x)′ = 2x, et non 1 × 1. Au numérateur du quotient, c'est u′v − uv′ : l'échanger inverse toutes les variations.
✗ y = f(a)(x − a) + f′(a)  ·  f(2) = 3 donc la tangente en 2 a pour pente 3
✓ y = f′(a)(x − a) + f(a) : la pente multiplie la parenthèse, l'ordonnée s'ajoute. La pente en 2 est f′(2), jamais f(2) : l'un est une hauteur, l'autre une inclinaison.
✗ (sin(3x))′ = cos(3x)
✓ La règle est (f(ax + b))′ = a f′(ax + b) : le facteur a ne s'oublie jamais, donc (sin(3x))′ = 3 cos(3x). Poser t = 3x, c'est aller trois fois plus vite : les pentes sont triplées.
✗ f′(a) = 0 donc extremum en a  ·  f′ < 0 sur ℝ* donc f décroissante sur ℝ*
✓ f′(a) = 0 est nécessaire, pas suffisant : il faut que f′ change de signe. Pour x3, 3x2 s'annule en 0 en restant positive : point d'inflexion, pas d'extremum. Et le lien signe/variation ne vaut que sur un intervalle : 1x décroît sur ]−∞ ; 0[ et sur ]0 ; +∞[, jamais sur la réunion (f(−1) = −1 < f(1) = 1).
✗ f est négative, donc f est décroissante
✓ Le signe de f situe la courbe par rapport à (Ox) ; celui de f′ donne son inclinaison. Deux études distinctes : f(x) = x − 5 est négative et croissante en x = 1.
✗ La courbe admet y = x pour asymptote, donc elle est au-dessus  ·  f(x + 2) décale vers la droite
✓ La limite de f(x) − x donne l'asymptote, mais c'est son signe qui donne la position : une courbe peut couper son asymptote. Et g(x) = f(x + 2) donne g(−2) = f(0) : décalage de 2 vers la gauche ; c'est f(x) + 2 qui décale vers le haut.
A SAVOIR PAR COEUR AVANT LE DEVOIR
  1. f′(a) = limh→0 f(a + h) − f(a)h = pente de la tangente = vitesse instantanée. Pas de dérivabilité si la limite est infinie (√x en 0) ou si celles de droite et de gauche diffèrent (|x| en 0).
  2. Tangente : y = f′(a)(x − a) + f(a) ; horizontale si f′(a) = 0, parallèle à y = mx + p si f′(a) = m, perpendiculaire si f′(a) = −1m. Approximation affine : f(a + h) ≈ f(a) + hf′(a), (1 + h)n ≈ 1 + nh.
  3. Dérivées : (xn)′ = nxn−1, (√x)′ = 12√x, (1x)′ = −1x2, (sin)′ = cos, (cos)′ = −sin, (tan)′ = 1 + tan2.
  4. Opérations : (uv)′ = u′v + uv′, (uv)′ = u′v − uv′v2, (λu)′ = λu′, (f(ax + b))′ = af′(ax + b), (un)′ = nu′un−1, (√u)′ = u′2√u.
  5. Le signe de f′ donne les variations, sur un intervalle ; extremum là où f′ change de signe ; toujours factoriser f′ d'abord. Bijection : f′ > 0 sur I ⇒ f(x) = λ a une solution unique dès que λ ∈ f(I).
  6. Etude complète : domaine · ensemble d'étude · limites · asymptotes · dérivée factorisée et signe · tableau · points particuliers · tracé. Asymptote oblique : f(x) = ax + b + ε(x), ε → 0 ; position par le signe de ε(x). Symétries : I(a ; b) centre si f(a + h) + f(a − h) = 2b, x = a axe si f(a + h) = f(a − h). Associées : pour λ > 0, f(x + λ) va vers la gauche et f + λ vers le haut ; |f| se replie vers le haut.
