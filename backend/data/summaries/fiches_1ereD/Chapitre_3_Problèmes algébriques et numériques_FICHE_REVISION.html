Leçon 1 : Equations avec radicaux

EQUATION √f(x) = g(x) : TROIS CONDITIONS SIMULTANEES
√f(x) = g(x) ⇔ f(x) ≥ 0  et  g(x) ≥ 0  et  f(x) = (g(x))2
  • 1re condition : existence du radical ; elle donne l'ensemble de validité V.
  • 2e condition : une racine carrée est positive ou nulle, donc le second membre l'est aussi.
  • 3e condition : équation obtenue en élevant au carré. On la résout, puis on ne garde que les valeurs vérifiant aussi les deux premières.

Deux nombres positifs qui ont le même carré sont égaux : c'est ce que garantissent les deux premières lignes, et c'est ce qui fait de ce système une équivalence. Sans elles, l'élévation au carré n'est qu'une implication et laisse ouverte la possibilité √f(x) = −g(x), source des solutions parasites.

DEUX CAS PARTICULIERS
√f(x) = √g(x) ⇔ f(x) ≥ 0  et  f(x) = g(x)
√f(x) = k :  aucune solution si k < 0 ;  équivaut à f(x) = k2 si k ≥ 0

Pour deux radicaux, aucune condition de signe n'est à ajouter : les deux membres sont déjà positifs, et une seule condition d'existence suffit, l'autre en découle. Pour un second membre constant négatif, on conclut en une ligne, sans élever au carré.

Marche à suivre

  • Poser f(x) ≥ 0 et résoudre : ensemble de validité V.
  • Poser g(x) ≥ 0 et résoudre. Si aucun x de V ne la vérifie, il n'y a pas de solution.
  • Elever au carré, résoudre f(x) = (g(x))2 en développant le carré du second membre.
  • Confronter chaque valeur trouvée aux deux conditions et écarter celles qui n'y satisfont pas.
  • Vérifier les valeurs retenues dans l'équation de départ, en calculant les deux membres séparément, puis conclure par une phrase.
Deux radicaux séparés. On isole un radical, on élève au carré, on simplifie, on isole de nouveau, puis on élève une seconde fois.

Leçon 2 : Inéquations avec radicaux

INEQUATION √f(x) < g(x) : INTERSECTION
√f(x) < g(x) ⇔ f(x) ≥ 0  et  g(x) > 0  et  f(x) < (g(x))2
inégalité large :  les deux dernières conditions deviennent g(x) ≥ 0  et  f(x) ≤ (g(x))2

L'ensemble des solutions est l'intersection des trois ensembles obtenus. La condition g(x) > 0 est celle qu'on oublie : une racine carrée, positive ou nulle, ne peut être strictement inférieure à g(x) que si g(x) est strictement positif. Le passage au carré n'est une équivalence que parce que les deux membres sont positifs : sur les positifs, élever au carré conserve l'ordre.

INEQUATION √f(x) > g(x) : REUNION DE DEUX CAS
Cas 1 :  f(x) ≥ 0  et  g(x) < 0  (inégalité automatiquement vraie)
Cas 2 :  g(x) ≥ 0  et  f(x) > (g(x))2

La solution est la réunion des deux ensembles ; au cas 2, la condition f(x) ≥ 0 est automatique. Une seule idée commande les deux encadrés, le signe du second membre, mais elle produit deux effets opposés : pour < l'inégalité devient impossible et l'on intersecte ; pour > elle devient certaine et l'on réunit.

COMPARER DEUX RADICAUX
√f(x) < √g(x) ⇔ 0 ≤ f(x) < g(x)
√f(x) ≤ √g(x) ⇔ 0 ≤ f(x) ≤ g(x)

Cas le plus simple : aucune condition de signe, et une seule condition d'existence, celle du plus petit radicand. L'inégalité se transmet du radicand à la racine sans changer de sens, la fonction racine carrée étant croissante.

Marche à suivre

  • Pour < : résoudre les trois conditions, hachurer les trois ensembles sur un axe, prendre la partie commune.
  • Pour > : traiter le cas 1, puis le cas 2, et réunir ; vérifier que les bornes se recollent, les deux morceaux se rejoignant souvent en un seul intervalle.
  • Le carré ramène à une inéquation du second degré : tableau de signes obligatoire.
  • Conclure en intervalles, en soignant les crochets, ouverts ou fermés.
Quand la condition d'existence n'est pas un intervalle. Si le radicand est un trinôme, sa positivité s'écrit en réunion de deux intervalles : x2 − 4 ≥ 0 donne ]−∞ ; −2] ∪ [2 ; +∞[, et l'intersection finale se fait morceau par morceau. La méthode, elle, ne change pas.

Leçon 3 : Systèmes linéaires

Une équation est linéaire lorsque chaque inconnue y figure au premier degré seulement, sans carré, sans produit d'inconnues et sans radical. Résoudre un système, c'est trouver toutes les valeurs des inconnues qui vérifient toutes les équations à la fois : une solution est un couple (x ; y) à deux inconnues, un triplet (x ; y ; z) à trois. Deux systèmes sont équivalents lorsqu'ils ont exactement le même ensemble de solutions.

OPERATIONS QUI CONSERVENT LES SOLUTIONS
échanger deux équations  ·  multiplier une équation par un nombre non nul
ajouter à une équation un multiple d'une autre équation

On note ces opérations en marge, par exemple L2 ← L2 − 2L1. Multiplier par 0 transformerait l'équation en 0 = 0 et ferait gagner de fausses solutions ; ajouter à L2 un multiple d'elle-même la ferait disparaître. Ces précautions garantissent qu'on peut toujours revenir en arrière : c'est le retour qui fait l'équivalence.

Nombre de solutions d'un système 2×2

Chaque équation ax + by = c représente une droite du plan. Trois configurations, et trois seulement :

DETERMINANT DU SYSTEME ax + by = c ET a′x + b′y = c′
ab′ − a′b ≠ 0 ⇔ droites sécantes ⇔ solution unique

Si ab′ − a′b = 0, les couples (a ; b) et (a′ ; b′) sont proportionnels : même direction, donc droites parallèles, éventuellement confondues. On départage par les seconds membres.

Trois techniques de résolution

  • Combinaison : ranger les inconnues en colonnes, rendre les coefficients d'une inconnue égaux au signe près, additionner ou soustraire pour l'éliminer, résoudre, puis reporter dans une équation de départ.
  • Substitution : repérer une inconnue de coefficient 1 ou −1, l'exprimer en fonction de l'autre, la remplacer dans toutes les autres équations, résoudre, puis remonter.
  • Pivot de Gauss : par combinaisons successives, amener le système à une forme en escalier, puis remonter de la dernière équation vers la première.

Dans les trois cas, vérifier le couple ou le triplet dans toutes les équations initiales avant de conclure.

Mettre un problème en système

  • Nommer les inconnues par une phrase complète, avec l'unité : « soit x le prix d'un sac de mil, en FCFA ».
  • Traduire chaque information par une équation : en principe autant d'équations que d'inconnues.
  • Nettoyer le système : chasser les dénominateurs, simplifier les coefficients par un diviseur commun.
  • Résoudre, vérifier, puis conclure par une phrase revenant au contexte, avec les unités, en contrôlant la vraisemblance (un prix négatif, un effectif décimal doivent alerter).
PARTAGE PROPORTIONNEL D'UNE SOMME S A p, q, r
parts : pk, qk, rk   et   (p + q + r) k = S

Un partage proportionnel n'introduit qu'une seule inconnue véritable, le coefficient k, quel que soit le nombre de parts. On contrôle à la fin que la somme des parts vaut bien S.

PIEGES ET ERREURS FREQUENTES
✗ √x + 2 = x donne x = 2 ou x = −1  ·  « j'ai posé x + 2 ≥ 0, donc j'ai vérifié »
✓ L'élévation au carré est une implication : elle crée des solutions parasites. Ici −1 vérifie bien la condition d'existence ; c'est la condition de signe x ≥ 0 qui l'écarte, car √1 = 1 ≠ −1. Seule solution : x = 2.
✗ √x + 3 = −1 a pour solution x = −2
✓ Une racine carrée est toujours positive ou nulle : elle ne peut valoir −1. Aucune solution, et sans aucun calcul. Celui qui élève au carré a résolu √x + 3 = 1, une équation différente.
✗ √x + 4 = x + 2 donne x + 4 = x2 + 4  ·  √a + b = √a + √b
✓ Le carré d'une somme n'est pas la somme des carrés : (x + 2)2 = x2 + 4x + 4, d'où x2 + 3x = 0, du second degré. De même √9 + 16 = 5 alors que √9 + √16 = 7.
✗ √f(x) < g(x) équivaut à f(x) < (g(x))2  ·  « je vérifierai à la fin »
✓ Il faut aussi f(x) ≥ 0 et g(x) > 0, et la solution est l'intersection des trois. Une inéquation ne se vérifie pas après coup : son ensemble solution contient une infinité de valeurs. Les conditions se posent avant, jamais après.
✗ √x + 6 > x : j'élève au carré, donc x + 6 > x2
✓ Pour >, on discute d'abord le signe du second membre : si x < 0 l'inégalité est vraie partout où le radical existe ; le carré ne s'applique que si x ≥ 0. On prend ensuite la réunion des deux ensembles, jamais leur intersection.
✗ Une inégalité large, c'est la stricte à laquelle on ajoute la borne
✓ Les bonnes conditions s'écrivent dès le départ : pour √f(x) ≤ g(x), ce sont g(x) ≥ 0 et f(x) ≤ (g(x))2. Une borne se justifie par un calcul, jamais par une impression : la remplacer dans l'inéquation de départ tranche la question.
✗ Le système x + y = 1 et 2x + 2y = 5 a une solution  ·  le système x − y = 1 et 2x − 2y = 2 n'en a pas
✓ C'est l'inverse. Le premier aboutit à 0 = 3 : droites strictement parallèles, aucune solution. Le second aboutit à 0 = 0, la seconde équation étant le double de la première : droites confondues, une infinité de solutions.
✗ Réponse d'un problème : « (2 ; 5) », sans phrase, sans unité, sans vérification
✓ Ecrire la phrase qui définit les inconnues avec leur unité, les garder dans le même ordre d'une équation à l'autre, contrôler le couple dans toutes les équations de départ, puis conclure dans l'unité de la question. Un résultat invraisemblable signale une erreur de mise en équation.
A SAVOIR PAR COEUR AVANT LE DEVOIR
  1. √f(x) n'existe que si f(x) ≥ 0, et une racine carrée est toujours positive ou nulle : ces deux faits commandent tout le chapitre.
  2. Equation : √f = g ⇔ f ≥ 0, g ≥ 0, f = g2, puis vérifier  ·  le carré crée des solutions parasites.
  3. √f = √g ⇔ f = g avec f ≥ 0  ·  √f = k avec k < 0 : aucune solution  ·  deux radicaux séparés : isoler, carré, isoler, carré.
  4. Inéquation : √f < g ⇔ f ≥ 0, g > 0, f < g2 : intersection des trois. Version large : f ≥ 0, g ≥ 0 et f ≤ g2.
  5. √f > g : cas g < 0 (vrai dès que f ≥ 0) réuni au cas g ≥ 0 avec f > g2  ·  √f < √g ⇔ 0 ≤ f < g.
  6. Opérations autorisées sur un système : échanger deux équations, multiplier une équation par un nombre non nul, ajouter à une équation un multiple d'une autre équation.
  7. Système 2×2 : une solution si ab′ − a′b ≠ 0 (sécantes) ; aucune si strictement parallèles (0 = 3) ; une infinité si confondues (0 = 0). Résolution par combinaison, substitution ou pivot de Gauss.
  8. Mise en équation : nommer les inconnues par une phrase et une unité, une équation par information, chasser les dénominateurs ; partage proportionnel : parts pk, qk, rk et une seule inconnue k. Vérifier dans toutes les équations, conclure par une phrase.
