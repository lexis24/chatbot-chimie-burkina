L'ESSENTIEL

Leçon 1 : Angle orienté de deux vecteurs

Orientation. Le sens direct (positif) est l'inverse des aiguilles d'une montre. Une base orthonormée (i, j) est directe si l'on passe de i à j par un quart de tour dans ce sens, indirecte sinon ; repère orthonormé direct sauf mention contraire.

ANGLES ORIENTES : u, v, w NON NULS, λ ET μ REELS NON NULS
(u, v) = θ + 2kπ  (k ∈ ℤ), noté (u, v) = θ [2π]
mesure principale : l'unique mesure de ]−π ; π]
(v, u) = −(u, v) [2π]
Chasles : (u, v) + (v, w) = (u, w) [2π]
(−u, v) = (u, v) + π [2π]    (−u, −v) = (u, v) [2π]
(λu, μv) = (u, v) [2π] si λ et μ sont de même signe

L'angle se lit de u vers v ; mesure principale positive = sens direct, négative = sens indirect. Si λ et μ sont de signes contraires, on ajoute π.

Cosinus et sinus d'un réel

M étant le point du cercle trigonométrique associé au réel x, cos x est l'abscisse de M et sin x son ordonnée. Signes (cos, sin) par quadrant, du haut à droite dans le sens direct : (+, +)  ·  (−, +)  ·  (−, −)  ·  (+, −).

RELATION FONDAMENTALE ET ANGLES ASSOCIES : POUR TOUT REEL x, k ∈ ℤ
M(cos x ; sin x)    cos2x + sin2x = 1
−1 ≤ cos x ≤ 1    −1 ≤ sin x ≤ 1
cos(−x) = cos x    sin(−x) = −sin x
cos(π − x) = −cos x    sin(π − x) = sin x
cos(π + x) = −cos x    sin(π + x) = −sin x
cos(π2 − x) = sin x    sin(π2 − x) = cos x
cos(π2 + x) = −sin x    sin(π2 + x) = cos x
cos(x + 2kπ) = cos x    sin(x + 2kπ) = sin x

Chaque ligne est une symétrie du cercle : axe des abscisses (−x), axe des ordonnées (π − x), centre O (π + x), première bissectrice (π2 − x), qui échange les coordonnées : x et π2 − x sont complémentaires, x et π − x supplémentaires.

Tangente

DEFINITION : POUR cos x ≠ 0
tan x = sin xcos x     1 + tan2x = 1cos2x

La condition s'écrit x ≠ π2 + kπ. La tangente est impaire et de période π, non 2π : tan(−x) = −tan x et tan(x + π) = tan x.

Angle de deux vecteurs par les coordonnées

u(x ; y) et v(x′ ; y′) non nuls, base orthonormée directe, θ = (u, v).

COSINUS ET SINUS DE L'ANGLE (u, v)
cos θ = u ⋅ v‖u‖ ⋅ ‖v‖ = xx′ + yy′‖u‖ ⋅ ‖v‖    sin θ = xy′ − yx′‖u‖ ⋅ ‖v‖
‖u‖ = √x2 + y2    ‖v‖ = √x′2 + y′2
  • xx′ + yy′ est le produit scalaire, xy′ − yx′ le déterminant : u et v sont orthogonaux ⇔ premier nul, colinéaires ⇔ second nul.
  • Réciproquement, si ‖u‖ = r et (i, u) = θ, alors u(r cos θ ; r sin θ). Contrôle : cos2θ + sin2θ = 1.

Leçon 2 : Formules d'addition, de duplication et de linéarisation

ADDITION : POUR TOUS REELS a ET b
cos(a + b) = cos a cos b − sin a sin b
cos(a − b) = cos a cos b + sin a sin b
sin(a + b) = sin a cos b + cos a sin b
sin(a − b) = sin a cos b − cos a sin b
tan(a + b) = tan a + tan b1 − tan a tan b    tan(a − b) = tan a − tan b1 + tan a tan b

Les deux dernières valent si les trois tangentes existent. Mémo : le cosinus garde et change le signe, le sinus mélange et garde le signe.

DUPLICATION ET LINEARISATION : CAS b = a DE L'ADDITION
cos 2a = cos2a − sin2a = 2cos2a − 1 = 1 − 2sin2a
sin 2a = 2 sin a cos a
cos2a = 1 + cos 2a2     sin2a = 1 − cos 2a2

Les trois écritures de cos 2a n'en font qu'une (via cos2a + sin2a = 1) : choisir celle qui contient la donnée de l'énoncé. La linéarisation les lit à l'envers pour abaisser un carré.

SOMME EN PRODUIT : POUR TOUS REELS p ET q
cos p + cos q = 2 cos p + q2 cos p − q2
cos p − cos q = −2 sin p + q2 sin p − q2
sin p + sin q = 2 sin p + q2 cos p − q2
sin p − sin q = 2 cos p + q2 sin p − q2

Obtenues en posant p = a + b, q = a − b, elles factorisent une somme : un produit est nul si et seulement si l'un de ses facteurs l'est.

Leçon 3 : Equations trigonométriques et angle auxiliaire

EQUATIONS FONDAMENTALES : k ∈ ℤ
cos x = cos a ⇔ x = a + 2kπ  ou  x = −a + 2kπ
sin x = sin a ⇔ x = a + 2kπ  ou  x = π − a + 2kπ
tan x = tan a ⇔ x = a + kπ

Deux familles modulo 2π pour cos et sin, une seule modulo π pour tan. Existence : cos x = m et sin x = m exigent m ∈ [−1 ; 1]. Second degré en cos x ou sin x : si les deux figurent, remplacer sin2x par 1 − cos2x ; poser X = cos x, résoudre avec le discriminant, écarter les X hors [−1 ; 1], puis revenir à x. Cas particuliers : cos x = 1 ⇔ x = 2kπ  ·  cos x = −1 ⇔ x = π + 2kπ  ·  cos x = 0 ⇔ x = π2 + kπ  ·  sin x = 0 ⇔ x = kπ  ·  sin x = 1 ⇔ x = π2 + 2kπ  ·  sin x = −1 ⇔ x = −π2 + 2kπ.

Fonctions circulaires

  • x ↦ cos x et x ↦ sin x sont définies sur ℝ, à valeurs dans [−1 ; 1], périodiques de période 2π ; le cosinus est pair (courbe symétrique par rapport à l'axe des ordonnées), le sinus impair (symétrique par rapport à l'origine).
  • Les deux courbes se déduisent l'une de l'autre par une translation horizontale, puisque sin x = cos(x − π2)  ·  x ↦ tan x est définie pour x ≠ π2 + kπ, de période π.

Inéquations fondamentales

On les résout sur le cercle : les solutions forment un arc dont les extrémités sont les solutions de l'équation associée. cos x ≥ m donne l'arc à droite de la verticale d'abscisse m ; sin x ≥ m, l'arc au-dessus de l'horizontale d'ordonnée m. Inégalité stricte : bornes ouvertes ; sur [0 ; 2π] l'arc peut se couper en deux morceaux.

Angle auxiliaire

TRANSFORMATION DE a cos x + b sin x : a ET b NON TOUS DEUX NULS
a cos x + b sin x = R cos(x − φ)
R = √a2 + b2    cos φ = aR    sin φ = bR

R est l'amplitude, φ l'angle auxiliaire, défini par les deux conditions à la fois. a cos x + b sin x = c se ramène à cos(x − φ) = cR : l'expression restant entre −R et R, il n'y a de solution que si |c| ≤ R.

Leçon 4 : Relations métriques dans le triangle

Notations. Dans un triangle ABC : a = BC, b = CA, c = AB, et Â, B̂, Ĉ pour les angles. Chaque côté porte la lettre minuscule du sommet opposé.

RELATION D'AL-KASHI : ELLE GENERALISE PYTHAGORE
a2 = b2 + c2 − 2bc cos Â
b2 = a2 + c2 − 2ac cos B̂    c2 = a2 + b2 − 2ab cos Ĉ
cos Â = b2 + c2 − a22bc

L'angle est celui compris entre les deux côtés dont on prend les carrés, donc opposé au côté calculé. La dernière écriture sert si les trois côtés sont connus ; cosinus négatif = angle obtus.

AIRE ET LOI DES SINUS : DANS TOUT TRIANGLE ABC
S = 12bc sin Â = 12ac sin B̂ = 12ab sin Ĉ
asin Â = bsin B̂ = csin Ĉ

Résoudre un triangle = trouver tous ses côtés et tous ses angles : deux côtés et l'angle compris, Al-Kashi ; trois côtés, la forme en cosinus ; deux angles et un côté, Â + B̂ + Ĉ = 180° puis loi des sinus. Au plus grand angle est opposé le plus grand côté. Médiane AI : Al-Kashi dans ABI avec BI = a2.

PIEGES ET ERREURS FREQUENTES
✗ cos(a + b) = cos a + cos b  ·  cos 2a = 2 cos a  ·  sin a2 = sin a2
✓ Ni cos ni sin ne se distribuent sur une somme : ce sont des fonctions, il faut passer par les formules d'addition. Contre-exemple : cos π = −1 mais cos π2 + cos π2 = 0.
✗ cos x = 12 donc x = π3, une seule solution  ·  cos 2x = 12 donne x = ±π6 + 2kπ
✓ Deux familles modulo 2π : x = ±π3 + 2kπ, et le «  + 2kπ » ne s'oublie pas. Avec 2x, on divise toute l'écriture par 2, période comprise : x = ±π6 + kπ, soit quatre solutions sur [0 ; 2π].
✗ La mesure principale de 11π6 est 11π6  ·  u et v sont orthogonaux car xy′ − yx′ = 0
✓ La mesure principale est dans ]−π ; π] : ici 11π6 > π, on retranche 2π, d'où −π6. Un déterminant nul caractérise des vecteurs colinéaires ; l'orthogonalité se lit sur le produit scalaire xx′ + yy′ = 0.
✗ sin2x = 1 + cos 2x2  ·  cos2a = 1 + 2cos a2
✓ C'est le cosinus qui prend le signe plus, le sinus le signe moins. Et le numérateur contient cos 2a, pas 2cos a : en a = 0 la version fautive donnerait 32 au lieu de 1.
✗ Dans ABC non rectangle, a2 = b2 + c2  ·  a2 = b2 + c2 − 2bc cos B̂
✓ Pythagore n'est que le cas Â = 90° d'Al-Kashi ; partout ailleurs a2 = b2 + c2 − 2bc cos Â, avec l'angle opposé au côté a, compris entre b et c.
✗ sin x = 35, donc cos x = 45
✓ La relation fondamentale ne donne que le carré : cos x = ±45. Le signe vient du quadrant donné par l'énoncé ; sans intervalle, pas de réponse unique.
A SAVOIR PAR COEUR AVANT LE DEVOIR
  1. Angle orienté (u, v) : lu de u vers v, défini modulo 2π ; mesure principale dans ]−π ; π]. Chasles (u, v) + (v, w) = (u, w) et (v, u) = −(u, v).
  2. cos2x + sin2x = 1, M(cos x ; sin x), signe donné par le quadrant ; tan x = sin xcos x, 1 + tan2x = 1cos2x, période π. Angles associés (symétries du cercle) : cos pair, sin impair ; π − x ne change que le signe du cosinus ; π2 − x échange les deux.
  3. Angle de deux vecteurs : cos θ = xx′ + yy′‖u‖ ⋅ ‖v‖, sin θ = xy′ − yx′‖u‖ ⋅ ‖v‖ ; produit scalaire nul = orthogonaux, déterminant nul = colinéaires.
  4. Addition cos(a ± b) = cos a cos b ∓ sin a sin b, sin(a ± b) = sin a cos b ± cos a sin b  ·  duplication cos 2a = 2cos2a − 1 = 1 − 2sin2a, sin 2a = 2 sin a cos a  ·  linéarisation cos2a = 1 + cos 2a2, sin2a = 1 − cos 2a2.
  5. Equations : cos x = cos a ⇔ x = ±a + 2kπ  ·  sin x = sin a ⇔ x = a + 2kπ ou π − a + 2kπ  ·  tan x = tan a ⇔ x = a + kπ. Une inéquation donne un arc du cercle.
  6. Angle auxiliaire a cos x + b sin x = R cos(x − φ), R = √a2 + b2. Triangle : a2 = b2 + c2 − 2bc cos Â, aire 12bc sin Â, loi des sinus asin Â = bsin B̂ = csin Ĉ.
