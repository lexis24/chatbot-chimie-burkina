Nombres relatifs

Leçon 1 : découvrir les nombres relatifs · Leçon 2 : la droite graduée et l'opposé · Leçon 3 : comparer et ranger · Leçon 4 : additionner des nombres relatifs
L'ESSENTIEL

Leçon 1 : Découvrir les nombres relatifs

Un nombre relatif est un nombre précédé d'un signe. Si ce signe est + (par exemple +5), le nombre est positif : il est plus grand que zéro. Si ce signe est − (par exemple −3), le nombre est négatif : il est plus petit que zéro.

Le zéro n'est ni positif ni négatif : c'est le repère. On peut écrire +5 plus simplement 5, mais un nombre négatif garde toujours son signe −.

DISTANCE A ZERO
le nombre relatif écrit sans son signe
−7 et +7 ont la même distance à zéro : 7

Deux ensembles. Les entiers relatifs forment ℤ : …, −3, −2, −1, 0, +1, +2, +3, … Les décimaux relatifs forment 𝔻 : −2,5 ; +3,7 ; 0. Tout entier relatif est aussi un décimal relatif (−3 s'écrit −3,0).

Ecrire un relatif à partir d'une situation. Choisis le repère, le zéro (niveau de la mer, solde nul, départ) : au-dessus (gain, montée, chaleur) → positif ; en dessous (dette, descente, froid) → négatif.

Leçon 2 : La droite graduée et l'opposé

Droite graduée. On place le 0 (l'origine) et on choisit une unité de longueur, toujours la même ; on la reporte vers la droite pour les positifs, vers la gauche pour les négatifs. Le nombre qui correspond à un point est son abscisse : on écrit A(−2,5).

OPPOSE D'UN NOMBRE RELATIF
même distance au 0, de l'autre côté : on change le signe
opposé de +7 : −7  ·  de −3 : +3  ·  de 0 : 0  ·  (+5) + (−5) = 0

L'opposé de l'opposé redonne le nombre de départ. Deux nombres opposés ont une somme égale à 0 et sont symétriques par rapport au 0 : le 0 joue le rôle du miroir.

Placer un point d'abscisse donnée. Pars du 0 ; va vers la droite si le nombre est positif, vers la gauche s'il est négatif ; avance du nombre d'unités indiqué en comptant les graduations une à une ; marque une croix et écris le nom du point.

Leçon 3 : Comparer et ranger des nombres relatifs

REGLE DE COMPARAISON
sur la droite graduée, plus un nombre est à droite, plus il est grand

On en déduit trois règles pratiques :

  • tout nombre positif est plus grand que tout nombre négatif ;
  • le zéro est plus grand que tout négatif et plus petit que tout positif ;
  • entre deux négatifs, le plus grand est celui qui est le plus proche de zéro : −3 > −5.

Ranger. Ordre croissant : du plus petit (le plus à gauche) au plus grand (le plus à droite) ; ordre décroissant : l'inverse. Méthode sûre : d'abord tous les négatifs, du plus éloigné de zéro au plus proche, puis le zéro s'il y est, puis tous les positifs dans l'ordre habituel. Le symbole  <  pointe toujours vers le plus petit nombre.

Leçon 4 : Additionner des nombres relatifs

Sur la droite graduée : ajouter un positif, c'est avancer vers la droite ; ajouter un négatif, c'est reculer vers la gauche.

MEMES SIGNES
on additionne les distances à zéro, on garde le signe commun
(+4 200) + (+5 300) = +9 500     (−1 950) + (−2 500) = −4 450
SIGNES DIFFERENTS
on prend l'écart des distances à zéro (la plus petite ôtée de la plus grande) et on garde le signe du nombre le plus éloigné de zéro
(+4 200) + (−1 950) = +2 250

Un nombre plus son opposé donne 0 : (+5) + (−5) = 0, y compris pour les décimaux relatifs. Avec plusieurs nombres, on additionne de gauche à droite, deux par deux ; on peut aussi regrouper d'abord tous les positifs, puis tous les négatifs.

PIEGES ET ERREURS FREQUENTES
✗ −3 se lit « moins 3 » au sens d'enlever 3  ·  le zéro est positif, puisqu'il n'a pas de signe −
✓ Le signe − d'un nombre négatif n'est pas une soustraction : −3 est un nombre, situé 3 unités en dessous de zéro. Et le zéro n'est ni positif ni négatif : c'est le repère.
✗ L'opposé de −3 est −3  ·  l'abscisse de A est +3,5, donc son opposé est 3,5
✓ On change le signe, la valeur ne bouge pas : l'opposé de −3 est +3, et celui de +3,5 est −3,5 (même distance du 0, de l'autre côté).
✗ On peut changer la longueur de l'unité au milieu de la droite graduée
✓ L'unité reste la même d'un bout à l'autre, sinon les abscisses ne veulent plus rien dire.
✗ −13 > −2 parce que 13 > 2  ·  −5 > −3 parce que 5 > 3
✓ Entre deux négatifs, le plus grand est le plus proche de zéro : −2 > −13. Et −5 est à gauche de −3 sur la droite graduée, donc −5 < −3.
✗ Il n'y a aucun nombre entre −1 et 0  ·  le nombre −2,5 n'existe pas
✓ Il y en a une infinité, par exemple −0,5 ou −0,25 : les relatifs peuvent être décimaux, et −2,5 se place entre −3 et −2.
✗ (+8) + (−3) = +11  ·  (−6) + (−9) = −3
✓ Signes différents : on soustrait. Ecart 8 − 3 = 5 et signe du plus éloigné de 0 (le +8), donc +5. Signes identiques : on additionne. 6 + 9 = 15, donc −15 : deux pertes se cumulent.
A SAVOIR PAR COEUR AVANT LE DEVOIR
  1. Un relatif, c'est un signe et une valeur : positif > 0, négatif < 0 ; le zéro n'est ni positif ni négatif.
  2. La distance à zéro est le nombre écrit sans son signe : celle de −7 vaut 7.
  3. Droite graduée : 0 à l'origine, unité constante, positifs à droite, négatifs à gauche ; le nombre d'un point est son abscisse.
  4. Opposé : même distance au 0, signe contraire ; un nombre plus son opposé donne 0.
  5. Comparer : plus on va à droite, plus le nombre est grand ; négatif < 0 < positif ; entre deux négatifs, le plus proche de 0 est le plus grand.
  6. Addition, mêmes signes : on additionne les distances à zéro et on garde le signe commun.
  7. Addition, signes différents : on prend l'écart des distances à zéro et on garde le signe du nombre le plus éloigné de zéro.
