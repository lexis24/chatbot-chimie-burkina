Leçon 1 : Systèmes de deux équations à deux inconnues

SYSTEME LINEAIRE 2 × 2 : INCONNUES x ET y
{ax + by = ca′x + b′y = c′

a, b, c, a′, b′, c′ sont des nombres connus ; a′ et b′, « a prime » et « b prime », sont les coefficients de la seconde ligne.

  • Une équation est linéaire lorsque chaque inconnue y figure au premier degré seulement : ni x2, ni produit xy, ni √x, ni 1x.
  • Résoudre le système, c'est trouver tous les couples (x ; y) qui vérifient les deux équations à la fois ; un tel couple est une solution du système.

Les deux méthodes algébriques

  • Substitution. On exprime une inconnue en fonction de l'autre à partir d'une équation, on la remplace par cette expression, entre parenthèses, dans l'autre équation, on résout l'équation à une seule inconnue obtenue, puis on remonte pour la seconde inconnue.
  • Combinaison (élimination). On multiplie chaque équation par un nombre non nul bien choisi pour rendre opposés les coefficients d'une même inconnue, puis on additionne les deux équations membre à membre : cette inconnue disparaît.

Même résultat par les deux chemins : coefficient 1 ou −1 quelque part → substitution ; sinon combinaison, qui évite les fractions. On vérifie toujours le couple dans les deux équations de départ avant de conclure par (x ; y).

Nettoyer un système avant de le résoudre

  • Ranger : inconnues du même côté, dans le même ordre, nombres seuls à droite. 3x + 4 = 2y s'écrit 3x − 2y = −4 ; 4x + 3y − 11 = 0 s'écrit 4x + 3y = 11.
  • Chasser les dénominateurs : multiplier les deux membres par un multiple commun, chaque équation séparément : x2 + y3 = 4 donne, par 6, 3x + 2y = 24.
  • Supprimer les décimaux : 0,8x + 1,2y = 4 devient, par 10, 8x + 12y = 40, puis 2x + 3y = 10.
  • Simplifier une ligne par un diviseur commun à ses coefficients : l'opération est réversible, elle ne change pas les solutions.
  • Coefficients irrationnels : rien ne change ; le résultat se donne sous forme exacte.

Poser une inconnue auxiliaire

  • Un système non linéaire peut le devenir après un changement de nom : on résout dans les nouvelles inconnues, puis on revient aux anciennes.
  • X = 1x et Y = 1y changent 1x + 8y = 17 en X + 8Y = 17. Valeurs interdites x ≠ 0, y ≠ 0 ; retour par x = 1X et y = 1Y.
  • X = x2 : au retour, x2 = 4 donne deux valeurs, 2 et −2. X = |x| : une valeur absolue est positive, donc |x| = −1 n'a pas de solution.
  • Equation en produit : un produit est nul si et seulement si l'un au moins des facteurs est nul. La ligne (x + 2y)(x − y) = 0 se remplace par deux cas, x + 2y = 0 ou x − y = 0 : deux systèmes linéaires, dont on réunit les solutions.

Leçon 2 : Déterminant d'un système 2 × 2 : existence et unicité

DETERMINANT : SYSTEME RANGE ax + by = c ET a′x + b′y = c′
D = ab′ − a′b

On croise les coefficients : diagonale descendante a b′ moins diagonale montante a′ b. Seuls les coefficients des inconnues interviennent : c et c′ n'y figurent pas. C'est le déterminant des vecteurs u(a ; a′) et v(b ; b′) du chapitre 3 : D = 0 signifie qu'ils sont colinéaires, donc que les deux droites ont la même direction.

DéterminantSolutionsDroites
D ≠ 0une solution uniquesécantes
D = 0 et une équation multiple de l'autre, second membre comprisune infinité de solutionsconfondues
D = 0, sinonaucune solution : système incompatibleparallèles distinctes

Le déterminant indique s'il existe une solution unique ; il ne la calcule pas. On résout ensuite par substitution ou par combinaison, et l'on conclut par une phrase, jamais par le seul nombre D.

Les deux cas D = 0 se reconnaissent aussi pendant le calcul, quand les deux inconnues disparaissent ensemble : égalité fausse, du type 0 = 4, aucune solution ; égalité vraie, du type 0 = 0, une infinité.

Un coefficient désigné par une lettre

On calcule D en traitant la lettre comme un nombre, puis on résout D = 0. Pour {x − 3y = 42x + my = 1 : a = 1, b = −3, a′ = 2, b′ = m, donc D = m + 6. Si m ≠ −6 : solution unique. Si m = −6 : la seconde ligne devient 2x − 6y = 1 quand le double de la première donne 2x − 6y = 8 : droites parallèles distinctes, aucune solution.

Leçon 3 : Systèmes à trois (ou quatre) inconnues

SYSTEME 3 × 3 : LES INDICES NUMEROTENT LES LIGNES
{a1x + b1y + c1z = d1a2x + b2y + c2z = d2a3x + b3y + c3z = d3

Une solution est un triplet (x ; y ; z) vérifiant les trois équations à la fois ; quatre inconnues donnent un quadruplet. Le programme se limite à quatre inconnues au plus et n'étudie aucune méthode générale : on raisonne sur la forme de chaque système.

Elimination en cascade

  • Ranger les équations, une inconnue par colonne, et les numéroter (1), (2), (3).
  • Choisir à l'avance l'inconnue à éliminer, celle dont les coefficients sont les plus simples, et garder une équation comme référence.
  • Combiner la référence avec chacune des deux autres pour éliminer la même inconnue : il reste deux équations à deux inconnues. Ecrire en marge l'opération, du type « (2) moins deux fois (1) ».
  • Résoudre ce système 2 × 2, puis remonter : reporter les deux valeurs dans l'équation de référence pour la troisième inconnue, et vérifier le triplet dans les trois équations de départ.

Une combinaison ne remplace jamais les deux lignes à la fois : une équation reste intacte. Comme un système 2 × 2, un système à trois inconnues admet une solution unique, aucune solution, ou une infinité.

Leçon 4 : Résolution graphique des systèmes

Chaque équation ax + by = c, avec a et b non tous les deux nuls, se représente par une droite. Résoudre graphiquement, c'est chercher les points communs aux deux droites : sécantes, une solution, le point d'intersection ; parallèles distinctes, aucune solution ; confondues, une infinité de solutions, tous les points de la droite.

Tracé. Mettre chaque équation sous la forme y = mx + p quand c'est possible, calculer deux points par droite, de préférence à coordonnées entières, choisir une échelle laissant voir l'intersection, tracer à la règle, puis lire le couple.

La lecture graphique donne une valeur approchée : on la conjecture, puis on la confirme par le calcul. D compare les directions des droites, le dessin les montre.

Inéquation et demi-plan

Une droite partage le plan en deux demi-plans. Une inéquation y ≤ mx + p, ou ax + by ≤ c, a pour solutions tous les points de l'un d'eux ; la droite ax + by = c est la frontière.

  • Frontière incluse (≤ ou ≥) : trait plein. Frontière exclue (< ou >) : trait pointillé.
  • On teste un point hors de la frontière, l'origine O(0 ; 0) le plus souvent : si ses coordonnées vérifient l'inéquation, c'est le demi-plan qui le contient ; sinon, c'est l'autre. Si la frontière passe par O, tester (1 ; 0) ou (0 ; 1).
  • « Plus petit veut dire en dessous » n'est vrai que sous la forme y ≤ … : dès que y est multiplié par un nombre négatif, tout s'inverse.

Système d'inéquations

L'ensemble des solutions est l'intersection des demi-plans, la zone commune à toutes les inéquations, mise en évidence par des hachures ou une couleur. Elle est non bornée, ou bornée : c'est alors un polygone, dont les sommets sont les intersections des frontières.

  • Marche à suivre : ranger chaque inéquation, tracer sa frontière, tester un point pour chacune, hachurer les demi-plans retenus dans des directions différentes, colorier la zone commune, puis contrôler avec un point intérieur.
  • Lecture inverse : pour écrire le système d'une région donnée, lire l'équation de chaque frontière sur deux points à coordonnées entières, regarder le trait (plein → ≤, ≥ ; pointillé → <, >), puis tester un point intérieur.

Leçon 5 : Mise en équation et résolution de problèmes

  • Nommer les inconnues par une phrase complète, avec l'unité : « soit x le nombre de sacs de mil ».
  • Traduire chaque information chiffrée par une équation ou une inéquation : il faut en principe autant d'équations que d'inconnues.
  • Nettoyer le système, puis le résoudre par substitution, combinaison ou élimination en cascade.
  • Interpréter : phrase de réponse avec les unités, et contrôle de bon sens (signes, valeurs entières s'il s'agit de personnes ou d'objets, ordre de grandeur).

Les deux membres d'une équation s'expriment dans la même unité : ce seul contrôle repère beaucoup d'erreurs de traduction. Trois inconnues pour deux équations : une phrase de l'énoncé n'a pas été traduite.

Petit dictionnaire des traductions

  • « somme S » : x + y = S ; « différence d » : x − y = d ; « y est le double de x » : y = 2x ; « y dépasse x de 7 » : y = x + 7.
  • Achat : prix total = prix unitaire × quantité, puis on additionne les articles. Trajet : distance = vitesse × durée, donc durée = distance ÷ vitesse.
  • Mélange : une équation sur les masses, une sur les valeurs (masse × prix au kg). Placement : intérêt = capital × taux, taux en écriture décimale (10 % : 0,10).
  • Nombre de deux chiffres : 10a + b, et 10b + a en permutant les chiffres. Division euclidienne : N = q × d + r, avec 0 ≤ r < d. Consécutifs : n, n + 1, n + 2 ; impairs consécutifs : n, n + 2, n + 4.
  • Relevés physiques : deux mesures d'une même loi, comme u = e − r i, donnent deux équations dont les inconnues sont les coefficients e et r.
PIEGES ET ERREURS FREQUENTES
✗ « D = 0, donc pas de solution »  ·  « D ≠ 0, donc pas de solution »
✓ L'erreur la plus répandue du chapitre. D ≠ 0 entraîne au contraire une unique solution. Si D = 0, regarder les deux équations de plus près : proportionnelles second membre compris, droites confondues, une infinité de solutions ; sinon parallèles distinctes, aucune solution.
✗ Devant 3x + 4 = 2y, on écrit aussitôt a = 3 et b = 4
✓ On range avant de lire les coefficients : la première ligne devient 3x − 2y = −4, d'où b = −2. Lire un système non rangé, ou oublier un signe négatif, fausse D et toute la conclusion.
✗ 3x + y = 7 multipliée par 2 donne 6x + 2y = 7
✓ On multiplie les deux membres, sans oublier le nombre de droite : 6x + 2y = 14. Une égalité est une balance : doubler un seul plateau rompt l'équilibre. Même règle pour chasser les dénominateurs.
✗ (2 ; 1) est solution car il vérifie la première équation  ·  on s'arrête après avoir trouvé x
✓ Une solution vérifie toutes les équations : tout point d'une droite vérifie l'équation de cette droite, cela ne prouve rien sur l'autre. Et la réponse est un couple (x ; y), pas un nombre : la vérification s'écrit en deux temps.
✗ Frontière tracée en trait plein pour x + y < 4  ·  demi-plan hachuré au jugé
✓ Trait plein si la borne est incluse (≤, ≥), pointillé si elle est exclue (<, >). Et l'on teste un point hors frontière : un seul calcul, du type « 0 ≤ 2, c'est vrai », désigne le bon côté.
✗ Le point d'intersection est lu « environ 1,4 » et donné comme la solution  ·  réponse : « 3,5 personnes », « −200 FCFA »
✓ Une lecture graphique se conjecture, puis se confirme par le calcul, seul à donner la valeur exacte, sous forme de fraction si nécessaire. Et une solution sans sens dans le contexte (effectif non entier, prix négatif) doit être discutée : ou le calcul est à reprendre, ou le problème n'a pas de solution acceptable.
A SAVOIR PAR COEUR AVANT LE DEVOIR
  1. Un système 2 × 2 se résout par substitution (inconnue de coefficient 1 ou −1) ou par combinaison (coefficients opposés, puis addition). La solution est un couple, vérifié dans les deux équations.
  2. Nettoyer d'abord : ranger en ax + by = c, chasser dénominateurs et décimaux en multipliant les deux membres, simplifier.
  3. D = ab′ − a′b : diagonale descendante moins diagonale montante ; les seconds membres n'y figurent pas.
  4. D ≠ 0 : solution unique, droites sécantes. D = 0 : une infinité si les droites sont confondues (calcul finissant par 0 = 0), aucune si elles sont parallèles distinctes (0 = 3).
  5. Trois ou quatre inconnues : élimination en cascade, en supprimant la même inconnue dans les deux combinaisons ; vérifier le triplet dans toutes les équations.
  6. Graphique, équations : la solution est l'intersection des droites ; sécantes → une, parallèles distinctes → aucune, confondues → une infinité. Lecture approchée, à confirmer.
  7. Graphique, inéquations : demi-plan de frontière ax + by = c, trait plein si ≤ ou ≥, pointillé si < ou >, côté choisi par le test d'un point. Un système d'inéquations a pour solution la région commune.
  8. Inconnue auxiliaire X = 1x, x2 ou |x| : valeurs interdites, résoudre, puis revenir aux inconnues de départ. Problème : nommer avec l'unité, traduire, résoudre, interpréter.
