Leçon 1 : Polynômes : zéro et factorisation par (x − a)

  • Polynôme en x : expression anxn + an−1xn−1 + … + a1x + a0. Les nombres a0, …, an sont les coefficients.
  • Degré : le plus grand exposant dont le coefficient est non nul. Un coefficient nul se note 0, il ne supprime pas le rang.
  • Zéro (ou racine) de P : réel a tel que P(a) = 0. Les deux mots sont interchangeables.
THEOREME DE FACTORISATION : P polynôme, a réel
P(a) = 0 ⇔ il existe Q tel que P(x) = (x − a) Q(x)
avec deg Q = deg P − 1

Le facteur s'écrit toujours (x − a), avec un moins, quel que soit le signe de a : racine −2 → facteur (x + 2).

REGLE DU PRODUIT NUL
A × B = 0 ⇔ A = 0 ou B = 0

Factoriser par coefficients indéterminés

  1. Chercher une racine évidente : essayer 0, 1, −1, 2, −2, 3, −3.
  2. Poser P(x) = (x − a) Q(x) avec Q à coefficients inconnus (degré 3 → Q(x) = αx2 + βx + γ).
  3. Développer, ranger par puissances décroissantes, puis identifier les coefficients terme à terme.
  4. Contrôler : coefficient dominant de Q = celui de P ; terme constant de Q multiplié par (−a) redonne celui de P.
  5. Factoriser encore Q si possible, puis appliquer la règle du produit nul.

Leçon 2 : Trinôme : forme canonique et discriminant

Trinôme du second degré : ax2 + bx + c avec a ≠ 0 (a coefficient dominant, c terme constant). Si a = 0, l'expression est du premier degré : vérifier a dès qu'un coefficient contient une lettre.

FORME CANONIQUE : TOUT TRINOME S'ECRIT AINSI
ax2 + bx + c = a(x − α)2 + β
α = −b2a     β = f(α)

L'inconnue n'y figure qu'une seule fois. On en déduit l'extremum :

  • a > 0 : β est la plus petite valeur du trinôme, atteinte en x = α ;
  • a < 0 : β est la plus grande valeur, atteinte en x = α.
Pour β, aucune formule : on remplace x par α dans le trinôme de départ. Contrôle : aα2 + β = c.
DISCRIMINANT ET RACINES : pour a ≠ 0
Δ = b2 − 4ac
x1 = −b − √Δ2a     x2 = −b + √Δ2a  (si Δ > 0)
  • Δ > 0 : deux racines distinctes x1 et x2 ;
  • Δ = 0 : une seule racine, dite double, x0 = −b2a = α ;
  • Δ < 0 : aucune racine réelle.

Les deux racines sont symétriques par rapport à α : leur milieu vaut α. Quand Δ = 0, elles se confondent en α.

FACTORISATION DU TRINOME : NE JAMAIS OUBLIER a
Δ > 0 : ax2 + bx + c = a(x − x1)(x − x2)
Δ = 0 : ax2 + bx + c = a(x − x0)2

Si Δ < 0, le trinôme ne se factorise pas en facteurs du premier degré.

Condition sur le nombre de racines. « Deux racines distinctes » se traduit par Δ > 0 ; « une racine double » par Δ = 0 ; « aucune racine » par Δ < 0 ; « au moins une racine » par Δ ≥ 0. On calcule Δ en fonction du paramètre, puis on résout l'inéquation obtenue.

Leçon 3 : Résoudre une équation du second degré

Ranger d'abord sous la forme ax2 + bx + c = 0, tout d'un même côté. Quatre méthodes mènent au même résultat ; on choisit la plus rapide :

  • Racine évidente : factoriser par (x − a), puis produit nul.
  • Identité remarquable : x2 − k2 = 0 donne x = k ou x = −k ; (x − α)2 = 0 donne x = α.
  • Forme canonique : isoler le carré, (x − α)2 = −βa.
  • Discriminant : méthode générale, valable toujours.
Rédaction. L'ensemble des solutions s'écrit avec des accolades : S = {−3 ; 2}, jamais avec des crochets. Sans solution : S = ∅, et non « S = 0 ».
SOMME ET PRODUIT DES RACINES
S = x1 + x2 = −ba     P = x1x2 = ca
réciproque : t2 − S t + P = 0

Deux nombres de somme S et de produit P sont les racines de t2 − St + P = 0 ; ils existent si et seulement si S2 − 4P ≥ 0. Deux usages : contrôler deux racines calculées ; déduire la seconde racine d'une racine évidente par x2 = ca x1.

Equations qui se ramènent au second degré

  • Equation produit A(x) × B(x) = 0 : règle du produit nul.
  • Egalité de deux carrés : A2 = B2 ⇔ (A − B)(A + B) = 0.
  • Equation bicarrée ax4 + bx2 + c = 0 : poser X = x2, avec X ≥ 0, résoudre en X, revenir à x.
  • Equation quotient : chercher les valeurs interdites (celles qui annulent un dénominateur), puis même dénominateur ou produit en croix AB = CD ⇔ AD = BC, et écarter à la fin les solutions interdites.
  • Valeur absolue : |A| = k (avec k ≥ 0) ⇔ A = k ou A = −k ; |A| = |B| ⇔ A = B ou A = −B.
  • Changement d'inconnue : dès qu'une même quantité se répète, on la nomme X et l'on écrit aussitôt la condition sur X (X = x2, X = √x, X = |x| donnent X ≥ 0).

Résolution graphique. Les solutions de ax2 + bx + c = k sont les abscisses des points communs à la parabole et à la droite y = k. La lecture donne le nombre de solutions de façon sûre, leurs valeurs de façon approchée.

Leçon 4 : Signe du trinôme et inéquations

REGLES DE L'ORDRE : a, b, k réels
a ≤ b ⇒ a + k ≤ b + k
a ≤ b ⇒ ka ≤ kb si k > 0    ka ≥ kb si k < 0

Multiplier ou diviser par un nombre strictement négatif retourne le sens de l'inégalité ; ajouter, retrancher, ou multiplier par un nombre strictement positif le conservent.

Signe de ax + b (a ≠ 0) : l'expression s'annule en x = −ba, et elle est du signe de a après la racine, du signe contraire avant.

Signe du trinôme ax2 + bx + c

CasSigne du trinôme
Δ > 0
(x1 < x2)		signe de a à l'extérieur des racines, signe contraire entre elles ; nul en x1 et x2

A retenir en une phrase : « le trinôme est du signe de a, sauf entre les racines ». Aux racines il vaut 0 : elles sont incluses si l'inégalité est large, exclues si elle est stricte.

Tableau de signes et inéquations

  1. Ramener tout dans un seul membre pour comparer à 0, réduire au même dénominateur, repérer les valeurs interdites.
  2. Factoriser en facteurs du premier degré ; pour un trinôme seul, calculer Δ.
  3. Ranger dans l'ordre croissant les valeurs qui annulent chaque facteur : ce sont les colonnes du tableau, de −∞ à +∞.
  4. Remplir chaque ligne (« du signe de a après la racine ») avec un 0 à la valeur qui l'annule, puis multiplier les signes colonne par colonne : un nombre pair de « − » donne « + ».
  5. Une valeur interdite se marque par une double barre, jamais par un 0, et reste toujours exclue.
  6. Lire la réponse dans le sens demandé et écrire S avec des intervalles : crochet fermé sur un zéro si l'inégalité est large, ouvert sinon ; toujours ouvert sur une valeur interdite et sur les infinis. Contrôler avec un nombre de chaque intervalle.

Lecture graphique. Résoudre ax2 + bx + c > 0, c'est lire les abscisses des points de la parabole situés au-dessus de l'axe des abscisses ; « ≤ 0 » correspond aux points au-dessous, bornes comprises.

Leçon 5 : La parabole : représentation graphique

La courbe de y = ax2 + bx + c (a ≠ 0) est une parabole.

  • Sommet S(α ; β) : point le plus bas si a > 0, le plus haut si a < 0, avec α = −b2a et β la valeur du trinôme en α.
  • Axe de symétrie : la droite verticale d'équation x = α. Chaque point calculé en donne un second, son symétrique.
  • Orientation : tournée vers le haut si a > 0, vers le bas si a < 0.
CHANGEMENT D'ORIGINE AU SOMMET
X = x − α    Y = y − β  ⇒  Y = aX2

Toutes les paraboles de même coefficient a ont la même forme : une seule courbe, Y = aX2, posée ailleurs sur la feuille.

Intersections avec les axes

  • Avec l'axe des ordonnées : x = 0 donne le point (0 ; c), dont le symétrique a pour abscisse 2α.
  • Avec l'axe des abscisses : on résout ax2 + bx + c = 0. Deux points si Δ > 0, un seul (le sommet) si Δ = 0, aucun si Δ < 0.

Racines du trinôme, solutions de l'équation et abscisses des points où la courbe traverse l'axe horizontal sont trois noms pour la même chose. Tracé : sens, sommet, axe en pointillés, racines, ordonnée à l'origine et sa symétrique, puis un trait régulier arrondi au sommet.

PIEGES ET ERREURS FREQUENTES
✗ x2 = 3x donc x = 3  ·  x2 = 9 donc x = 3
✓ On ne divise jamais par x : la solution x = 0 disparaît. On ramène tout d'un côté et l'on factorise : x(x − 3) = 0, donc x = 0 ou x = 3. De même x2 = 9 donne x = 3 ou x = −3.
✗ Pour x2 − 4x + 3 : Δ = −42 − 12 = −28
✓ Le carré d'un nombre négatif est positif : b = −4 donc b2 = (−4)2 = 16 et Δ = 16 − 12 = 4. Surveiller aussi le signe de c : pour 2x2 − x − 6, Δ = 1 + 48, et non 1 − 48.
✗ 2x2 − x − 6 = (x − x1)(x − x2)  ·  (x + 3)2 = x2 + 9
✓ Le facteur a est indispensable : ici 2(x − x1)(x − x2), sinon le coefficient de x2 vaut 1. Et la puissance ne se distribue pas sur une somme : (x + 3)2 = x2 + 6x + 9.
✗ x4 + 3x2 − 4 = 0 : X = 1 ou X = −4, donc x = ±1 et x = ±2
✓ X = x2 ne peut pas être négative : on écarte X = −4, car x2 = −4 n'a aucune solution. Il reste X = 1, d'où S = {−1 ; 1}. La condition sur X s'écrit au moment du changement d'inconnue.
✗ −3x ≤ −6 donc x ≤ 2
✓ Diviser par −3 retourne le sens : x ≥ 2. Contrôle avec x = 5 : −15 ≤ −6, exact ; avec x = 0 la réponse fautive donnerait 0 ≤ −6.
✗ x2 < 4 donc x < 2  ·  (x − 1)(x − 2) > 0 donc les deux facteurs sont positifs
✓ Une inéquation du second degré se ramène à 0 puis se factorise : x2 − 4 < 0, soit (x − 2)(x + 2) < 0, donc −2 < x < 2. Un produit est aussi positif quand les deux facteurs sont négatifs : il faut un tableau de signes.
✗ « Δ < 0, donc pas de solution »  ·  « un trinôme est toujours positif »
✓ Δ < 0 signifie aucune racine, donc un signe constant : c'est une information, pas une absence d'information. Le trinôme n'est positif partout que si Δ < 0 et a > 0. Ainsi −5x2 + x − 1 < 0 a pour solution ℝ tout entier.
✗ Dans x − 1x + 2 ≥ 0, écrire S = ]−∞ ; −2]∪[1 ; +∞[  ·  toute parabole a son sommet en (0 ; 0)
✓ x = −2 est une valeur interdite : crochet ouvert en −2 et fermé en 1, soit S = ]−∞ ; −2[∪[1 ; +∞[. Et le sommet n'est en (0 ; 0) que pour y = ax2 : sinon il est en S(α ; β).
A SAVOIR PAR COEUR AVANT LE DEVOIR
  1. Si P(a) = 0, alors P(x) = (x − a)Q(x), avec deg Q inférieur d'une unité. Produit nul : A×B = 0 ⇔ A = 0 ou B = 0.
  2. Forme canonique a(x − α)2 + β avec α = −b2a et β = f(α) ; β est le minimum si a > 0, le maximum si a < 0.
  3. Δ = b2 − 4ac : deux racines −b − √Δ2a et −b + √Δ2a si Δ > 0 ; une racine double −b2a si Δ = 0 ; aucune si Δ < 0.
  4. Si Δ ≥ 0 : ax2 + bx + c = a(x − x1)(x − x2). Le facteur a ne s'oublie pas.
  5. Somme et produit : x1 + x2 = −ba, x1x2 = ca ; réciproquement, deux nombres de somme S et de produit P sont racines de t2 − St + P = 0, s'ils existent (S2 − 4P ≥ 0).
  6. Identités : (a + b)2 = a2 + 2ab + b2 ; (a − b)2 = a2 − 2ab + b2 ; a2 − b2 = (a − b)(a + b).
  7. Signe : « du signe de a, sauf entre les racines ». Multiplier ou diviser une inégalité par un nombre négatif retourne le sens. Une valeur interdite est toujours exclue de S.
  8. Parabole y = ax2 + bx + c : sommet S(α ; β), axe x = α, vers le haut si a > 0, vers le bas si a < 0 ; elle coupe l'axe des abscisses aux racines, et l'axe des ordonnées en (0 ; c).
