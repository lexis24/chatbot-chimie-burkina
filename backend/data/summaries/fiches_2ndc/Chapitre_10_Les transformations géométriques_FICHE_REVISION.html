L'ESSENTIEL

Leçon 1 : Translation, symétrie centrale, symétrie orthogonale

Une transformation du plan associe à tout point M un unique point M′, et tout point du plan est l'image d'un point et d'un seul. M′ est l'image de M, M l'antécédent de M′ ; on écrit M′ = f(M). Un point tel que f(M) = M est un point invariant.

LES TROIS TRANSFORMATIONS CONNUES
Translation de vecteur u→ : MM′→ = u→
Symétrie centrale de centre O : O milieu de [MM′]
Symétrie orthogonale d'axe (D) : (D) médiatrice de [MM′]
  • Pour la symétrie d'axe (D), la médiatrice ne concerne que les points M n'appartenant pas à (D) : tout point de (D) est sa propre image.
  • Points invariants : une translation de vecteur non nul n'en a aucun ; une symétrie centrale en a un seul, le centre O ; une symétrie orthogonale en a toute une droite, l'axe (D).
  • La symétrie centrale s'écrit aussi en vecteurs : OM′→ = −OM→.
  • Construire une figure image : ne traite que les points clés (sommets, centre et un point d'un cercle), puis relie les images dans le même ordre. Pour l'axe (D) : trace la perpendiculaire à (D) passant par M, de pied H, et reporte MH de l'autre côté de H. Contrôle : un côté et son image ont la même longueur.

Isométries

ISOMETRIE : A′ ET B′ IMAGES DE A ET B
A′B′ = AB

Translation, symétrie centrale, symétrie orthogonale et rotation sont des isométries : elles conservent les distances. Elles conservent donc aussi les longueurs, périmètres, aires, angles, l'alignement, le parallélisme, l'orthogonalité, les milieux et les barycentres : la figure image a la même taille et la même forme que la figure de départ.

Leçon 2 : L'homothétie

DEFINITION : CENTRE O, RAPPORT k REEL NON NUL
h(O ; k) : M ↦ M′ tel que OM′→ = k OM→

Le centre O est invariant, et c'est le seul dès que k ≠ 1. Le rapport k ne peut pas être nul.

  • k > 0 : M′ est sur la demi-droite [OM), du même côté du centre ; k < 0 : M′ est de l'autre côté de O.
  • |k| > 1 : la figure est agrandie ; |k| < 1 : elle est réduite ; |k| = 1 : elle garde sa taille.
  • Cas particuliers : h(O ; 1) est l'identité ; h(O ; −1) est la symétrie centrale de centre O.

Ce qu'elle conserve, ce qu'elle change

Conserve : l'alignement, le parallélisme, l'orthogonalité, les angles, les milieux et les barycentres. L'image d'une droite est une droite parallèle à la première.

EFFET SUR LES GRANDEURS
A′B′ = |k| × AB     aire′ = k2 × aire
Thalès. Si A′ et B′ sont les images de A et B par h(O ; k), alors (A′B′) et (AB) sont parallèles et OA′OA = OB′OB = A′B′AB = |k|.

Traduire un énoncé. « B est l'image de A par l'homothétie de centre I et de rapport k » s'écrit IB→ = k IA→ : le centre est l'origine des deux vecteurs.

Homothétie dans un repère

CENTRE O1(x1 ; y1), RAPPORT k
x′ = x1 + k(x − x1)    y′ = y1 + k(y − y1)
  • Si le centre est l'origine : x′ = kx et y′ = ky.
  • Antécédent d'un point M′ connu : on applique l'homothétie de même centre et de rapport 1k.
  • Construire M′ : sur la droite (OM), du côté donné par le signe de k, à la distance |k| × OM du centre. Contrôle : deux côtés qui se correspondent sont parallèles.

Leçon 3 : La rotation

DEFINITION : CENTRE O, ANGLE ORIENTE α, POUR M ≠ O
r(O ; α) : OM′ = OM   et   (OM→ , OM′→) = α

Le centre O est invariant : son image est lui-même. Les deux conditions sont indispensables ; ensemble, elles déterminent M′ de façon unique.

  • Le plan est orienté dans le sens direct, celui qui est contraire aux aiguilles d'une montre.
  • α > 0 : rotation dans le sens direct ; α < 0 : rotation dans le sens indirect.
  • r(O ; π2) est le quart de tour direct, r(O ; −π2) le quart de tour indirect : les images sont différentes.

La rotation est une isométrie : elle conserve les distances, les longueurs, les périmètres, les aires, les angles, l'alignement, le parallélisme, l'orthogonalité et les barycentres. La figure a la même taille et la même forme ; elle a seulement pivoté, elle n'est pas retournée.

  • Images : une droite a pour image une droite ; un segment, un segment de même longueur ; un cercle de centre I et de rayon r, le cercle de centre l'image de I et de même rayon r.
  • Cas particuliers : l'angle 0 donne l'identité ; l'angle π (soit 180°) donne la symétrie centrale de centre O.
  • Elle conserve le parallélisme mais non la direction : l'image d'une droite a pivoté de α, elle n'est en général pas parallèle à cette droite.
  • Construire M′ : à partir de la demi-droite [OM), trace au rapporteur un angle de mesure |α|, dans le sens indiqué par le signe de α, puis reporte au compas la longueur OM sur la demi-droite obtenue.
Retrouver le centre et l'angle connaissant A, B et leurs images : O est le point d'intersection des médiatrices de [AA′] et de [BB′], car OA′ = OA et OB′ = OB ; l'angle est ensuite l'angle orienté (OA→ , OA′→).

Leçon 4 : Utilisation des transformations

  • Construire une figure : frises, motifs, agrandissements (homothétie), figures tournées (rotation).
  • Démontrer une propriété : on transporte une configuration par une transformation qui conserve ce qui nous intéresse.
  • Déterminer un ensemble de points : l'image d'une figure simple est une figure simple, dont on précise les éléments caractéristiques.
Règle d'or. On choisit toujours la transformation qui conserve la propriété cherchée : longueurs → isométrie ; formes et directions → homothétie ; orientation → rotation.

Images des figures usuelles

  • Homothétie de rapport k : une droite a pour image une droite parallèle (confondue avec elle si la droite passe par le centre) ; un cercle de centre I et de rayon r a pour image le cercle de centre l'image de I et de rayon |k| × r.
  • Isométrie (translation, symétries, rotation) : une droite a pour image une droite ; un cercle, un cercle de même rayon.
  • Dans tous les cas : segment → segment, triangle → triangle, angle → angle de même mesure.

Enchaîner deux transformations

Aucune étude systématique n'est exigée ; deux observations suffisent :

  • deux symétries orthogonales d'axes sécants en O donnent une rotation de centre O, d'angle le double de l'angle des deux axes ;
  • deux symétries orthogonales d'axes parallèles donnent une translation.
PIEGES ET ERREURS FREQUENTES
✗ Par une homothétie de rapport k, les aires sont multipliées par k
✓ Les longueurs sont multipliées par |k|, les aires par k2, car on agrandit dans les deux directions. Un rapport 3 multiplie l'aire par 9, pas par 3 : 4 hectares en donnent 36. Inversement, une aire multipliée par 9 vient d'un rapport 3.
✗ Homothétie de rapport −2 : les longueurs sont multipliées par −2
✓ Une longueur est toujours positive : elle est multipliée par |−2| = 2. Le nombre |k| commande la taille, le signe de k commande seulement le côté du centre où atterrit la figure.
✗ La translation agrandit la figure  ·  l'homothétie de rapport 3 garde les longueurs
✓ Exactement l'inverse. Translation, symétries et rotation sont des isométries : un côté de 5 cm reste un côté de 5 cm. L'homothétie, elle, multiplie les longueurs par |k|.
✗ La rotation d'angle π est une symétrie axiale
✓ C'est la symétrie centrale de centre O. Une rotation est définie par un centre et un angle, une symétrie axiale par une droite : la rotation ne retourne jamais la figure, la symétrie axiale la retourne toujours.
✗ L'image d'une droite par une homothétie est une droite sécante à la première
✓ C'est une droite parallèle, et distincte en général : les deux droites ne se confondent que si (D) passe par le centre. Ne transporte pas ce résultat à la rotation : d'angle non nul, elle fait pivoter la droite, qui n'est plus parallèle.
✗ Le symétrique de M(3 ; 2) par rapport à l'axe des abscisses est (−3 ; 2)
✓ C'est (3 ; −2) : l'axe des abscisses ne change que le signe de l'ordonnée. Par rapport à l'origine, les deux signes changent : (−3 ; −2). Un point donné, c'est une symétrie centrale ; une droite, une symétrie orthogonale.
✗ r(O ; π3) et r(O ; −π3) donnent la même image
✓ Le signe donne le sens : les deux images sont différentes, symétriques par rapport à (OM). Lis le signe avant de poser le rapporteur ; le sens positif tourne à l'inverse des aiguilles d'une montre.
✗ « B est l'image de A par h(I ; k) » traduit par AB→ = k AI→
✓ Le centre est l'origine des deux vecteurs : IB→ = k IA→. De même, dans un enchaînement, la seconde transformation s'applique aux images, jamais aux points de départ.
A SAVOIR PAR COEUR AVANT LE DEVOIR
  1. Une transformation associe à tout point M un unique point M′ ; un point invariant vérifie f(M) = M. Aucun pour une translation de vecteur non nul, le centre seul pour une symétrie centrale, toute la droite pour une symétrie d'axe.
  2. Translation : MM′→ = u→. Symétrie centrale : O milieu de [MM′]. Symétrie axiale : (D) médiatrice de [MM′]. Rotation : OM′ = OM et (OM→ , OM′→) = α.
  3. Ces quatre transformations sont des isométries : A′B′ = AB, et elles conservent aires, angles, alignement, parallélisme, milieux et barycentres.
  4. Homothétie h(O ; k), k ≠ 0 : OM′→ = k OM→. Elle conserve la forme mais longueurs × |k| et aires × k2. h(O ; −1) et r(O ; π) sont la symétrie centrale de centre O.
  5. Images : par une homothétie, une droite donne une droite parallèle et un cercle un cercle de rayon |k| × r ; par une isométrie, une droite donne une droite et un cercle un cercle de même rayon.
  6. Dans un repère : translation de u→(a ; b) → (x + a ; y + b) ; centre O → (−x ; −y) ; axe des abscisses → (x ; −y) ; axe des ordonnées → (−x ; y) ; quart de tour direct → (−y ; x).
  7. Homothétie de centre O1(x1 ; y1) : x′ = x1 + k(x − x1) et y′ = y1 + k(y − y1).
  8. Le centre d'une rotation est l'intersection des médiatrices de [AA′] et [BB′]. On choisit toujours la transformation qui conserve la propriété cherchée.
