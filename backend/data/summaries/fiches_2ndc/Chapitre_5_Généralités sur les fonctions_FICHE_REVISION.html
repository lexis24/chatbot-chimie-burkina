L'ESSENTIEL

Leçon 1 : Décrire une fonction : domaine, image, antécédent

Une fonction f d'une variable réelle est un procédé qui, à chaque nombre x, associe au plus un nombre noté f(x). On écrit f : x ↦ f(x), et ↦ se lit « a pour image ».

  • x est la variable, f(x) l'image de x par f. « Au plus un » : jamais deux images pour un même x, mais parfois aucune.
  • f désigne la règle de calcul, f(x) le nombre obtenu : on dit « la fonction f », jamais « la fonction f(x) ».
  • Egalité de deux fonctions : même ensemble de définition et mêmes images en tout point.

Modes de description et courbe

Une fonction se donne par une formule, un tableau de valeurs, une courbe ou une phrase. La courbe représentative de f, notée (Cf), est l'ensemble des points de coordonnées (x ; f(x)) lorsque x parcourt Df.

UN POINT EST-IL SUR LA COURBE ?
M(a ; b) ∈ (Cf) ⇔ a ∈ Df  et  b = f(a)

Vocabulaire : « la courbe passe par (−1 ; 3) » signifie f(−1) = 3 ; « elle coupe l'axe des abscisses en a » signifie f(a) = 0 ; « elle coupe l'axe des ordonnées en b » signifie f(0) = b.

Test de la droite verticale. Un tracé qu'une même verticale rencontre deux fois ou plus n'est pas la courbe d'une fonction : un cercle échoue, une parabole réussit.

Ensemble de définition

DEFINITION : LES DEUX SEULS OBSTACLES DU PROGRAMME
Df = ensemble des x pour lesquels f(x) existe
quotient : dénominateur ≠ 0     racine : contenu du radical ≥ 0
  • Ni quotient ni radical : aucune contrainte, Df = ℝ.
  • La réponse s'écrit en intervalle ou en réunion d'intervalles : x ≠ 3 s'écrit ℝ∖{3}, ou ]−∞ ; 3[ ∪ ]3 ; +∞[.
  • Plusieurs conditions : elles valent toutes en même temps, on prend l'intersection, jamais la réunion.
  • Df est la première question à traiter : image, antécédent et parité en dépendent.

Image et antécédent

DEUX NOTIONS INVERSES L'UNE DE L'AUTRE
image de a : f(a), on remplace x par a → un calcul
antécédent de b : tout x tel que f(x) = b → une équation
  • Tout a de Df a une seule image ; un nombre b peut avoir un, plusieurs ou aucun antécédent, et il faut les donner tous.
  • L'ensemble image de f est l'ensemble de toutes les images f(x), x parcourant Df.
  • L'image se calcule en partant de l'axe horizontal ; l'antécédent se cherche en partant de l'axe vertical, et chaque solution de f(x) = b se vérifie dans Df.

Leçon 2 : Lecture d'un graphique : image réciproque et extrema

  • Lire f(a) : de a sur l'axe des abscisses, aller verticalement jusqu'à la courbe, puis horizontalement jusqu'à l'axe des ordonnées. Une verticale ne coupe la courbe qu'une fois.
  • Lire les antécédents de b : de b sur l'axe des ordonnées, suivre l'horizontale y = b et relever l'abscisse de chaque point d'intersection ; cette horizontale peut couper la courbe zéro, une, deux fois ou davantage.

Image et image réciproque d'un intervalle

DEUX ENSEMBLES A NE JAMAIS ECHANGER
f([a ; b]) = toutes les images f(x), x ∈ [a ; b] → des ordonnées
f−1([c ; d]) = tous les x tels que f(x) ∈ [c ; d] → des abscisses
  • Si f est croissante sur [a ; b] : f([a ; b]) = [f(a) ; f(b)] ; si elle est décroissante, les bornes s'échangent : [f(b) ; f(a)].
  • L'image est l'ombre portée sur l'axe vertical du morceau de courbe situé au-dessus de [a ; b] ; l'image réciproque est l'ombre portée sur l'axe horizontal de la portion de courbe située dans la bande entre y = c et y = d, et elle peut être formée de plusieurs morceaux séparés.

Maximum et minimum sur un intervalle I

DEUX CONDITIONS : AUCUNE NE PEUT MANQUER
maximum M : f(x) ≤ M pour tout x de I, et f(x0) = M pour au moins un x0 de I
minimum m : f(x) ≥ m pour tout x de I, et f(x0) = m pour au moins un x0 de I
  • La première condition est une barrière, la seconde dit qu'elle est atteinte. Une barrière non atteinte n'est qu'un majorant, ou un minorant.
  • Le maximum et le minimum sont des ordonnées ; l'abscisse x0 où l'extremum est atteint est un autre nombre, à préciser séparément.
  • Preuve par le calcul : partir d'un morceau de signe sûr (carré, racine, valeur absolue, toujours ≥ 0), transformer l'inégalité jusqu'à f(x) en notant que multiplier par un nombre négatif renverse le sens, puis chercher le x qui annule ce morceau.

Leçon 3 : Sens de variation d'une fonction

DEFINITIONS : POUR TOUS a, b DE I AVEC a < b
croissante : f(a) ≤ f(b)    strictement croissante : f(a) < f(b)
décroissante : f(a) ≥ f(b)    strictement décroissante : f(a) > f(b)
constante : f(x) garde la même valeur pour tout x de I
  • Croissante = conserve l'ordre ; décroissante = inverse l'ordre ; croissante ou décroissante sur I : monotone sur I. La propriété vaut pour tous les couples de I, pas pour un couple choisi.
  • Le sens de variation est toujours relatif à un intervalle : on l'indique, et on ne recolle jamais deux intervalles de sens contraires.
  • Une fonction constante est croissante et décroissante au sens large, mais n'est strictement ni l'une ni l'autre.

Etudier et exploiter la variation

Par la différence. Prendre a < b quelconques dans I, avec des lettres ; calculer f(b) − f(a) et factoriser pour faire apparaître b − a, qui est positif ; conclure sur le signe : positif donne strictement croissante, négatif strictement décroissante.

COMPARER SANS CALCULER : a < b DANS LE MEME INTERVALLE DE MONOTONIE I
f croissante sur I ⇒ f(a) ≤ f(b)
f décroissante sur I ⇒ f(a) ≥ f(b)

Hors d'un même intervalle de monotonie, on ne conclut rien ainsi : il faut calculer.

Leçon 4 : Parité d'une fonction

ETAPE OBLIGATOIRE : DOMAINE SYMETRIQUE PAR RAPPORT A 0
pour tout x de Df, −x appartient aussi à Df

Symétriques : ℝ, [−5 ; 5], ℝ*, ℝ∖{−2 ; 2}. Non symétriques : [0 ; +∞[, [−1 ; 4], ℝ∖{6}. Si Df n'est pas symétrique, f n'est ni paire ni impaire : le calcul de f(−x) est inutile et l'exercice est terminé.

Fonction paire, fonction impaire

DEFINITIONS : Df SYMETRIQUE ET, POUR TOUT x DE Df
f paire : f(−x) = f(x) → symétrie par rapport à l'axe des ordonnées
f impaire : f(−x) = −f(x) → symétrie par rapport à l'origine
  • Calcul de f(−x) : mettre −x entre parenthèses, avec (−x)2 = x2, (−x)3 = −x3, |−x| = |x|. L'égalité doit valoir pour tout x, jamais sur des essais numériques.
  • x ↦ x2 et x ↦ x4 sont paires ; x ↦ x et x ↦ x3 sont impaires, d'où les mots « pair » et « impair ».
  • Ni paire ni impaire est le cas le plus fréquent : c'est une réponse valable, justifiée par un contre-exemple chiffré.
  • f impaire et définie en 0 donne f(0) = −f(0), donc f(0) = 0 : la courbe passe par l'origine.
Economie de travail. On étudie et on trace pour x ≥ 0, puis on complète : à chaque point M(x ; y) on ajoute M′(−x ; y) si f est paire (pli le long de l'axe), et M′(−x ; −y) si f est impaire (demi-tour autour de O) : là, on change les deux signes.

Leçon 5 : Périodicité d'une fonction

DEFINITION : PERIODE T > 0, POUR TOUT x DE Df
x + T ∈ Df  et  f(x + T) = f(x)
d'où f(x + kT) = f(x) pour tout entier k, positif ou négatif
  • La première condition est indispensable : parler de f(x + T) n'a de sens que si ce nombre a une image.
  • Le motif, portion de courbe sur un intervalle de longueur T, se reproduit identique par translation horizontale de T, 2T, 3T…, vers la droite comme vers la gauche.
  • Il suffit donc de connaître f sur un seul intervalle de longueur T, choisi d'ordinaire égal à [0 ; T[.
  • Calculer f(a) : ajouter ou retrancher T autant de fois qu'il le faut pour ramener a dans le motif, en écrivant chaque étape, puis appliquer la formule connue.
PIEGES ET ERREURS FREQUENTES
✗ f(2) = 5, donc 2 est l'antécédent de 5
✓ 2 a pour image 5. Un antécédent de 5 est une solution de f(x) = 5, et il peut y en avoir plusieurs, ou aucun. L'image se calcule, l'antécédent se cherche.
✗ f(x) = √x − 3 est définie pour x ≥ 0  ·  f(x) = 1x − 2 est définie pour x ≠ 0
✓ La condition porte sur ce qui est écrit sous le radical ou au dénominateur : x − 3 ≥ 0 donne x ≥ 3, et x − 2 ≠ 0 donne x ≠ 2.
✗ f−1([c ; d]) se calcule en prenant 1f  ·  c'est un ensemble d'ordonnées
✓ f−1 n'est pas un inverse et aucune division n'intervient : c'est l'ensemble des abscisses x telles que f(x) ∈ [c ; d]. C'est l'image d'un intervalle qui est un ensemble d'ordonnées.
✗ f(x) ≤ 6 pour tout x, donc 6 est le maximum de f
✓ Il manque la seconde condition : 6 doit être atteinte en un x0 de l'intervalle, sans quoi ce n'est qu'un majorant. Ainsi x ↦ −x2 vérifie f(x) ≤ 7, mais son maximum vaut 0, atteint en 0.
✗ −3 < 1 et la fonction carré est croissante, donc 9 < 1
✓ « La fonction carré est croissante » sans intervalle est faux : x ↦ x2 décroît sur ]−∞ ; 0] et croît sur [0 ; +∞[. Ici −3 et 1 ne sont pas dans le même intervalle de monotonie : on ne conclut rien, et en fait 9 > 1.
✗ f(−x) = f(x), donc f est impaire  ·  f(x) = √x est paire
✓ f(−x) = f(x) définit une fonction paire ; impaire signifie f(−x) = −f(x). Et la parité exige d'abord un domaine symétrique : sur [0 ; +∞[, −4 n'a pas d'image, donc « ni paire ni impaire ».
✗ f(0) = f(4), donc f est périodique de période 4
✓ Une égalité en une valeur ne prouve rien : deux valeurs égales peuvent se produire par hasard. Il faut f(x + 4) = f(x) pour tout x. Une période est de plus strictement positive : jamais 0, jamais −3.
A SAVOIR PAR COEUR AVANT LE DEVOIR
  1. Df rassemble les x pour lesquels f(x) existe : contenu du radical ≥ 0, dénominateur ≠ 0. Réponse en intervalle(s), et intersection si plusieurs conditions.
  2. L'image de a est f(a), elle se calcule et elle est unique ; un antécédent de b est une solution de f(x) = b, et il peut y en avoir un, plusieurs ou aucun.
  3. M(a ; b) ∈ (Cf) si et seulement si a ∈ Df et b = f(a) ; « coupe l'axe des abscisses en a » signifie f(a) = 0.
  4. Sur une courbe : l'image d'un intervalle est un ensemble d'ordonnées, l'image réciproque f−1([c ; d]) un ensemble d'abscisses.
  5. Maximum M sur I : f(x) ≤ M pour tout x de I et M atteinte en un x0 de I ; sans cela, M n'est qu'un majorant. Idem pour le minimum avec ≥.
  6. Croissante conserve l'ordre, décroissante l'inverse, toujours sur un intervalle précisé : on compare deux images sans les calculer si les deux nombres sont dans le même intervalle de monotonie.
  7. Parité : Df symétrique d'abord. Paire : f(−x) = f(x), symétrie par rapport à l'axe des ordonnées. Impaire : f(−x) = −f(x), symétrie par rapport à l'origine, avec f(0) = 0 si 0 est dans le domaine.
  8. Périodique de période T (T > 0) : x + T ∈ Df et f(x + T) = f(x) pour tout x ; alors f(x + kT) = f(x) et le motif se répète par translation de T.
