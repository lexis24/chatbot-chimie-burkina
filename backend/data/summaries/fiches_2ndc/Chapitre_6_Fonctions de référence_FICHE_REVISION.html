Leçon 1 : Fonctions affines et proportionnalité

DEFINITION : a ET b REELS FIXES
f affine sur ℝ :  f(x) = ax + b
  • a est le coefficient directeur, b l'ordonnée à l'origine, car f(0) = b.
  • Linéaire si b = 0 : f(x) = ax. C'est le seul cas de proportionnalité, de coefficient a. Constante si a = 0.
  • Toute fonction linéaire est affine ; une fonction affine n'est linéaire que si son ordonnée à l'origine est nulle.
  • Courbe : une droite, donc deux points suffisent. Elle coupe l'axe des ordonnées en (0 ; b) et passe par l'origine si et seulement si b = 0. Quand x augmente de 1, l'ordonnée augmente de a.
  • Variation sur ℝ : strictement croissante si a > 0, strictement décroissante si a < 0, constante si a = 0.

Proportionnalité et détermination

Il y a proportionnalité lorsque l'une des trois conditions équivalentes est remplie : on passe de x à y en multipliant toujours par le même nombre a ; la fonction s'écrit y = ax, sans terme constant ; la droite passe par l'origine. Test : les quotients yx (x ≠ 0) sont tous égaux, et ce quotient commun est le coefficient.

DEUX IMAGES CONNUES : f(x1) = y1, f(x2) = y2, x1 ≠ x2
a = y2 − y1x2 − x1

On obtient b en remplaçant x et f(x) par l'un des couples, puis on vérifie avec l'autre. Ce quotient est le taux de variation de f ; pour une fonction affine seulement, il ne dépend pas des deux points choisis.

Fonctions affines par intervalles

Le domaine se découpe en plusieurs intervalles, sur chacun desquels la fonction est donnée par une expression affine, en général différente d'un intervalle à l'autre : la courbe est faite de morceaux de droites (tarifs par tranches).

  • Pour calculer f(c) : chercher d'abord l'intervalle qui contient c, puis appliquer la formule de cet intervalle, et elle seule. Surveiller les bornes : le symbole ≥ ou > décide.
  • Le sens de variation se donne sur chaque intervalle, jamais sur ℝ tout entier. Aux bornes, contrôler le recollement : si les deux formules y donnent la même valeur, la courbe est d'un seul tenant.

Leçon 2 : Fonctions x ↦ x2 et x ↦ x3

Carré f(x) = x2Cube g(x) = x3
Définie sur ℝ. (−x)2 = x2 : paire, courbe symétrique par rapport à l'axe des ordonnées ; c'est une parabole. Définie sur ℝ. (−x)3 = −x3 : impaire, courbe symétrique par rapport à l'origine.
x2 ≥ 0 pour tout réel x, et x2 = 0 seulement pour x = 0. Le cube garde le signe de x : négatif si x < 0, nul en 0, positif si x > 0.
Strictement décroissante sur ]−∞ ; 0], strictement croissante sur [0 ; +∞[ : minimum 0 atteint en 0. Strictement croissante sur ℝ tout entier : ni maximum ni minimum.
COMPARER : CONSEQUENCE DU SENS DE VARIATION
0 ≤ u < v donne u2 < v2    u < v ≤ 0 donne u2 > v2
u < v donne u3 < v3, quels que soient les signes

Comportement numérique, lu sur un tableau de valeurs et sans aucun calcul de limite : quand |x| devient grand, x2 et |x3| deviennent très grands, bien plus vite que x ; quand x est proche de 0, ils sont plus petits que x. Le nombre 1 est la frontière entre les deux comportements.

Leçon 3 : Fonctions x ↦ 1x et x ↦ √x

Inverse f(x) = 1xRacine carrée g(x) = √x
La division par 0 est impossible : 0 est une valeur interdite, le domaine est ℝ* = ]−∞ ; 0[ ∪ ]0 ; +∞[. √x est le nombre positif dont le carré vaut x ; un carré n'étant jamais strictement négatif, le domaine est [0 ; +∞[.
1−x = −1x : impaire, symétrique par rapport à l'origine ; sa courbe est une hyperbole à deux branches séparées. Ni paire ni impaire : le domaine n'est pas symétrique par rapport à 0, puisque √4 existe alors que √−4 n'existe pas.
L'inverse garde le signe de x. Strictement décroissante sur ]−∞ ; 0[ et sur ]0 ; +∞[, jamais sur ℝ* entier. Strictement croissante sur [0 ; +∞[ : minimum 0 atteint en 0, pas de maximum.
si 0 < u < v ou si u < v < 0 : 1u > 1v ; si u < 0 < v, conclure par le signe : 1u < 0 < 1v. si 0 ≤ u < v, alors √u < √v : la racine carrée conserve l'ordre.
ENSEMBLE DE DEFINITION : DEUX SEULES INTERDICTIONS
tout dénominateur  ≠ 0   ·   toute quantité sous un radical  ≥ 0

Une condition par quotient, une par radical ; le domaine rassemble les réels qui les vérifient toutes en même temps, et la réponse s'écrit avec des intervalles.

LE NOMBRE 1 SEPARE DEUX COMPORTEMENTS : POUR a > 0
a > 1 :  1a < 1 < √a < a < a2 < a3
0 < a < 1 :  a3 < a2 < a < √a < 1 < 1a
a = 1 : toutes ces quantités valent 1

Multiplier un nombre par lui-même l'agrandit s'il est plus grand que 1, mais le rapetisse s'il est compris entre 0 et 1. Toutes ces courbes se rencontrent au point (1 ; 1), où l'ordre se retourne.

Leçon 4 : Fonction valeur absolue x ↦ |x|

DEFINITION : SUR ℝ TOUT ENTIER
|x| = x si x ≥ 0     |x| = −x si x < 0
  • −x désigne l'opposé de x : pour x négatif, cet opposé est positif. Ainsi |−5| = −(−5) = 5.
  • |x| ≥ 0 pour tout réel x, et |x| = 0 seulement pour x = 0. Comme |−x| = |x|, la fonction est paire : courbe symétrique par rapport à l'axe des ordonnées.
  • |x| est la distance de x à zéro sur la droite graduée ; |x − a| est la distance entre x et a.
  • Strictement décroissante sur ]−∞ ; 0], strictement croissante sur [0 ; +∞[ : minimum 0 en 0, pas de maximum. La courbe est faite de deux demi-droites issues de l'origine, y = −x pour x < 0 et y = x pour x ≥ 0 : un V de sommet l'origine.

Equation |x| = k et suppression des barres

Signe de kSolutions de |x| = k
k > 0deux solutions opposées : x = k ou x = −k
k = 0une seule solution : x = 0
k < 0aucune solution : une valeur absolue n'est jamais strictement négative

Pour k > 0, l'équation |x − a| = k a pour solutions les deux nombres situés à la distance k de a : a − k et a + k.

Pour supprimer les barres de |ax + b|, on sépare deux cas : |ax + b| = ax + b là où ax + b ≥ 0, et |ax + b| = −(ax + b) là où ax + b < 0. La valeur charnière est la solution de ax + b = 0, repérée par un tableau de signes. La fonction x ↦ |ax + b| est donc affine par intervalles, et sa courbe est un V dont le sommet a pour abscisse cette valeur charnière.

Leçon 5 : Fonctions se ramenant aux fonctions de référence

PARABOLE DEPLACEE : h, k REELS ET a ≠ 0
f(x) = a(x − h)2 + k    sommet (h ; k)
  • Pour a = 1 : décroissante sur ]−∞ ; h], croissante sur [h ; +∞[, minimum k atteint en x = h ; courbe symétrique par rapport à la droite d'équation x = h.
  • Si a > 0 : parabole tournée vers le haut, la fonction décroît puis croît et k est un minimum. Si a < 0 : parabole retournée vers le bas, la fonction croît puis décroît et k est un maximum.
  • Si |a| > 1 elle est resserrée ; si 0 < |a| < 1 elle est aplatie. Dans tous les cas le sommet reste (h ; k).
Le décalage horizontal se lit à l'envers. Dans (x − 2)2 la courbe se déplace de 2 vers la droite ; dans (x + 3)2 = (x − (−3))2, de 3 vers la gauche. Réflexe : chercher la valeur de x qui annule la quantité mise au carré.

Forme canonique

Toute expression x2 + px + q se réécrit (x − h)2 + k à l'aide de (x − h)2 = x2 − 2hx + h2 lue de droite à gauche : h est la moitié du coefficient de x, changée de signe, puis on corrige la constante. En pratique, l'énoncé donne la forme cherchée et il suffit de la vérifier en développant.

Même principe pour toutes les références

Remplacer x par x − h décale la courbe de h horizontalement, ajouter k la décale de k verticalement. Le sens de variation ne change pas : il est seulement déplacé.

FonctionCe qu'il faut en dire
x ↦ |x − h| + kcourbe en V de sommet (h ; k) ; minimum k atteint en h.
x ↦ (x − h)3croissante sur ℝ ; centre de symétrie déplacé en (h ; 0).
x ↦ √x − h + kdéfinie pour x ≥ h ; croissante ; minimum k atteint en h.
x ↦ 1x − h + kdéfinie pour x ≠ h ; décroissante sur chacun des deux intervalles.

Certains quotients se réécrivent f(x) = a + bx − h : c'est la fonction inverse décalée, définie pour x ≠ h, décroissante sur chaque intervalle si b > 0 et croissante si b < 0. Aucun exposé général n'est au programme : l'énoncé fournit la forme à obtenir.

Résoudre graphiquement f(x) = g(x) : tracer les deux courbes dans le même repère ; le nombre de points d'intersection donne le nombre de solutions ; lire leurs abscisses, jamais leurs ordonnées ; vérifier ensuite par le calcul, une lecture graphique restant approximative.

PIEGES ET ERREURS FREQUENTES
✗ x ↦ 2x + 3 traduit une proportionnalité  ·  on calcule f(5) avec la formule écrite en premier
✓ Seule une fonction linéaire x ↦ ax, sans constante ajoutée, traduit une proportionnalité : ici f(0) = 3 ≠ 0, la droite ne passe pas par l'origine. Et pour une fonction par morceaux, la première question est « dans quel intervalle se trouve mon nombre ? » ; avec x ≥ 2, la valeur 2 relève de la seconde formule.
✗ x ↦ x2 est croissante sur ℝ  ·  (−2)2 = −4  ·  (−2)3 = 8
✓ Le carré décroît sur ]−∞ ; 0] puis croît sur [0 ; +∞[ ; contre-exemple : −3 < 1 et pourtant 9 > 1. (−2)2 = 4 car un carré est positif, tandis que (−2)3 = −8 car le cube garde le signe. Le carré est pair, le cube impair : tester f(−2) et f(2).
✗ Pour f(x) = 1x, on a f(0) = 0  ·  g(x) = √x est définie pour tout x
✓ 0 est une valeur interdite pour l'inverse : aucun nombre multiplié par 0 ne donne 1, donc f(0) n'existe pas. Et la racine carrée n'existe que pour x ≥ 0, aucun carré n'étant strictement négatif : son domaine est [0 ; +∞[, ce qui la rend ni paire ni impaire.
✗ −1 < 2, donc par décroissance 1−1 > 12
✓ La décroissance de l'inverse vaut sur chaque intervalle séparément, jamais en franchissant 0 : ici 1−1 = −1 < 0,5. Quand les deux nombres sont de signes contraires, on compare par le signe des images.
✗ |−3| = −3  ·  |x| = −x toujours  ·  |x| = −5 a pour solutions 5 et −5
✓ Une valeur absolue mesure une distance à zéro : jamais négative, donc |−3| = 3. L'écriture |x| = −x n'est correcte que si x est négatif ; pour x = 3 elle donnerait 3 = −3. Enfin |x| = −5 n'a aucune solution : regarder le signe de k avant tout calcul.
✗ Le minimum de (x + 4)2 − 1 est atteint en x = 4  ·  (x + 3)2 décale la courbe vers la droite
✓ Le carré s'annule quand x + 4 = 0, donc en x = −4, où le minimum vaut −1. De même (x + 3)2 = (x − (−3))2 : le décalage vaut −3, donc vers la gauche.
A SAVOIR PAR COEUR AVANT LE DEVOIR
  1. Affine x ↦ ax + b : courbe = droite ; a coefficient directeur, b ordonnée à l'origine ; croissante si a > 0, décroissante si a < 0. Linéaire (proportionnalité) si b = 0. Détermination : a = y2 − y1x2 − x1, puis b par remplacement.
  2. Affine par intervalles : une formule par intervalle ; pour une image, chercher d'abord l'intervalle ; variation donnée sur chaque intervalle.
  3. Carré : paire, parabole, minimum 0 en 0, décroît sur ]−∞ ; 0] puis croît sur [0 ; +∞[. Cube : impaire, croissante sur ℝ, garde le signe.
  4. Inverse : impaire, hyperbole, 0 interdit, décroissante sur chaque branche, jamais de l'une à l'autre. Racine : domaine [0 ; +∞[, croissante, ni paire ni impaire.
  5. Valeur absolue : paire, courbe en V, minimum 0 en 0 ; |x| = x si x ≥ 0 et −x si x < 0 ; |x − a| = distance de x à a. L'équation |x| = k a deux solutions si k > 0, une si k = 0, aucune si k < 0.
  6. Comparaison : pour a > 1, 1a < 1 < √a < a < a2 < a3 ; pour 0 < a < 1, tout s'inverse.
  7. Fonction décalée a(x − h)2 + k : sommet (h ; k), extremum k en x = h ; minimum si a > 0, maximum si a < 0. Même principe pour |x − h| + k, √x − h + k, 1x − h + k.
  8. Réflexes. Domaine : dénominateur ≠ 0, quantité sous le radical ≥ 0. Parité : tester f(−x). Ne jamais annoncer un sens de variation sans dire sur quel intervalle ; un contre-exemple suffit à réfuter.
