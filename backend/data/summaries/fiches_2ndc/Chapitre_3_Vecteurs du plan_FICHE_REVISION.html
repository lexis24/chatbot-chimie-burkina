L'ESSENTIEL

Leçon 1 : Combinaison linéaire, points et vecteurs

Somme de deux vecteurs

RELATION DE CHASLES : POUR TOUS POINTS A, B, C
AB + BC = AC

On place l'origine du second vecteur à l'extrémité du premier ; la somme joint la première origine à la dernière extrémité. A lire dans les deux sens : pour simplifier, et pour décomposer AC en AB + BC en glissant au milieu le point de passage voulu.

REGLE DU PARALLELOGRAMME : DEUX VECTEURS DE MEME ORIGINE A
si u = AB et v = AD, alors u + v = AC
C étant le quatrième sommet du parallélogramme ABCD
  • Vecteur nul : u + 0 = u pour tout u ; AA = 0.
  • Opposé : l'opposé de AB est BA = −AB : même direction, même longueur, sens contraire.
  • Soustraire, c'est ajouter l'opposé : u − v = u + (−v).
  • Norme : ‖AB‖ = AB, la longueur du segment.

Multiplication d'un vecteur par un réel

Soit k un réel et u un vecteur non nul. Le vecteur ku a :

  • la même direction que u ;
  • le même sens si k > 0, le sens contraire si k < 0 ;
  • pour longueur ‖ku‖ = |k| × ‖u‖.

Si k = 0 ou u = 0, alors ku = 0.

REGLES DE CALCUL : k ET k′ REELS, u ET v VECTEURS
k(u + v) = ku + kv
(k + k′)u = ku + k′u     k(k′u) = (kk′)u
On ne multiplie jamais deux vecteurs entre eux dans ce chapitre : u × v n'a pas de sens ici, et uv n'en a jamais. Seuls les produits d'un nombre par un vecteur existent.

Combinaison linéaire et colinéarité

COMBINAISON LINEAIRE DE u ET v
w = au + bv    (a et b réels, les coefficients)
COLINEARITE : POUR u ≠ 0
u et v colinéaires ⇔ il existe un réel k tel que v = ku
  • Deux vecteurs colinéaires ont la même direction.
  • Le vecteur nul est colinéaire à tout vecteur, puisque 0 = 0 × u.

Points et vecteurs : les caractérisations

ConfigurationTraduction vectorielle
I milieu de [AB]AI = 12AB, ou IA + IB = 0
A, B, C alignésAB et AC colinéaires : AC = kAB
(AB) ∥ (CD)AB et CD colinéaires
ABCD parallélogrammeAB = DC, ou AD = BC, ou [AC] et [BD] de même milieu
E symétrique de B par rapport à CBE = 2BC

Chaque ligne est une équivalence : elle se lit dans les deux sens. Une figure qui « a l'air » juste ne démontre rien ; c'est l'égalité vectorielle qu'il faut établir.

Méthode : alignement, parallélisme, construction

  • Choisir les deux vecteurs qui portent l'information : AB et AC pour un alignement (un point commun), AB et CD pour un parallélisme.
  • Exprimer chacun d'eux en fonction des mêmes vecteurs de référence, avec la relation de Chasles et les données.
  • Chercher un réel k tel que l'un soit k fois l'autre, puis conclure par une phrase : les vecteurs sont colinéaires, donc les points sont alignés (ou les droites parallèles).
  • Construire un point défini par AD = 2u + v : partir du point déjà placé A, reporter 2u puis v bout à bout, en faisant demi-tour si un coefficient est négatif.

Leçon 2 : Base de l'ensemble des vecteurs du plan

BASE
(i ; j) est une base ⇔ i et j ne sont pas colinéaires
  • Aucune autre condition : les deux vecteurs n'ont pas besoin d'être perpendiculaires, ni d'avoir la même longueur, ni d'être de longueur 1. Il suffit que leurs directions soient différentes.
  • Repère : la donnée d'un point O, l'origine, et d'une base ; on note (O ; i ; j). Une base sert à repérer les vecteurs ; un repère permet de repérer aussi les points.
  • Si A, B, C ne sont pas alignés, (AB ; AC) est une base et (A ; AB ; AC) un repère.

Décomposition et coordonnées

DECOMPOSITION : (i ; j) ETANT UNE BASE
tout vecteur u s'écrit d'une seule manière u = xi + yj

Le couple (x ; y) est formé des coordonnées de u dans cette base ; on note u(x ; y). L'unicité entraîne qu'une égalité vectorielle se coupe en deux égalités de nombres : si xi + yj = x′i + y′j, alors x = x′ et y = y′.

Calculer sur les coordonnées

DANS UNE BASE FIXEE : u(x ; y), v(x′ ; y′), k REEL
u + v (x + x′ ; y + y′)     ku (kx ; ky)
u = v ⇔ x = x′ et y = y′     u = 0 ⇔ x = 0 et y = 0
DANS UN REPERE (O ; i ; j) : A(xA ; yA), B(xB ; yB)
AB (xB − xA ; yB − yA)    arrivée moins départ
I milieu de [AB] : I (xA + xB2 ; yA + yB2)
Des coordonnées n'ont de sens que dans une base précisée. Changer d'origine change les coordonnées des points, mais pas celles des vecteurs.

Méthode : décomposer w dans la base (u ; v)

  • Vérifier d'abord que (u ; v) est bien une base : les deux vecteurs ne sont pas colinéaires.
  • Poser w = au + bv, remplacer chaque vecteur par ses coordonnées, développer.
  • Identifier coordonnée par coordonnée : on obtient un système de deux équations à deux inconnues a et b.
  • Résoudre, puis vérifier en remplaçant a et b par les valeurs trouvées.

Leçon 3 : Déterminant de deux vecteurs et colinéarité

DETERMINANT : BASE FIXEE, u(x ; y) ET v(x′ ; y′)
det(u ; v) = x  x′y  y′ = xy′ − yx′

Calcul en croix : produit de la diagonale descendante, moins produit de la diagonale montante. Le premier vecteur donne la colonne de gauche. Un déterminant est un nombre, jamais un vecteur : il peut être positif, négatif ou nul.

CARACTERISATION DE LA COLINEARITE
u et v colinéaires  ⇔  det(u ; v) = xy′ − yx′ = 0

Les trois conséquences à connaître :

  • A, B, C alignés ⇔ det(AB ; AC) = 0.
  • (AB) ∥ (CD) ⇔ det(AB ; CD) = 0.
  • (u ; v) est une base ⇔ det(u ; v) ≠ 0.

Deux propriétés du déterminant

ANTISYMETRIE
det(v ; u) = −det(u ; v)     det(u ; u) = 0

Dépendance de la base : la valeur du déterminant dépend de la base choisie, mais le fait qu'il soit nul ou non n'en dépend pas. La colinéarité est une propriété géométrique : elle ne change pas selon le quadrillage utilisé.

Méthode : utiliser le déterminant

  • Ecrire les coordonnées des deux vecteurs dans la même base ; si l'énoncé donne des points, calculer d'abord « arrivée moins départ ».
  • Poser les deux produits séparément avant de soustraire, en surveillant les signes.
  • Conclure : déterminant nul → les deux vecteurs sont colinéaires, donc, selon les vecteurs choisis, les points sont alignés, les droites parallèles, ou le couple n'est pas une base ; déterminant non nul → ils ne sont pas colinéaires, et le couple est une base.
PIEGES ET ERREURS FREQUENTES
✗ u et v sont colinéaires, donc u = v
✓ Colinéaires signifie seulement qu'il existe un réel k tel que v = ku : la direction est commune, le sens et la longueur peuvent différer. AB, 2AB et −3AB sont colinéaires et deux à deux différents ; l'égalité est le seul cas k = 1.
✗ AB + CB = AC
✓ Chasles exige que la lettre d'arrivée du premier soit la lettre de départ du second : ici on arrive en B et l'on repart de C, rien ne se recolle. On transforme d'abord : CB = −BC, d'où AB + CB = AB − BC. Réflexe : dès qu'une soustraction apparaît, remplacer −XY par YX.
✗ (u ; 2u) est une base, car les deux vecteurs sont différents
✓ Etre différents ne suffit pas : une base est un couple de vecteurs non colinéaires, et ici det = 0. Un couple contenant 0 n'est jamais une base. A l'inverse, il n'est pas nécessaire que les vecteurs soient perpendiculaires ni de longueur 1.
✗ AB (xA − xB ; yA − yB)
✓ C'est l'inverse : toujours l'arrivée moins le départ, AB (xB − xA ; yB − yA). Contrôle immédiat : si B est à droite de A, la première coordonnée doit être positive.
✗ det(u ; v) = xx′ − yy′
✓ Le déterminant se calcule en croix : det(u ; v) = xy′ − yx′. Contrôle sur un cas connu : pour u(1 ; 0) et v(0 ; 1), la bonne formule donne 1 × 1 − 0 × 0 = 1, non nul, ce qui est correct.
✗ u(2 ; 3) et v(4 ; 6) ne sont pas colinéaires  ·  det(u ; v) = det(v ; u)
✓ Ici det = 2 × 6 − 3 × 4 = 0 : ils sont colinéaires, avec v = 2u. Et échanger les deux vecteurs change le signe du déterminant ; seule sa nullité ne dépend pas de l'ordre.
✗ ‖−3u‖ = −3‖u‖
✓ Une norme n'est jamais négative : ‖−3u‖ = |−3| × ‖u‖ = 3‖u‖. Un coefficient négatif retourne la flèche, il ne rend pas la longueur négative.
✗ ABCD parallélogramme donc AB = CD  ·  « w a pour coordonnées (8 ; 9) », sans autre précision
✓ L'ordre des lettres compte : AB = DC ; avec CD, le quadrilatère serait croisé. Et des coordonnées n'existent que dans une base : le même vecteur peut valoir (8 ; 9) dans (i ; j) et (3 ; 2) dans (u ; v).
A SAVOIR PAR COEUR AVANT LE DEVOIR
  1. Chasles : AB + BC = AC, à lire dans les deux sens ; BA = −AB ; AA = 0 ; règle du parallélogramme pour deux vecteurs de même origine.
  2. ku : même direction, même sens si k > 0, sens contraire si k < 0, et ‖ku‖ = |k| × ‖u‖. Jamais de produit de deux vecteurs.
  3. Combinaison linéaire : w = au + bv. Colinéaires (u ≠ 0) : il existe k tel que v = ku ; 0 est colinéaire à tout vecteur.
  4. I milieu de [AB] ⇔ AI = 12AB ; A, B, C alignés ⇔ AB et AC colinéaires ; (AB) ∥ (CD) ⇔ AB et CD colinéaires ; ABCD parallélogramme ⇔ AB = DC.
  5. Base = couple de vecteurs non colinéaires ; repère = une origine et une base. Si A, B, C ne sont pas alignés, (AB ; AC) est une base.
  6. Décomposition unique : u = xi + yj. Une égalité vectorielle se coupe en deux égalités de nombres. Toujours préciser la base.
  7. Coordonnées : AB (xB − xA ; yB − yA) ; on ajoute les coordonnées pour u + v, on les multiplie par k pour ku ; milieu = moyenne des coordonnées.
  8. Déterminant : det(u ; v) = xy′ − yx′, en croix. Il est nul ⇔ les deux vecteurs sont colinéaires : c'est le test de l'alignement, du parallélisme, et il permet de reconnaître une base. Sa valeur dépend de la base, sa nullité non.
