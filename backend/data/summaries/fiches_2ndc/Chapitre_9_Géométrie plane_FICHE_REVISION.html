L'ESSENTIEL

Leçon 1 : Vecteur directeur d'une droite • PARTIE A : DROITES DANS UN REPERE

Un vecteur directeur de (D) est un vecteur non nul de même direction que (D). Si A et B sont deux points distincts de (D), alors AB en est un.

  • Il y en a une infinité, tous colinéaires : si u dirige (D), ku aussi pour tout k ≠ 0 ; on dit un vecteur directeur, jamais « le ».
  • M est sur la droite passant par A et dirigée par u ⇔ AM et u colinéaires (déterminant nul).
LIRE UN VECTEUR DIRECTEUR SUR UNE EQUATION
y = mx + p  →  u(1 ; m)
ax + by + c = 0  →  u(−b ; a) directeur, n(a ; b) normal (⊥)
Droites verticales. x = k n'a pas de coefficient directeur, mais possède un vecteur directeur, (0 ; 1), et une équation cartésienne, x − k = 0.

Leçon 2 : Représentation paramétrique d'une droite

(D) passe par A(xA ; yA) et est dirigée par u(α ; β) : M(x ; y) ∈ (D) ⇔ il existe un réel t tel que AM = tu.

REPRESENTATION PARAMETRIQUE DE (D)
x = xA + tα  et  y = yA + tβ   avec t ∈ ℝ
  • t est le paramètre : à chaque t un seul point de (D), et réciproquement ; t = 0 donne A. La mention t ∈ ℝ fait partie de la réponse.
  • Une même droite en a une infinité, selon A et u choisis.
  • Tester un point : résoudre la première équation en t, reporter dans la seconde, comparer à l'ordonnée (si α = 0, commencer par la seconde).

Leçon 3 : Equation cartésienne d'une droite

EQUATION CARTESIENNE : avec (a ; b) ≠ (0 ; 0)
ax + by + c = 0

Toute droite en admet une ; M lui appartient ⇔ ses coordonnées la vérifient. Réciproquement, toute équation de cette forme est celle d'une droite, de directeur u(−b ; a) et de normal n(a ; b).

  • Une même droite en a une infinité, toutes proportionnelles : x − 2y + 3 = 0 et 2x − 4y + 6 = 0 sont la même droite.
  • b = 0 : droite verticale ; a = 0 : droite horizontale. Si b ≠ 0, on isole y et l'on obtient la forme réduite, de coefficient directeur m = −ab.
PAR LE DETERMINANT : droite par A(xA ; yA), de directeur u(α ; β)
det(AM ; u) = 0 ⇔ β(x − xA) − α(y − yA) = 0
Changer de forme. Paramétrique → cartésienne : on élimine t. Cartésienne → paramétrique : on lit un point et u(−b ; a), puis on écrit le système.

Leçon 4 : Parallélisme et orthogonalité de deux droites

CRITERES : u et u′ dirigent (D) et (D′)
(D) ∥ (D′) ⇔ u et u′ colinéaires ⇔ det(u ; u′) = 0
(D) ⊥ (D′) ⇔ u · u′ = 0  (repère orthonormé)

En équations réduites : parallèles ⇔ m = m′ ; perpendiculaires ⇔ m × m′ = −1, mais seulement si les deux coefficients existent ; le critère vectoriel, lui, est sans exception.

Position relative : trois cas, et trois seulement

CasReconnaissancePoints communs
Sécantesdet(u ; u′) ≠ 0un seul : solution du système
Strict. parallèlescolinéaires, équations non proportionnellesaucun
Confondueséquations proportionnellestous

Parallélisme établi : on teste un point de la première dans la seconde ; s'il la vérifie, elles sont confondues, sinon strictement parallèles.

Par un point P. Parallèle à ax + by + c = 0 : ax + by + k = 0 (mêmes a et b) ; perpendiculaire : −bx + ay + k′ = 0. On trouve k avec les coordonnées de P.

Leçon 5 : Barycentre de deux points pondérés • PARTIE B : BARYCENTRE

Un point pondéré est un couple (A ; a) : le réel a est le coefficient.

DEFINITION : sous la condition a + b ≠ 0
a GA + b GB = 0

Il existe alors un unique point G : le barycentre de (A ; a) et (B ; b). Si a + b = 0, il n'existe pas. Si a = b, c'est le milieu de [AB], dit isobarycentre.

COORDONNEES ET POSITION DE G
xG = a xA + b xBa + b   yG = a yA + b yBa + b   AG = ba + b AB
  • Coordonnées de G = moyennes pondérées de celles de A et B ; G est toujours sur la droite (AB), et sur le segment [AB] si a et b sont de même signe.
  • G est inchangé si l'on multiplie les deux coefficients par un même réel non nul.

Leçon 6 : Barycentre de trois et quatre points ; associativité

TROIS POINTS : sous la condition a + b + c ≠ 0
a GA + b GB + c GC = 0
xG = a xA + b xB + c xCa + b + c  (de même pour yG)
  • Tout s'étend à quatre points pondérés, sous la condition a + b + c + d ≠ 0 ; pas au-delà.
  • Coefficients tous égaux : G est l'isobarycentre ; celui de trois points non alignés est le centre de gravité du triangle.
ASSOCIATIVITE (admise) : G barycentre de (A ; a), (B ; b), (C ; c)
si a + b ≠ 0 et si I est le barycentre de (A ; a) et (B ; b),
alors G est le barycentre de (I ; a + b) et (C ; c)

On remplace donc deux points par leur barycentre partiel, affecté de la somme de leurs coefficients : trois points se ramènent à deux.

Leçon 7 : Utilisation du barycentre

  • Alignement. Tout barycentre de (A ; a) et (B ; b) est sur (AB), et réciproquement tout point de (AB) en est un, pour des coefficients bien choisis.
  • Partage d'un segment. Si AG = k AB avec 0 < k < 1, alors G est le barycentre de (A ; 1 − k) et (B ; k).
  • Centre de gravité. Isobarycentre des trois sommets, sur chaque médiane aux deux tiers depuis le sommet.
  • Concours de droites. On construit un point candidat, puis on montre qu'il est sur les trois droites.
REDUCTION : G barycentre de (A ; a) et (B ; b), a + b ≠ 0
a MA2 + b MB2 = (a + b)MG2 + a GA2 + b GB2

Valable pour tout point M : l'ensemble des M tels que a MA2 + b MB2 = k est un cercle de centre G, un point, ou vide. Pour a = b = 1, G est le milieu de [AB] : théorème de la médiane.

Leçon 8 : Equation d'un cercle et intersection avec une droite • PARTIE C : CERCLE ET ANGLES ORIENTES

CENTRE Ω(a ; b), RAYON r > 0 : repère orthonormé
(x − a)2 + (y − b)2 = r2

Forme canonique : le centre annule les deux parenthèses, et le second membre vaut r2. En développant : x2 + y2 − 2ax − 2by + c = 0 ; on revient à la forme canonique en complétant les carrés (x2 − 2αx = (x − α)2 − α2). Selon le signe du second membre obtenu, l'ensemble est un cercle, un point, ou vide.

CERCLE DE DIAMETRE [AB]
M est sur le cercle ⇔ MA · MB = 0

Intersection d'une droite et d'un cercle

On remplace dans l'équation du cercle l'expression tirée de celle de la droite : équation du second degré. A chaque solution en x correspond un point, dont on calcule l'ordonnée avec l'équation de la droite.

Le nombre de solutions donne la position : deux → sécante ; une (double) → tangente ; aucune → extérieure.

Leçon 9 : Orientation du plan et mesure principale

Orienter le plan, c'est choisir un sens de rotation comme positif : le sens direct (ou trigonométrique), contraire aux aiguilles d'une montre ; l'autre est indirect. Pour u et v non nuls, l'angle orienté (u , v) va de u vers v : il tient compte du sens de rotation, a donc un signe, et l'ordre compte.

Une mesure est un réel, en radians ; un même angle en a une infinité, différant d'un multiple de 2π : si α en est une, α + 2kπ aussi (k ∈ ℤ). La mesure est définie modulo 2π. En degrés, le tour vaut 360.

MESURE PRINCIPALE : l'unique mesure située dans cet intervalle
]−π ; π]   −π exclu, π inclus

On l'obtient en ajoutant ou en retranchant 2π autant de fois que nécessaire. La mesure principale d'un demi-tour est π, jamais −π.

Leçon 10 : Propriétés des angles orientés

PROPRIETES ADMISES : u, v, w non nuls, modulo 2π
(v , u) = −(u , v)  (changement d'ordre)
(u , v) + (v , w) = (u , w)  (Chasles)
(u , u) = 0   (u , −u) = π

On peut ajouter 2kπ (k ∈ ℤ) sans changer l'angle : toutes les mesures d'un même angle ont le même cosinus et le même sinus. On calcule donc avec les angles comme avec des nombres relatifs, modulo 2π, puis l'on ramène le résultat dans ]−π ; π] si besoin.

PIEGES ET ERREURS FREQUENTES
✗ Pour ax + by + c = 0, un vecteur directeur est (a ; b)
✓ (a ; b) est le vecteur normal ; le directeur est u(−b ; a). Attention aux signes : dans 2x − 3y + 1 = 0, b = −3, donc u(3 ; 2) ; écris « a = …, b = … » avant d'appliquer la règle.
✗ Deux droites sont parallèles si leurs directeurs sont orthogonaux  ·  deux droites parallèles n'ont jamais de point commun
✓ Déterminant nul = directeurs colinéaires = droites parallèles ; produit scalaire nul = directeurs orthogonaux = droites perpendiculaires. Deux droites confondues sont parallèles, avec tous leurs points communs : « aucun point commun » se dit strictement parallèles.
✗ Le barycentre de (A ; 3) et (B ; −3) existe
✓ La somme des coefficients vaut 0 : la division par a + b est impossible, le barycentre n'existe pas. La condition porte sur la somme, non sur chaque coefficient : (A ; −2) et (B ; 3) sont licites.
✗ AG = aa + b AB  ·  on remplace A et B par leur milieu I affecté du coefficient 1
✓ C'est le coefficient de l'autre point : AG = ba + b AB. Pour a = 3, b = 1 : G est au quart de [AB] depuis A, près du gros coefficient. Et le point partiel reçoit la somme a + b, jamais 1.
✗ (x − 2)2 + (y + 1)2 = 16 a pour centre (−2 ; 1) et pour rayon 16  ·  x2 − 2x = (x − 1)2
✓ Le centre annule les parenthèses : Ω(2 ; −1) ; le second membre vaut r2, donc r = 4. En complétant, x2 − 2x = (x − 1)2 − 1 : on retranche le carré ajouté. Ainsi x2 + y2 − 2x + 5 = 0 donne (x − 1)2 + y2 = −4 : ensemble vide.
✗ La mesure principale est dans [0 ; 2π]  ·  un angle orienté est toujours compris entre 0 et π
✓ La mesure principale est l'unique mesure de ]−π ; π] : −π est exclu, π est inclus. Un angle orienté est défini modulo 2π et peut être négatif ; c'est l'angle géométrique qui reste entre 0 et π, sans signe.
A SAVOIR PAR COEUR AVANT LE DEVOIR
  1. ax + by + c = 0 : directeur u(−b ; a), normal n(a ; b) ; y = mx + p : u(1 ; m) ; verticale x = k : pas de coefficient directeur.
  2. Paramétrique : x = xA + tα, y = yA + tβ, avec t ∈ ℝ. Cartésienne par le déterminant : β(x − xA) − α(y − yA) = 0.
  3. Parallèles ⇔ det(u ; u′) = 0 ; perpendiculaires, en repère orthonormé, ⇔ u · u′ = 0 ou m × m′ = −1 s'ils existent. Trois positions : sécantes, strictement parallèles, confondues.
  4. Barycentre : existe ⇔ somme des coefficients non nulle ; coordonnées = moyennes pondérées ; AG = ba + b AB.
  5. Associativité : deux points se remplacent par leur barycentre partiel affecté de la somme de leurs coefficients. Isobarycentre d'un triangle = centre de gravité, aux deux tiers de chaque médiane depuis le sommet.
  6. Réduction : a MA2 + b MB2 = (a + b)MG2 + a GA2 + b GB2 ; d'où a MA2 + b MB2 = k : cercle de centre G, point, ou vide.
  7. Cercle : (x − a)2 + (y − b)2 = r2, centre Ω(a ; b), rayon r ; diamètre [AB] : MA · MB = 0. Après complétion des carrés : cercle, point, ou vide.
  8. Angles orientés : définis modulo 2π, mesure principale dans ]−π ; π] ; Chasles (u , v) + (v , w) = (u , w) et (v , u) = −(u , v).
