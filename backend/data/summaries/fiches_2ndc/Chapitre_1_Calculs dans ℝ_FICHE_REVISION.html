Leçon 1 : Ordre et comparaison dans ℝ

LES CINQ ENSEMBLES DE NOMBRES
ℕ ⊂ ℤ ⊂ 𝔻 ⊂ ℚ ⊂ ℝ

ℕ entiers naturels  ·  ℤ entiers relatifs  ·  𝔻 décimaux, de la forme a10n avec a ∈ ℤ et n ∈ ℕ, dont l'écriture décimale s'arrête  ·  ℚ rationnels, de la forme pq avec p ∈ ℤ et q ∈ ℕ non nul  ·  ℝ réels, qui repèrent chacun un point de la droite graduée.

Chaque ensemble contient tous les précédents. On simplifie l'écriture avant de conclure : √9 = 3 ∈ ℕ.

Comparer deux réels

ORDRE DANS ℝ : DEFINITION ET OPERATIONS
a < b ⇔ b − a > 0    a = b ⇔ b − a = 0
a ≤ b donne a + c ≤ b + c (tout réel c), ac ≤ bc si c > 0, ac ≥ bc si c < 0
0 ≤ a ≤ b donne a2 ≤ b2 et √a ≤ √b    a ≤ b ≤ 0 donne a2 ≥ b2    0 < a ≤ b donne 1a ≥ 1b

Comparer, c'est étudier le signe de la différence a − b ; seulement pour deux nombres strictement positifs, on peut comparer le quotient ab à 1. Ajouter conserve toujours le sens, multiplier par un négatif l'inverse ; sur les négatifs, le carré mesure l'éloignement à zéro et retourne l'ordre.

Puissances et écriture scientifique

PUISSANCES : a ≠ 0, b ≠ 0, m et n dans ℤ
am × an = am+n    aman = am−n    (am)n = amn
(ab)n = anbn    (ab)n = anbn    a0 = 1    a−n = 1an

Ecriture scientifique d'un nombre non nul : a × 10n avec n ∈ ℤ et 1 ≤ |a| < 10 : un seul chiffre non nul avant la virgule.

Racine carrée

RACINE CARREE : pour a ≥ 0 et b ≥ 0
√a est l'unique nombre positif de carré a : (√a)2 = a
√a × b = √a × √b    √ab = √a√b (b > 0)    √a2 = |a|
quantité conjuguée : (a + √b)(a − √b) = a2 − b

Aucune formule ne donne √a + b. Equation x2 = a : deux solutions √a et −√a si a > 0 ; une seule, 0, si a = 0 ; aucune si a < 0.

Simplifier un radical, c'est en sortir le plus grand carré parfait : √75 = 5√3 ; deux radicaux ne s'additionnent que s'ils ont le même radicande. La conjuguée rend rationnel un dénominateur.

Signe d'un produit ou d'un quotient

Un produit est positif si les deux facteurs sont de même signe, négatif s'ils sont de signes contraires, nul si un facteur est nul ; même règle pour un quotient, la valeur qui annule le dénominateur étant interdite. Un facteur ax + b (a ≠ 0) s'annule en x = −ba et prend le signe de a après cette valeur.

Tableau de signes : factoriser, ranger les racines dans l'ordre croissant de −∞ à +∞, une ligne par facteur puis une ligne pour l'expression, double barre sous la valeur interdite.

Leçon 2 : Intervalles, valeur absolue et distance

Un intervalle est un ensemble de réels sans trou. Pour a ≤ b : [a ; b] fermé (a ≤ x ≤ b, bornes incluses), ]a ; b[ ouvert (a < x < b, bornes exclues), [a ; b[ et ]a ; b] semi-ouverts. Non bornés : [a ; +∞[, ]a ; +∞[, ]−∞ ; b], ]−∞ ; b[.

Règle du crochet : vers l'intérieur, borne incluse (point plein) ; vers l'extérieur, borne exclue (point creux). +∞ et −∞ ne sont pas des nombres : le crochet est toujours ouvert de leur côté.

CENTRE, RAYON, AMPLITUDE : bornes a ≤ b
c = a + b2    r = b − a2    amplitude = b − a = 2r
a = c − r   et   b = c + r

A ∩ B : les nombres qui sont à la fois dans A et dans B. A ∪ B : ceux qui sont dans A ou dans B, le « ou » étant inclusif. Sans nombre commun, l'intersection est l'ensemble vide ∅. Le complémentaire de I dans ℝ est souvent une réunion de deux intervalles.

On dessine les deux intervalles l'un sous l'autre : l'intersection est couverte deux fois, la réunion au moins une fois.

Valeur absolue

DEFINITION ET PROPRIETES : a et b réels
|x| = x si x ≥ 0     |x| = −x si x < 0
|−a| = |a|    |a|2 = a2    √a2 = |a|
|a × b| = |a| × |b|    |ab| = |a||b| (b ≠ 0)

Une valeur absolue est toujours positive ou nulle ; la ligne |x| = −x ne sert que si x est déjà négatif. Aucune formule ne donne |a + b| : seulement l'inégalité triangulaire (Leçon 4).

Ecrire une expression sans les barres : chercher les valeurs qui annulent chaque expression placée entre les barres, les ranger dans l'ordre croissant, puis, sur chaque zone ainsi découpée, remplacer chaque valeur absolue par l'expression elle-même si elle y est positive, par son opposé si elle y est négative.

Distance et intervalle de centre a

DISTANCE ET INTERVALLE DE CENTRE a, DE RAYON r > 0
d(a ; b) = |b − a| = |a − b|
|x − a| ≤ r ⇔ x ∈ [a − r ; a + r] (avec < : intervalle ouvert)
|x − a| = r ⇔ x = a − r ou x = a + r
|x − a| > r ⇔ x ∈ ]−∞ ; a − r[ ∪ ]a + r ; +∞[

|x| est la distance de x à 0. Une écriture |x + 3| se lit |x − (−3)| : le centre est −3. Pour résoudre, on isole la valeur absolue ; si le second membre est négatif, on conclut sans calculer : |A| = −2 n'a aucune solution, |A| ≥ −2 est vraie pour tout réel.

Leçon 3 : Majorant, minorant, maximum et minimum

MAJORANT ET MINORANT : A partie de ℝ
pour tout x ∈ A :  x ≤ M (M majore A)   ·   x ≥ m (m minore A)
  • Une partie à la fois majorée et minorée est bornée. Une partie majorée a une infinité de majorants : si M convient, tout nombre plus grand convient aussi.
  • Maximum de A : un majorant qui appartient à A, noté max A. Minimum : un minorant qui appartient à A, noté min A.
  • Un maximum est unique quand il existe, mais il peut ne pas exister. Tout ensemble fini non vide a un maximum et un minimum.
  • Pour un maximum, deux vérifications : c'est un majorant, et il appartient à A.

Leçon 4 : Encadrement et calcul approché

Encadrer un réel x, c'est trouver deux réels tels que a ≤ x ≤ b : a est un minorant, b un majorant. L'amplitude est b − a ; plus elle est petite, plus l'encadrement est précis. Une amplitude de 10−n donne un encadrement « à 10−n près ». Une mesure donnée à p près se traduit par m − p ≤ x ≤ m + p : l'amplitude vaut 2p, le double de la précision annoncée.

ENCADRER : a ≤ x ≤ b et c ≤ y ≤ d
a + c ≤ x + y ≤ b + d    a − d ≤ x − y ≤ b − c (tous réels ; bornes croisées)
ac ≤ xy ≤ bd    ad ≤ xy ≤ bc (si a > 0 et c > 0)
inégalité triangulaire : |a + b| ≤ |a| + |b|

Si un facteur est négatif, on passe d'abord à son opposé, ce qui retourne son encadrement, on multiplie, puis on repasse à l'opposé. Dans l'inégalité triangulaire, l'égalité a lieu exactement lorsque a et b sont de même signe (ou lorsque l'un des deux est nul) ; cette inégalité permet de majorer sans calculer.

Valeur approchée, arrondi, troncature

  • Un décimal v est une valeur approchée de x à 10−n près lorsque |x − v| ≤ 10−n.
  • Troncature d'ordre n : on coupe l'écriture décimale après la n-ième décimale. Arrondi d'ordre n : le décimal d'ordre n le plus proche, le dernier chiffre conservé étant augmenté d'une unité si la décimale suivante est ≥ 5. Pour 3,148 : troncature 3,14 au centième, arrondi 3,15.
  • Ordre de grandeur : valeur approchée volontairement grossière, en puissances de 10 ; elle sert à contrôler un résultat, non à le donner.
  • Réponse fiable : ne garder que les décimales communes aux deux bornes, arrondir seulement à la fin, et toujours préciser la nature du résultat : valeur exacte, arrondi, troncature ou encadrement.

Leçon 5 : Nombres irrationnels et partie entière

Un rationnel s'écrit pq avec p ∈ ℤ et q ∈ ℕ non nul ; un réel qui n'est pas rationnel est irrationnel : √2, √3, π. Un nombre est rationnel si et seulement si son écriture décimale s'arrête ou devient périodique.

√2 est irrationnel : aucune fraction n'a pour carré 2 (démonstration par l'absurde). A chaque point de la droite graduée correspond un réel et un seul : les irrationnels comblent les trous laissés par les rationnels.

PARTIE ENTIERE
E(x) est le plus grand entier inférieur ou égal à x
E(x) ≤ x < E(x) + 1   donc   0 ≤ x − E(x) < 1

x − E(x) est la partie décimale. Sur la droite graduée, E(x) est la graduation entière immédiatement à gauche de x : E(3,7) = 3 et E(−3,2) = −4. Avec un radical, on encadre entre deux carrés parfaits : 4 < 7 < 9 donne 2 < √7 < 3, donc E(√7) = 2.

Leçon 6 : Identités de degré 3 et triangle de Pascal

IDENTITES REMARQUABLES DE DEGRE 3 : a et b réels
(a + b)3 = a3 + 3a2b + 3ab2 + b3
(a − b)3 = a3 − 3a2b + 3ab2 − b3
a3 − b3 = (a − b)(a2 + ab + b2)
a3 + b3 = (a + b)(a2 − ab + b2)

Les puissances de a décroissent de 3 à 0 pendant que celles de b croissent de 0 à 3 ; pour (a − b)3, mêmes coefficients avec les signes alternés. Dans les deux factorisations, le produit central porte le signe contraire à celui du premier facteur.

TRIANGLE DE PASCAL : CHAQUE NOMBRE EST LA SOMME DES DEUX AU-DESSUS
ligne 2 : 1  2  1   ·   ligne 3 : 1  3  3  1   ·   ligne 4 : 1  4  6  4  1

La ligne n donne les coefficients de (a + b)n (signes alternés pour (a − b)n), d'où (a + b)4 = a4 + 4a3b + 6a2b2 + 4ab3 + b4. Attention aux termes composés : dans (2x − 1)3, a vaut 2x, donc a3 = 8x3.

PIEGES ET ERREURS FREQUENTES
✗ −5 < 2 donc (−5)2 < 22
✓ Le passage au carré ne conserve l'ordre que pour des nombres positifs : ici 25 > 4. Sur les négatifs il l'inverse : si a ≤ b ≤ 0, alors a2 ≥ b2.
✗ De a < b on déduit ax < bx
✓ Vrai si x > 0, faux si x < 0, égalité si x = 0. Tant que le signe de x est inconnu, on discute les cas : c'est pourquoi on ne « multiplie pas en croix » une inéquation à dénominateurs.
✗ |x| = 5 donc x = 5  ·  |x| ≤ 3 donc x ≤ 3  ·  |x − 1| = −4 donc x − 1 = −4
✓ Une valeur absolue encadre des deux côtés de 0 : |x| = 5 ⇔ x = 5 ou x = −5, et |x| ≤ 3 ⇔ −3 ≤ x ≤ 3 : toujours deux conditions. N'étant jamais négative, elle ne peut valoir −4 : aucune solution.
✗ √a2 = a  ·  √a + b = √a + √b
✓ Une racine carrée est positive : √a2 = |a|, donc √(1 − √2)2 = √2 − 1. Et elle ne se distribue pas sur une somme : √9 + 16 = 5, alors que √9 + √16 = 7.
✗ 100 est le maximum de [0 ; 100[
✓ Le crochet est ouvert : 100 n'appartient pas à l'intervalle, qui n'a donc pas de maximum. 100 en est seulement un majorant ; un maximum doit appartenir à l'ensemble.
✗ −2 < x < 3 donc 4 < x2 < 9  ·  −3 < x < −1 et 2 < y < 4 donc −6 < xy < −4
✓ x change de signe : le carré vaut au minimum 0, donc 0 ≤ x2 < 9. Et le produit d'encadrements exige des réels strictement positifs : de 1 < −x < 3 on tire 2 < −xy < 12, donc −12 < xy < −2.
✗ (x + 2)3 = x3 + 8  ·  (2x)3 = 2x3
✓ Les deux termes du milieu ne s'oublient pas : (x + 2)3 = x3 + 6x2 + 12x + 8 (pour x = 1 : 27, et non 9). L'exposant porte sur tout le facteur : (2x)3 = 8x3.
✗ E(−3,2) = −3  ·  0,25 est irrationnel car il a une virgule
✓ E(x) est le plus grand entier inférieur ou égal à x, donc l'entier de gauche : E(−3,2) = −4. Et 0,25 = 14 est rationnel : ce qui décide, c'est de pouvoir écrire le nombre en fraction, non son apparence.
A SAVOIR PAR COEUR AVANT LE DEVOIR
  1. ℕ ⊂ ℤ ⊂ 𝔻 ⊂ ℚ ⊂ ℝ ; on simplifie l'écriture avant de conclure. Comparer, c'est étudier le signe de a − b.
  2. Ajouter conserve le sens ; multiplier par un négatif l'inverse ; le carré ne conserve l'ordre que sur les positifs ; le passage à l'inverse le retourne, mais seulement pour deux réels strictement positifs.
  3. √a ≥ 0, (√a)2 = a, √ab = √a√b, √a2 = |a|, rien pour √a + b ; conjuguée (a + √b)(a − √b) = a2 − b.
  4. |x| = x si x ≥ 0, −x sinon ; |ab| = |a||b| ; |a + b| ≤ |a| + |b|.
  5. d(a ; b) = |b − a| ; |x − a| ≤ r ⇔ x ∈ [a − r ; a + r] ; |x − a| > r donne une réunion. Crochet ouvert du côté de l'infini ; centre (a + b) ÷ 2, rayon (b − a) ÷ 2, amplitude b − a.
  6. Un majorant n'appartient pas forcément à l'ensemble, un maximum si. Encadrer : somme et différence pour tous les réels, produit et quotient pour les positifs stricts. E(x) est le plus grand entier ≤ x ; (a + b)3 = a3 + 3a2b + 3ab2 + b3.
