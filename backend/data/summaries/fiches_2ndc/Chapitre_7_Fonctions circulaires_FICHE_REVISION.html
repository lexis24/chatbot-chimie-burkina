Leçon 1 : Cercle trigonométrique, radian, cosinus et sinus

Le radian est l'unité d'angle telle que 360° = 2π rad. Un angle de 1 radian découpe, sur un cercle de rayon 1, un arc de longueur 1.

CONVERSIONS DEGRES ↔ RADIANS
180° = π   90° = π2   60° = π3   45° = π4   30° = π6
degrés → radians : × π180    radians → degrés : × 180π

Cercle trigonométrique et enroulement

  • Cercle trigonométrique : cercle de centre O et de rayon 1, muni du sens direct, contraire à celui des aiguilles d'une montre. I(1 ; 0) est le point de départ, J(0 ; 1).
  • Enroulement : à tout réel x on associe le point image M, obtenu en parcourant à partir de I un arc de longueur |x|, dans le sens direct si x est positif, dans l'autre sens si x est négatif.
  • Un réel a un seul point image ; un point du cercle est l'image d'une infinité de réels, qui diffèrent d'un nombre entier de tours, soit de 2kπ avec k ∈ ℤ.

Cosinus et sinus d'un réel

M est le point image du réel x sur le cercle trigonométrique.

DEFINITION
cos x = abscisse de M    sin x = ordonnée de M
M(cos x ; sin x)

Le cosinus se lit horizontalement, sur l'axe des abscisses ; le sinus se lit verticalement, sur l'axe des ordonnées.

PROPRIETES FONDAMENTALES : pour tout réel x
−1 ≤ cos x ≤ 1     −1 ≤ sin x ≤ 1
cos2x + sin2x = 1   (identité fondamentale)

cos2x abrège (cos x)2 : ce n'est pas x que l'on élève au carré.

Ajouter des tours entiers

PERIODICITE : k ∈ ℤ
cos(x + 2kπ) = cos x    sin(x + 2kπ) = sin x

Ajouter 2kπ, c'est faire k tours complets : le point image ne bouge pas. Devant un réel quelconque, on enlève d'abord les tours, puis on reconnaît l'une des cinq formes du tableau. Un multiple pair de π vaut un nombre entier de tours, un multiple impair laisse un π à traiter.

Leçon 3 : Les fonctions x ↦ cos x et x ↦ sin x

Les deux fonctions sont définies sur ℝ, à valeurs dans [−1 ; 1], et périodiques de période 2π.

La fonction cosinus

  • Paire : cos(−x) = cos x ; courbe symétrique par rapport à l'axe des ordonnées.
  • Décroissante sur [0 ; π], de 1 à −1 ; croissante sur [π ; 2π], de −1 à 1.
  • Maximum 1 atteint en x = 2kπ ; minimum −1 en x = π + 2kπ. Sa courbe est la cosinusoïde.
x0π2π
cos x1↘−1↗1

La fonction sinus

  • Impaire : sin(−x) = −sin x ; courbe symétrique par rapport à l'origine O.
  • Croissante sur [−π2 ; π2], de −1 à 1 ; décroissante sur [π2 ; 3π2], de 1 à −1. Sa courbe est la sinusoïde.
x−π2π23π2
sin x−1↗1↘−1

Les deux courbes ont la même forme : sin x = cos(π2 − x), donc un décalage horizontal de π2. En x = 0, la cosinusoïde est en haut, au point (0 ; 1) ; la sinusoïde passe par l'origine.

Reconnaître une période

DEFINITION : T > 0 est une période de f
f(x + T) = f(x)   pour tout réel x
  • Pour prouver que T est une période, on calcule f(x + T) et l'on montre que le résultat vaut f(x), en faisant apparaître un multiple de 2π dans le cosinus ou le sinus.
  • cos et sin ont pour périodes 2π, 4π, 6π et tout multiple de 2π ; la plus petite, 2π, est appelée la période.
  • La parité se prouve de même, par le calcul de f(−x) : un dessin suggère la symétrie, seul le calcul l'établit.

Leçon 4 : Equations cos x = a et sin x = b

Chaque équation n'a de solution que si le nombre donné appartient à [−1 ; 1] ; sinon, il n'y a aucune solution.

EQUATION cos x = a, avec −1 ≤ a ≤ 1
on cherche α tel que cos α = a, puis
x = α + 2kπ  ou  x = −α + 2kπ,  k ∈ ℤ
EQUATION sin x = b, avec −1 ≤ b ≤ 1
on cherche β tel que sin β = b, puis
x = β + 2kπ  ou  x = π − β + 2kπ,  k ∈ ℤ
  • Pour cos x = a : droite verticale d'équation x = a ; les deux points images sont symétriques par rapport à l'axe des abscisses.
  • Pour sin x = b : droite horizontale ; les deux points images sont symétriques par rapport à l'axe des ordonnées.

Cas particuliers

EquationSolutionsEquationSolutions
cos x = 1x = 2kπsin x = 1x = π2 + 2kπ
cos x = −1x = π + 2kπsin x = −1x = −π2 + 2kπ

k est un entier relatif quelconque. Pour 1 et −1, la droite est tangente au cercle : les deux familles n'en font plus qu'une. Pour 0, les deux points sont diamétralement opposés, d'où le pas kπ au lieu de 2kπ.

Angle orienté et mesure principale

  • Deux vecteurs non nuls u et v définissent un angle orienté, noté (u, v) et lu du premier vecteur vers le second ; sa mesure en radians est comptée positivement dans le sens direct.
  • Si θ est une mesure de l'angle, alors toutes ses mesures sont les réels θ + 2kπ, k ∈ ℤ : deux mesures diffèrent d'un nombre entier de tours.
  • Mesure principale : l'unique mesure appartenant à ]−π ; π], borne de gauche exclue, borne de droite incluse. On l'obtient en retranchant ou en ajoutant des tours complets.
PIEGES ET ERREURS FREQUENTES
✗ sin 0 = 1  ·  cosinus et sinus échangés
✓ Le cosinus est l'abscisse, le sinus l'ordonnée. Au point de départ I(1 ; 0) : cos 0 = 1 et sin 0 = 0. Repère : l'abscisse va avec le cosinus (a avant o, c avant s) ; le cosinus est couché, le sinus est sur pied.
✗ cos x = 1,5  ·  « cos x = 2 a une solution »  ·  cos2x pris pour cos x2
✓ Le point image ne quitte pas le cercle de rayon 1 : −1 ≤ cos x ≤ 1 et −1 ≤ sin x ≤ 1 pour tout réel x : l'équation cos x = 2 n'a aucune solution. Et cos2x = (cos x)2, à distinguer de cos(x2).
✗ cos2x + sin2x = 2
✓ L'identité fondamentale vaut 1. Elle sert à contrôler un couple (cos x = 12 et sin x = 12 donnent 12 et non 1, donc c'est faux) et à calculer l'un des deux quand on connaît l'autre.
✗ 180° = π2 rad  ·  un angle noté « 60 » pour 60 degrés
✓ 180° = π rad : c'est 90° qui vaut π2. Un réel écrit sans unité est un nombre de radians : 60 vaut près de dix tours, alors que 60° = π3.
✗ cos(π − x) = cos x  ·  sin(π − x) = −sin x
✓ La symétrie par rapport à l'axe des ordonnées change l'abscisse et conserve l'ordonnée : cos(π − x) = −cos x et sin(π − x) = sin x. C'est sin(π + x) qui vaut −sin x. Un dessin de dix secondes départage les deux.
✗ cos(π2 − x) = cos x
✓ Double faute : dans les formes en π2, les deux fonctions s'échangent, car la symétrie par rapport à la droite y = x échange abscisse et ordonnée. Donc cos(π2 − x) = sin x et sin(π2 − x) = cos x.
✗ « cos est périodique de période 2π, donc elle n'est définie que sur [0 ; 2π] »  ·  parité et périodicité confondues
✓ cos est définie sur ℝ tout entier et sa courbe se prolonge indéfiniment : la période décrit la répétition du motif, pas l'ensemble de définition. Les deux propriétés sont indépendantes : x ↦ x2 est paire sans être périodique.
✗ cos x = 12 donc x = π3  ·  pour sin x = b : x = −β + 2kπ
✓ On oublie la seconde famille et le + 2kπ : x = π3 + 2kπ ou x = −π3 + 2kπ, k ∈ ℤ. Cette seconde famille est l'opposé −α pour le cosinus, mais le supplémentaire π − β pour le sinus.
A SAVOIR PAR COEUR AVANT LE DEVOIR
  1. 180° = π rad ; degrés → radians : × π180, radians → degrés : × 180π. Cercle trigonométrique : centre O, rayon 1, sens direct à partir de I(1 ; 0).
  2. cos x est l'abscisse du point image M, sin x son ordonnée : M(cos x ; sin x). Le signe se lit sur le quadrant.
  3. −1 ≤ cos x ≤ 1, −1 ≤ sin x ≤ 1 et cos2x + sin2x = 1, pour tout réel x.
  4. Valeurs remarquables : pour 0, π6, π4, π3, π2, le sinus vaut 0, 12, √22, √32, 1 ; le cosinus donne les mêmes valeurs en ordre inverse.
  5. Angles associés : cos(−x) = cos x, sin(−x) = −sin x ; cos(π − x) = −cos x, sin(π − x) = sin x ; cos(π + x) = −cos x, sin(π + x) = −sin x ; cos(π2 − x) = sin x, sin(π2 − x) = cos x.
  6. cos(x + 2kπ) = cos x et sin(x + 2kπ) = sin x : devant un grand réel, enlever d'abord les tours complets.
  7. cos est paire, sin est impaire ; toutes deux définies sur ℝ, à valeurs dans [−1 ; 1], périodiques de période 2π. cos décroît sur [0 ; π], sin croît sur [−π2 ; π2].
  8. Equations, si le nombre est dans [−1 ; 1] et k ∈ ℤ : cos x = a → x = α + 2kπ ou −α + 2kπ ; sin x = b → x = β + 2kπ ou π − β + 2kπ. Mesure principale : unique mesure dans ]−π ; π].
