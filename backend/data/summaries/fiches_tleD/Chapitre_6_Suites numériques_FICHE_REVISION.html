L'ESSENTIEL

Leçon 1 : Limites de suites : énoncés admis

Vocabulaire

Soit (un) une suite définie à partir d'un rang n0. Pour tout n ≥ n0 :

  • croissante si un+1 ≥ un ; décroissante si un+1 ≤ un ; constante si un+1 = un. Croissante ou décroissante : monotone.
  • majorée s'il existe un réel M tel que un ≤ M pour tout n ; minorée s'il existe un réel m tel que un ≥ m ; bornée si elle est majorée et minorée.
  • Si un = f(n) et si f est majorée (respectivement minorée) sur [n0 ; +∞[, la suite l'est aussi.
Un majorant n'est pas unique. Monotonie et caractère borné sont indépendants : ((−1)n) est bornée sans être monotone, (n2) monotone sans être majorée, (1n) les deux.

Convergence et divergence

(un) converge vers le réel L lorsque la distance |un − L| devient aussi petite que l'on veut à partir d'un certain rang ; on note limn→+∞ un = L. La limite d'une suite convergente est unique.

Une suite non convergente est divergente. Elle diverge vers +∞ lorsque, pour tout réel A > 0, on a un > A à partir d'un certain rang (définition analogue vers −∞) ; elle peut aussi n'avoir aucune limite, comme (−1)n. Trois cas et non deux : convergente · divergente vers ±∞ · sans limite ; on précise toujours lequel.

THEOREMES ADMIS : A PARTIR D'UN CERTAIN RANG
Comparaison : un ≤ vn et lim un = +∞ ⇒ lim vn = +∞
un ≤ vn et lim vn = −∞ ⇒ lim un = −∞
Gendarmes : un ≤ wn ≤ vn et lim un = lim vn = L ⇒ lim wn = L
Ordre : un ≤ vn, lim un = L, lim vn = L′ ⇒ L ≤ L′

Seules les inégalités larges passent à la limite : 1n > 0 pour tout n ≥ 1, et pourtant la limite vaut 0.

Encadrer. Repérer le morceau gênant (sin n, cos n, (−1)n), l'encadrer entre −1 et 1, transporter l'encadrement jusqu'à la suite (multiplier par un strictement positif conserve le sens, par un négatif le renverse), calculer les limites des bornes, puis citer le théorème par son nom.

CONVERGENCE MONOTONE (ADMIS)
croissante et majorée ⇒ convergente
décroissante et minorée ⇒ convergente

Le théorème affirme que la limite existe ; il ne la donne pas, et cette limite n'est pas le majorant : si (un) est croissante et majorée par M, on sait seulement que lim un ≤ M. C'est l'outil qui permet d'affirmer qu'une limite existe avant de savoir la calculer.

Raisonnement par récurrence

RECURRENCE : P(n) PROPRIETE, n0 ENTIER
initialisation : P(n0) est vraie
hérédité : pour tout n ≥ n0, P(n) vraie ⇒ P(n + 1) vraie
alors P(n) est vraie pour tout n ≥ n0

L'hypothèse de récurrence est supposée vraie pour un rang n fixé quelconque, jamais pour tous les n. Rédaction : écrire P(n) explicitement · vérifier P(n0) par le calcul des deux membres · partir du rang n + 1 et transformer jusqu'à utiliser visiblement l'hypothèse · conclure. Si l'hérédité n'appelle jamais l'hypothèse, la récurrence était inutile.

Etudier la monotonie

  • Signe de un+1 − un : positif ou nul, croissante ; négatif ou nul, décroissante. Méthode par défaut, valable toujours.
  • Termes tous strictement positifs : comparer un+1un à 1 ; réservé aux suites où n figure en exposant.
  • un = f(n) : signe de f′(x) sur [n0 ; +∞[.
  • Suite récurrente : la monotonie s'établit presque toujours par récurrence. Conclure en précisant à partir de quel rang.

Leçon 2 : Suites de référence et croissances comparées

SUITES DE REFERENCE : GEOMETRIQUE, PUISSANCE, LOGARITHME (a > 0)
lim an = +∞ si a > 1 ; = 1 si a = 1 ; = 0 si 0 < a < 1
lim nα = +∞ si α > 0 ; = 0 si α < 0    lim ln n = +∞

Reconnaître les déguisements : (1n3) est une puissance avec α = −3 ; (1√n) aussi, avec α = −12 ; (en) est géométrique de raison e ≈ 2,7 > 1 ; (3n2n) s'écrit ((32)n).

Arithmétiques et géométriques

TERME GENERAL ET SOMME : n, p ENTIERS NATURELS
arithmétique de raison r : un = up + (n − p) r
up + ⋯ + un = (n − p + 1) × up + un2
géométrique de raison q : un = up qn−p
up + ⋯ + un = up × 1 − qn−p+11 − q  (q ≠ 1)

La somme arithmétique est le nombre de termes multiplié par la demi-somme des extrêmes.

Convergence de ces deux suites

  • Arithmétique : converge si et seulement si r = 0 (elle est alors constante) ; si r ≠ 0, elle diverge vers +∞ ou −∞ selon le signe de r.
  • Géométrique (u0 qn) avec u0 ≠ 0 : converge vers 0 si −1 < q < 1 ; constante si q = 1 ; diverge vers ±∞ si q > 1, selon le signe de u0 ; aucune limite si q ≤ −1. Le critère porte sur |q|.
SOMME D'UNE GEOMETRIQUE DE RAISON |q| < 1
Sn = u0 + ⋯ + un = u0 1 − qn+11 − q    limn→+∞ Sn = u01 − q

Croissances comparées

POUR a > 1, α > 0, p ENTIER ≥ 1
lim annp = +∞    lim nαan = 0    lim ln nnα = 0
ln n ≪ nα ≪ an

La géométrique de raison supérieure à 1 l'emporte sur les puissances, les puissances l'emportent sur le logarithme. « L'emporte » signifie que le quotient part à l'infini : c'est ce qui lève les formes indéterminées ∞∞.

Limite d'un quotient. Repérer les références en présence · si c'est déjà un quotient de référence, citer la croissance comparée · sinon mettre le terme dominant en facteur en haut et en bas, simplifier · conclure par les opérations sur les limites en vérifiant qu'aucune nouvelle forme indéterminée n'apparaît.

Franchir un seuil

Isoler la puissance qn d'un côté et le nombre de l'autre, tous deux strictement positifs · appliquer ln, strictement croissant, donc le sens est conservé à cette étape · utiliser ln(qn) = n ln q · diviser par ln q en surveillant son signe : si 0 < q < 1, alors ln q < 0 et la division renverse l'inégalité. Conclure par le premier entier qui convient.

Leçon 3 : Suites un = f(n) et suites récurrentes

SUITE un = f(n) : f DEFINIE SUR [n0 ; +∞[
f croissante sur [n0 ; +∞[ ⇒ (un) croissante
f décroissante ⇒ (un) décroissante
lim un = limx→+∞ f(x)  (si cette limite existe)

L'implication ne vaut que dans le sens fonction vers suite : une suite peut être croissante sans que f le soit, car la suite ne regarde que les valeurs entières. La réciproque est fausse.

Etude pratique. Simplifier d'abord l'écriture (division, terme dominant en facteur) : une forme un = a − bn + c livre monotonie et limite d'un seul coup · monotonie par un+1 − un ou par f′ · limite par celle de f en +∞, au besoin par croissances comparées.

Suite récurrente un+1 = f(un)

On se donne le premier terme u0 et une fonction f.

  • Stabilité d'un intervalle : si u0 ∈ I et si f(I) ⊂ I, c'est-à-dire si x ∈ I entraîne f(x) ∈ I, alors tous les termes restent dans I. Se démontre par récurrence et fournit les bornes.
  • Monotonie : signe de un+1 − un lorsque le calcul est possible, sinon par récurrence.
LIMITE EVENTUELLE : POINT FIXE
(un) converge vers L et f continue en L ⇒ L = f(L)

Un point fixe est l'abscisse d'un point d'intersection de la courbe y = f(x) avec la droite y = x. Quand il y en a plusieurs, on retient celui qui est compatible avec l'intervalle stable et l'on écarte les autres en le justifiant.

Plan d'étude d'une suite récurrente

1. Trouver un intervalle I stable contenant u0, puis démontrer par récurrence que tous les termes appartiennent à I : on obtient ainsi un minorant et un majorant.  2. Etudier la monotonie.  3. Conclure à la convergence en citant le théorème de convergence monotone.  4. Résoudre L = f(L) et retenir la solution qui appartient à I.  5. Cas particulier : si f est affine, f(x) = ax + b avec a ≠ 1, poser vn = un − L (L point fixe) : (vn) est géométrique de raison a, ce qui donne un en fonction de n.

Constructions graphiques. Partir de u0 sur l'axe des abscisses, monter jusqu'à la courbe pour lire u1 = f(u0), rejoindre horizontalement y = x, recommencer. f croissante : escalier, suite monotone. f décroissante : escargot, termes alternativement de part et d'autre du point fixe. La figure suggère, elle ne démontre pas.
PIEGES ET ERREURS FREQUENTES
✗ ((−1)n) est bornée, donc elle converge  ·  lim (−1)n = 0 car elle oscille autour de 0
✓ Bornée n'implique pas convergente : la suite vaut 1, −1, 1, −1, … et n'a pas de limite ; ses termes restent à distance 1 de 0. Il faut la monotonie en plus : croissante majorée ou décroissante minorée. Inversement, ((−1)nn) converge vers 0 sans être monotone.
✗ L = f(L) donne L = 5, donc lim un = 5
✓ Le point fixe n'est la limite que si la suite converge : il faut d'abord la prouver monotone et bornée. Avec u0 = 1 et un+1 = 2un, le point fixe est 0 et la suite diverge vers +∞.
✗ lim n22n = +∞ car n2 → +∞
✓ Les deux termes tendent vers +∞ : c'est une forme indéterminée. Par croissance comparée, la géométrique l'emporte sur la puissance, donc cette limite vaut 0.
✗ Toute suite arithmétique converge, puisque un+1 − un est constant  ·  pour q = −1, on ne peut pas conclure sur (qn)
✓ Une arithmétique converge seulement si r = 0 ; sinon elle diverge vers +∞ ou −∞ selon le signe de r. Et ((−1)n) n'a pas de limite : pour une géométrique, le critère porte sur |q|, pas de limite dès que q ≤ −1, limite 0 si |q| < 1.
✗ P(0), P(1) et P(2) sont vraies, donc P(n) est vraie pour tout n  ·  l'hérédité est démontrée, donc la propriété est vraie
✓ Trois vérifications ne font qu'une conjecture : il faut l'hérédité. Et sans initialisation, rien ne tombe : « n > n » est héréditaire et pourtant fausse partout. Les deux étapes sont exigées, plus la phrase de conclusion.
✗ un < vn pour tout n, donc L < L′
✓ Seules les inégalités larges se conservent : on écrit L ≤ L′. Ainsi 1n > 0 pour tout n ≥ 1, et la limite vaut 0.
✗ 0,8n < 0,01 donne n < ln 0,01ln 0,8
✓ ln 0,8 < 0 : la division par un nombre négatif renverse l'inégalité, donc n > ln 0,01ln 0,8. Ce n'est pas ln qui change le sens : lui le conserve.
A SAVOIR PAR COEUR AVANT LE DEVOIR
  1. Croissante et majorée (ou décroissante et minorée) ⇒ converge. Bornée ≠ convergente. Trois cas : convergente · divergente vers ±∞ · sans limite.
  2. Récurrence : P(n0) vraie (initialisation) · P(n) ⇒ P(n + 1) (hérédité) · conclusion pour tout n ≥ n0. L'hypothèse doit servir dans l'hérédité.
  3. Gendarmes : un ≤ wn ≤ vn avec un, vn → L ⇒ wn → L. Comparaison : un ≤ vn et un → +∞ ⇒ vn → +∞. Seules les inégalités larges passent à la limite.
  4. Définitions : majorée, il existe M avec un ≤ M · minorée, il existe m avec un ≥ m · bornée, les deux · monotone, croissante ou décroissante.
  5. Arithmétique : un = up + (n − p)r · somme = (nombre de termes) × (demi-somme des extrêmes) · converge ⇔ r = 0. Géométrique : un = up qn−p · somme = up 1 − qnb1 − q · lim Sn = u01 − q si |q| < 1.
  6. Références : an → +∞ si a > 1, → 0 si |a| < 1, pas de limite si a ≤ −1 · nα → +∞ si α > 0 · ln n → +∞. Croissances comparées, pour a > 1 et α > 0 : annp → +∞, nαan → 0, ln nnα → 0.
  7. Seuil : isoler qn, appliquer ln, renverser l'inégalité si ln q < 0. un = f(n) : monotonie et limite via f, sens fonction vers suite seulement. un+1 = f(un) : intervalle stable par récurrence · monotonie · convergence ⇒ L = f(L) ; f affine, poser vn = un − L. Réflexe : justifier la convergence avant d'exploiter le point fixe.
