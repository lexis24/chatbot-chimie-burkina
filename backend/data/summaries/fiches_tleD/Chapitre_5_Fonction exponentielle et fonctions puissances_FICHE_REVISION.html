Leçon 1 : Fonction exponentielle

Définition

ln est continue, strictement croissante sur ]0 ; +∞[, de limites −∞ en 0+ et +∞ en +∞ : elle réalise une bijection de ]0 ; +∞[ sur ℝ. La fonction exponentielle népérienne, notée exp, est sa bijection réciproque : définie sur ℝ, à valeurs dans ]0 ; +∞[.

EQUIVALENCE FONDAMENTALE : x REEL, y > 0
y = exp(x) ⇔ x = ln y
ln(exp x) = x (x ∈ ℝ)     exp(ln y) = y (y > 0)

L'écriture x = ln y exige y > 0, alors que y = exp(x) n'exige rien de x : appliquer exp ne perd aucune solution, appliquer ln impose de vérifier une condition d'existence.

Le nombre e et la notation ex

Comme ln e = 1, on a exp(1) = e ≈ 2,718. On convient de noter exp(x) = ex.

  • e0 = 1 et e1 = e ;
  • ex > 0 pour tout réel x : l'exponentielle ne s'annule jamais et n'est jamais négative.
RELATION FONCTIONNELLE ET REGLES DE CALCUL : a, b, r REELS
ea+b = ea × eb
e−b = 1eb    ea−b = eaeb    (ea)r = era
ln(ea) = a     eln y = y (y > 0)

Equations et inéquations

STRICTE CROISSANCE DE exp : A, B REELS
eA = eB ⇔ A = B     eA < eB ⇔ A < B
eA = k : aucune solution si k ≤ 0 ; solution unique A = ln k si k > 0

Sens de l'inégalité conservé. Si l'inconnue figure dans e2x et ex, poser X = ex > 0, résoudre en X, puis écarter les valeurs ≤ 0.

Dérivée et sens de variation

DERIVEES : u DERIVABLE SUR UN INTERVALLE I
(ex)′ = ex     (eu)′ = u′ eu

exp est dérivable sur ℝ (admis), donc continue ; comme ex > 0, elle est strictement croissante. Pour eu : recopier l'exponentielle, multiplier par u′, sans toucher à l'exposant. Dans un produit P(x) eu(x), mettre eu > 0 en facteur : le signe est celui du facteur restant.

Limites, tangentes et courbe

  • limx→+∞ ex = +∞  ·  limx→−∞ ex = 0+ : l'axe des abscisses est asymptote horizontale en −∞, la courbe restant strictement au-dessus.
  • Près de 0 : ex ≈ 1 + x, c'est-à-dire limu→0 eu − 1u = 1 (nombre dérivé de exp en 0).
  • Tangentes : en B(0 ; 1), y = x + 1 ; en A(1 ; e), y = e x (elle passe par l'origine). Pour tout réel x, ex ≥ 1 + x : la courbe est au-dessus de sa tangente en B.
  • En +∞, exx → +∞ : branche parabolique de direction (Oy). Les courbes de exp et de ln sont symétriques par rapport à la droite y = x.

Modéliser une croissance ou une décroissance

MODELE EXPONENTIEL : N0 > 0 VALEUR INITIALE, k ≠ 0
N(t) = N0 ekt  avec N(0) = N0
  • k > 0 : croissance, limt→+∞ N(t) = +∞  ·  k < 0 : décroissance, limt→+∞ N(t) = 0+, asymptote y = 0.
  • Temps de doublement (k > 0) : T tel que N(T) = 2N0  ·  demi-vie (k < 0) : T tel que N(T) = N02. Dans les deux cas, T ne dépend pas de N0.

Traduire la question par une équation, diviser par N0 non nul, appliquer ln, résoudre en t, conclure avec l'unité : une durée doit être positive.

Leçon 2 : Puissances réelles d'un réel strictement positif

DEFINITION : a > 0 ET b REEL QUELCONQUE
ab = eb ln a

Cette définition prolonge les puissances entières et conserve ln(ab) = b ln a pour tout réel b. La condition a > 0 est une nécessité : sans elle, ln a n'existe pas. Conséquences : ab > 0 toujours ; a0 = 1 ; a1 = a ; 1b = 1 pour tout réel b ; eb ln e = eb, la notation est cohérente.

Règles de calcul

POUR a > 0, a′ > 0 ET b, c REELS
ab × ac = ab+c    abac = ab−c    a−b = 1ab
(ab)c = abc    (a a′)b = ab a′b    (aa′)b = aba′b
ln(ab) = b ln a     a1/n = n√a (n entier ≥ 1)

Toutes se démontrent depuis la définition, par exemple ab × ac = e(b+c) ln a : ce sont les règles des puissances entières, valables pour tout exposant réel. Pour calculer, écrire la base comme puissance d'un nombre plus petit : 8 = 23, 27 = 33, 81 = 34.

Fonction exponentielle de base a

Pour a > 0 fixé, x ↦ ax = ex ln a est définie et dérivable sur ℝ, à valeurs strictement positives.

DERIVEE DE LA FONCTION x ↦ ax
(ax)′ = (ln a) ax

Comme ax > 0, le signe de la dérivée est celui de ln a :

  • a > 1 : strictement croissante, de limite 0 en −∞ et +∞ en +∞ ;
  • a = 1 : fonction constante égale à 1 ;
  • 0 < a < 1 : strictement décroissante, de limite +∞ en −∞ et 0 en +∞.
  • Toutes ces courbes passent par le point (0 ; 1).

Evolutions en pourcentage

Une hausse de p % par période a pour coefficient 1 + p100 : après t périodes, P(t) = P0 (1 + p100)t ; une perte de 20 % suit V0 (0,8)t. Les écritures at et ekt décrivent le même phénomène, avec k = ln a : a > 1 ⇔ k > 0.

RESOUDRE at = k : a > 0, a ≠ 1, k > 0
t = ln kln a

Appliquer ln fait descendre l'inconnue de l'exposant. Pour une inéquation, la division par ln a change le sens lorsque 0 < a < 1, car ln a est alors négatif.

Leçon 3 : Fonctions puissances et racines n-ièmes

FONCTION PUISSANCE : α REEL FIXE, SUR ]0 ; +∞[
xα = eα ln x     (xα)′ = α xα−1

Elle se déduit de (eu)′ = u′eu avec u(x) = α ln x, et prolonge à tout exposant réel la formule de première : (√x)′ = 12 x−1/2 = 12√x. Se placer d'abord sur ]0 ; +∞[.

Sens de variation et allure

Sur ]0 ; +∞[, xα−1 > 0 : le signe de α xα−1 est celui de α.

  • α > 0 : strictement croissante, limx→0+ xα = 0 et limx→+∞ xα = +∞ ;
  • α < 0 : strictement décroissante, limx→0+ xα = +∞ et limx→+∞ xα = 0 : les deux axes sont asymptotes ;
  • α = 0 : fonction constante égale à 1, droite y = 1. Toutes ces courbes passent par (1 ; 1).

Racine n-ième

Pour n entier ≥ 1, x ↦ xn est continue et strictement croissante de [0 ; +∞[ sur [0 ; +∞[ : c'est une bijection, de réciproque la racine n-ième.

RACINE n-IEME : x ≥ 0, y ≥ 0
y = n√x ⇔ x = yn     n√x = x1/n (x > 0)
xn = k (k > 0) ⇔ x = n√k = k1/n

En particulier 2√x = √x. Les courbes de x ↦ xn et de x ↦ n√x sont symétriques par rapport à y = x ; xn = k a une solution unique dans ]0 ; +∞[ : valeur exacte d'abord, approximation ensuite.

Leçon 4 : Croissances comparées

CROISSANCES COMPAREES : POUR TOUT REEL α > 0
limx→+∞ exxα = +∞    limx→+∞ ln xxα = 0
limx→0+ xα ln x = 0    limx→−∞ xn ex = 0 (n entier ≥ 1)

A l'infini, l'exponentielle l'emporte sur les puissances, et les puissances sur le logarithme ; un exposant plus grand ne change que le moment du croisement.

Formes indéterminées

Les formes ∞∞, 0 × ∞ et ∞ − ∞ sont indéterminées : il faut transformer l'écriture. Limites de référence :

  • limx→+∞ xαex = 0 et limx→+∞ xα e−x = 0 ;
  • limx→+∞ (x − ln x) = +∞ et limx→+∞ (ex − xn) = +∞, après factorisation ;
  • limu→0 eu − 1u = 1, d'où limx→0 e3x − 1x = 3 en posant u = 3x.
Méthode. Nommer la forme obtenue, repérer le terme dominant selon la hiérarchie exponentielle, puissances, logarithme, puis le mettre en facteur pour faire apparaître un quotient de référence : ex − x10 = ex(1 − x10ex) → +∞.
PIEGES ET ERREURS FREQUENTES
✗ e2+3 = e2 + e3  ·  e2x = 2ex  ·  1ex = −ex
✓ L'exponentielle change la somme en produit : e2+3 = e2 × e3 = e5, alors que e0 + e0 = 2 et e0+0 = 1. Et e2x = (ex)2, 1ex = e−x.
✗ (1 + x)ex = 0 pour x = −1 ou ex = 0
✓ ex = 0 n'a aucune solution, car ex > 0 : la seule solution est x = −1. Un facteur eu ne change jamais un signe et ne s'annule jamais ; une somme comme ex + x ne se factorise pas.
✗ x ↦ 2x et x ↦ x2, c'est pareil  ·  (2x)′ = x 2x−1
✓ Dans 2x la variable est en exposant, dans x2 en base : 210 = 1024 contre 102 = 100. Les dérivées diffèrent : (2x)′ = (ln 2) 2x mais (xa)′ = a xa−1.
✗ x0,7 est définie pour tout réel x  ·  (−8)1/3 = −2
✓ xα = eα ln x exige x > 0 : (−3)0,5, 0−2 et (−8)1/3 n'ont pas de sens. Seuls les exposants entiers y échappent : x ↦ x3 est définie sur ℝ.
✗ limx→+∞ exx5 est une forme ∞∞, donc elle vaut 1  ·  exx100 → 0
✓ Une forme indéterminée n'a aucune valeur automatique. Par croissance comparée, l'exponentielle l'emporte sur toute puissance, même x100 : les deux limites valent +∞.
✗ L'exponentielle est toujours plus grande que toute puissance
✓ Faux au début : sur [2 ; 4], x3 dépasse ex (en x = 3 : 27 contre e3 ≈ 20,1). La croissance comparée ne parle que de l'infini : l'exponentielle finit par dépasser toute puissance.
✗ +6 % par an pendant dix ans, donc +60 %  ·  0,9t < 0,5 donne t < ln 0,5ln 0,9
✓ Les pourcentages se multiplient : le coefficient est (1,06)10, soit environ +79 %. Et ln 0,9 est négatif : la division retourne l'inégalité, donc t > ln 0,5ln 0,9.
A SAVOIR PAR COEUR AVANT LE DEVOIR
  1. exp est la réciproque de ln : y = ex ⇔ x = ln y (y > 0) ; e0 = 1, ex > 0 toujours, e ≈ 2,718 ; ln(ex) = x, eln y = y.
  2. ea+b = eaeb, ea−b = eaeb, e−b = 1eb, (ea)r = era, et jamais ea + eb.
  3. eA = eB ⇔ A = B, eA < eB ⇔ A < B (sens conservé) ; eA = k n'a de solution que si k > 0, et alors A = ln k ; si l'inconnue figure dans e2x et ex, poser X = ex > 0.
  4. (ex)′ = ex, (eu)′ = u′eu ; exp strictement croissante ; 0+ en −∞ (asymptote (Ox)), +∞ en +∞ (branche parabolique (Oy)) ; tangentes y = x + 1 en 0 et y = ex en 1 ; ex ≥ 1 + x.
  5. Modèle N(t) = N0ekt : N0 valeur initiale, k > 0 croissance, k < 0 décroissance (asymptote y = 0). Doublement et demi-vie : diviser par N0 puis appliquer ln ; indépendants de N0.
  6. ab = eb ln a (a > 0) ; (ax)′ = (ln a)ax, croissante si a > 1, décroissante si 0 < a < 1, courbes par (0 ; 1) ; hausse de p % : coefficient 1 + p100 et at = k ⇔ t = ln kln a.
  7. (xα)′ = α xα−1 sur ]0 ; +∞[ ; croissante si α > 0, décroissante si α < 0, courbes par (1 ; 1) ; y = n√x ⇔ x = yn (x, y ≥ 0), n√x = x1/n. Ne pas confondre ax et xa.
  8. A l'infini : exp l'emporte sur les puissances, les puissances sur ln ; factoriser le terme dominant.
