Leçon 1 : Définition et propriétés algébriques de ln

Définition

La fonction logarithme népérien, notée ln, est la primitive sur ]0 ; +∞[ de la fonction x ↦ 1x qui s'annule en 1. Donc :

  • ln est définie sur ]0 ; +∞[ : ln x n'a de sens que pour x > 0 ;
  • ln′(x) = 1x pour tout x > 0 ;
  • ln 1 = 0.

Composée. ln(u(x)) existe si et seulement si x appartient au domaine de u et u(x) > 0. Chercher l'ensemble de définition de ln u, c'est résoudre u(x) > 0.

PROPRIETES ALGEBRIQUES : pour a > 0, b > 0, n ∈ ℤ
ln(a×b) = ln a + ln b
ln 1b = −ln b     ln ab = ln a − ln b
ln(an) = n ln a
ln√a = 12ln a     ln n√a = 1nln a  (n ≥ 1)

Le logarithme abaisse d'un cran chaque opération : produit → somme, quotient → différence, puissance → produit, racine → quotient.

Leçon 2 : Etude de la fonction ln

Variations et signe

ln′(x) = 1x > 0 sur ]0 ; +∞[ : ln est strictement croissante sur ]0 ; +∞[.

ln x > 0 ⇔ x > 1  ·  ln x < 0 ⇔ 0 < x < 1  ·  ln 1 = 0.

OUTIL DE RESOLUTION : pour a > 0, b > 0
ln a = ln b ⇔ a = b
ln a < ln b ⇔ a < b

Bijection et nombre e

ln est continue (car dérivable) et strictement croissante, avec limx→0+ ln x = −∞ et limx→+∞ ln x = +∞ : elle réalise une bijection de ]0 ; +∞[ sur ℝ. Pour tout réel k, l'équation ln x = k admet une unique solution.

Le nombre e (nombre de Neper) est l'unique réel tel que ln e = 1 ; 2 < e < 3 et e ≈ 2,718. Pour tout n ∈ ℤ : ln(en) = n.

RESOLUTION DE BASE
ln x = k ⇔ x = ek  (x > 0)

Dérivation

DERIVEE DE ln u
(ln u)′ = u′u     (ln x)′ = 1x

u dérivable et strictement positive sur l'intervalle I. Comme u > 0, u′u a le signe de u′ : ln u varie dans le même sens que u.

Limites, tangentes et courbe

  • limx→0+ ln x = −∞ : l'axe des ordonnées (x = 0) est asymptote verticale.
  • limx→+∞ ln x = +∞ ; branche parabolique de direction (Ox) : aucune asymptote horizontale.
  • Près de 0 : ln(1 + x) ≈ x, c'est-à-dire limx→0 ln(1 + x)x = 1.
  • Tangentes : en A(1 ; 0), y = x − 1 ; en B(e ; 1), y = xe (elle passe par l'origine).

Egalité ln x = x − 1 seulement pour x = 1. Face à une puissance de x, le logarithme perd toujours.

Leçon 3 : Logarithme décimal et applications

DEFINITION DU LOGARITHME DECIMAL
log x = ln xln 10  sur ]0 ; +∞[

Comme ln 10 > 0, log a les mêmes propriétés algébriques et le même sens de variation que ln :

  • log(ab) = log a + log b ; log ab = log a − log b ; log(an) = n log a ;
  • log 1 = 0, log 10 = 1, log(10n) = n ;
  • log strictement croissante, et log x > 0 ⇔ x > 1 ;
  • log x = k ⇔ x = 10k  (x > 0).

Ces échelles comptent les puissances de 10 : la grandeur physique est multipliée par 10 quand M augmente de 1, quand L augmente de 10 dB, et quand le pH diminue de 1 (le signe moins renverse le sens).

Nombre de chiffres. Si N est un entier naturel non nul et si p est l'entier tel que p ≤ log N < p + 1, alors 10p ≤ N < 10p+1 : N possède exactement p + 1 chiffres.

PIEGES ET ERREURS FREQUENTES
✗ ln(a + b) = ln a + ln b
✓ ln ne se distribue pas sur une somme : la règle vaut pour le produit, ln(ab) = ln a + ln b. Ainsi ln(2 + 3) = ln 5 ≈ 1,61 alors que ln 2 + ln 3 = ln 6 ≈ 1,79.
✗ ln(−2) existe et vaut un nombre négatif
✓ ln est définie seulement sur ]0 ; +∞[ : ln(−2) n'existe pas.
✗ (ln 5)2 = 2 ln 5
✓ C'est ln(52) qui vaut 2 ln 5 ; dans (ln 5)2 le carré porte sur le résultat : (ln 5)2 ≈ 2,59 contre 2 ln 5 ≈ 3,22.
✗ Dans ln(3 − x), la condition est x > 0
✓ C'est la quantité écrite sous le logarithme qui doit être strictement positive : 3 − x > 0, donc x < 3.
✗ On résout ln(x − 1) = ln 5 par x − 1 = 5, sans plus
✓ La condition d'existence x − 1 > 0 se pose avant, et les solutions se confrontent à elle après : elle fait partie de la réponse.
✗ ln croît lentement, donc sa courbe admet une asymptote horizontale en +∞
✓ limx→+∞ ln x = +∞ : aucun plafond. La lenteur se traduit par ln xx → 0, donc une branche parabolique de direction (Ox).
✗ 0,9n < 0,5 donne n < ln 0,5ln 0,9
✓ ln 0,9 est négatif : la division retourne l'inégalité, donc n > ln 0,5ln 0,9. Ce n'est pas ln qui change le sens, c'est la division par un nombre négatif.
✗ (ln(3x − 1))′ = 13x − 1  ·  log et ln confondus
✓ Le numérateur u′ ne s'oublie pas : (ln(3x − 1))′ = 33x − 1. Et log x = ln xln 10 : les deux fonctions sont distinctes.
A SAVOIR PAR COEUR AVANT LE DEVOIR
  1. ln est définie sur ]0 ; +∞[, ln 1 = 0, ln e = 1, ln′(x) = 1x.
  2. Les quatre règles : ln(ab), ln ab, ln(an), ln√a, et jamais ln(a + b).
  3. ln a = ln b ⇔ a = b et ln a < ln b ⇔ a < b (a, b > 0).
  4. ln x = k ⇔ x = ek  ·  log x = k ⇔ x = 10k.
  5. (ln u)′ = u′u, valable là où u > 0 ; ln u varie comme u.
  6. Limites : −∞ en 0+ (asymptote x = 0), +∞ en +∞ ; ln xx → 0 en +∞ et x ln x → 0 en 0+.
  7. Tangentes : y = x − 1 en 1, y = xe en e ; branche parabolique de direction (Ox).
  8. Poser la condition d'existence, puis confronter les solutions trouvées à cette condition.
