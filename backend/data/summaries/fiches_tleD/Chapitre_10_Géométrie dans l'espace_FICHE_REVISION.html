Leçon 1 : Vecteurs et produit scalaire dans l'espace

Repère et coordonnées

Un repère de l'espace (O ; i, j, k) est la donnée d'une origine O et de trois vecteurs non coplanaires. Tout point M s'écrit alors d'une seule façon OM = x i + y j + z k : le triplet (x ; y ; z) donne les coordonnées de M(x ; y ; z), avec x abscisse, y ordonnée, z cote. Cette unicité autorise l'identification coordonnée par coordonnée.

Base orthonormée : les trois vecteurs sont unitaires (de norme 1) et deux à deux orthogonaux ; le repère est alors orthonormé. Sauf mention contraire, tous les repères du chapitre le sont.

Trois vecteurs sont coplanaires lorsqu'ils admettent des représentants dans un même plan. Une base de l'espace est formée de trois vecteurs non coplanaires.

Calcul vectoriel sur les coordonnées

Pour u(x ; y ; z), v(x′ ; y′ ; z′) et α réel, les règles du plan restent valables, avec une coordonnée de plus :

  • u + v (x + x′ ; y + y′ ; z + z′)  ·  αu (αx ; αy ; αz)  ·  AB (xB − xA ; yB − yA ; zB − zA) ;
  • Egalité : u = v si et seulement si x = x′, y = y′ et z = z′ ;
  • Colinéarité (avec u ≠ 0) : u et v sont colinéaires s'il existe un réel k tel que v = k u, c'est-à-dire x′ = kx, y′ = ky, z′ = kz ;
  • Milieu I de [AB] : (xA + xB2 ; yA + yB2 ; zA + zB2).
NORME ET DISTANCE : EN REPERE ORTHONORME
‖u‖ = √x2 + y2 + z2
AB = ‖AB‖ = √(xB − xA)2 + (yB − yA)2 + (zB − zA)2

Grande diagonale d'un pavé droit de dimensions a, b, c : √a2 + b2 + c2. Hors repère orthonormé, les axes ne sont pas perpendiculaires : ces formules sont fausses.

Produit scalaire

PRODUIT SCALAIRE : EN BASE ORTHONORMEE
u⋅v = xx′ + yy′ + zz′
u⋅v = ‖u‖ ‖v‖ cos θ   (u, v non nuls, 0 ≤ θ ≤ π)
u ⊥ v ⇔ u⋅v = 0

Propriétés admises : symétrie u⋅v = v⋅u ; bilinéarité (αu + βv)⋅w = α (u⋅w) + β (v⋅w) ; u⋅u = ‖u‖2. Le produit scalaire est un nombre. Un produit scalaire nul exprime l'orthogonalité : il n'oblige aucun des deux vecteurs à être nul.

Angle de deux vecteurs

COSINUS DE L'ANGLE : u ET v NON NULS
cos θ = u⋅v‖u‖ × ‖v‖
cos ∠BAC = AB⋅ACAB × AC

Pour un angle en un sommet, les deux vecteurs partent de ce sommet. Le signe du produit scalaire donne la nature de l'angle : positif → aigu, nul → droit, négatif → obtus. Contrôle : cos θ appartient à [−1 ; 1] ; une valeur hors de cet intervalle signale une norme mal calculée.

Leçon 2 : Orientation et produit vectoriel

Orientation de l'espace

L'orientation est une convention. Une base orthonormée (i, j, k) est directe lorsqu'elle respecte la règle de la main droite : le pouce donne i, l'index j, le majeur k ; sinon elle est indirecte.

Règle de l'observateur : un observateur placé le long de k, les pieds à l'origine et la tête du côté de k, regardant dans la direction de i, voit j à sa gauche si la base est directe, à sa droite si elle est indirecte.

  • Les permutations circulaires conservent l'orientation : (i, j, k), (j, k, i), (k, i, j) sont directes ;
  • échanger deux vecteurs inverse l'orientation : (i, k, j), (j, i, k), (k, j, i) sont indirectes.

Moyen de retenir : écrire i j k i j k ; trois lettres consécutives lues dans cet ordre forment une base directe. La mention orthonormé direct est nécessaire, car la formule du produit vectoriel change de signe en base indirecte.

Produit vectoriel : définition

Le produit vectoriel de u et v, noté u∧v et lu « u vectoriel v », est un vecteur :

  • si u et v sont colinéaires (en particulier si l'un est nul), u∧v = 0 ;
  • sinon, u∧v est caractérisé par : sa direction, il est orthogonal à u et à v, donc au plan qu'ils déterminent ; sa norme, ‖u∧v‖ = ‖u‖ ‖v‖ sin θ ; son sens, tel que la base (u, v, u∧v) soit directe.
COORDONNEES : EN BASE ORTHONORMEE DIRECTE
u∧v = (yz′ − zy′ ; zx′ − xz′ ; xy′ − yx′)
i∧j = k  ·  j∧k = i  ·  k∧i = j

Disposition pratique : coordonnées en deux colonnes, on masque tour à tour la 1re, la 2e, puis la 3e ligne ; les trois déterminants 2 × 2 obtenus donnent les composantes, avec un signe moins au milieu.

Propriétés du produit vectoriel (admises)

  • Anticommutativité : v∧u = − u∧v ; en particulier u∧u = 0 ;
  • Critère de colinéarité : u∧v = 0 si et seulement si u et v sont colinéaires ;
  • Bilinéarité : (αu)∧(βv) = αβ (u∧v) et u∧(v + w) = u∧v + u∧w ;
  • Orthogonalité : (u∧v)⋅u = 0 et (u∧v)⋅v = 0.
Vérification systématique. Après tout calcul de u∧v, contrôler que les deux produits scalaires ci-dessus sont nuls : deux lignes qui repèrent aussitôt une erreur de signe. Le produit vectoriel n'est pas associatif : ne jamais écrire u∧v∧w sans parenthèses.

Leçon 3 : Distances, aires et volumes

Aires

Soit u et v non colinéaires, A un point, B et D les points tels que AB = u et AD = v.

AIRES
parallélogramme ABCD :  Aire = ‖u∧v‖
triangle ABD :  Aire = 12 ‖u∧v‖ = 12 ‖AB∧AD‖

Comme sin θ ≤ 1, on a toujours ‖u∧v‖ ≤ ‖u‖ × ‖v‖, avec égalité si et seulement si u et v sont orthogonaux : une aire supérieure au produit des deux longueurs est fausse.

Produit mixte et volumes

Pour trois vecteurs, le nombre (u∧v)⋅w est le produit mixte, noté aussi det(u, v, w).

VOLUMES
parallélépipède :  V = |(u∧v)⋅w|
tétraèdre :  V = 16 |(u∧v)⋅w|
hauteur d'un tétraèdre :  h = 3Vaire de la base

Critère de coplanarité : (u∧v)⋅w = 0 si et seulement si u, v, w sont coplanaires (le volume est plat). Le produit mixte est positif si (u, v, w) est directe, négatif sinon : d'où la valeur absolue, un volume étant positif.

Distances

DISTANCES D'UN POINT M
à la droite (D) :  d(M, (D)) = ‖AM∧u‖‖u‖
au plan (P) :  d(M, (P)) = |AM⋅n|‖n‖

Dans les deux cas, A est un point de l'objet visé : la droite (D) de vecteur directeur u, le plan (P) de vecteur normal n. Discrimination : droite → directeur, produit vectoriel, barres de norme ; plan → normal, produit scalaire, barres de valeur absolue. Entre deux points, AB = ‖AB‖.

Si le plan est donné par trois points A, B, C non alignés, un vecteur normal est n = AB∧AC.

Equation cartésienne d'un plan

Un plan de vecteur normal n(a ; b ; c), avec n ≠ 0, admet une équation ax + by + cz + d = 0 ; le réel d se détermine en écrivant qu'un point connu du plan vérifie l'équation. Réciproquement, toute équation de cette forme est celle d'un plan de vecteur normal n(a ; b ; c) : les coefficients de x, y, z se lisent directement comme un vecteur normal.

DISTANCE A UN PLAN D'EQUATION DONNEE : M(x0 ; y0 ; z0)
d(M, (P)) = |ax0 + by0 + cz0 + d|√a2 + b2 + c2

C'est la formule précédente écrite en coordonnées. Elle exige zéro au second membre : 2x − y + 2z = 3 se ramène d'abord à 2x − y + 2z − 3 = 0. Le résultat est positif ou nul, et nul exactement lorsque M appartient au plan. Enfin, une droite est orthogonale à un plan lorsque son vecteur directeur est normal au plan.

PIEGES ET ERREURS FREQUENTES
✗ u⋅v est un vecteur orthogonal à u et v  ·  cos θ = u⋅vu∧v
✓ u⋅v est un nombre : pas de flèche sur le résultat. C'est u∧v qui est le vecteur orthogonal aux deux. On ne divise pas un nombre par un vecteur : cos θ = u⋅v‖u‖ × ‖v‖.
✗ u(1 ; 2 ; 5) et v(3 ; −1 ; 4) : u⋅v = 3 − 2 = 1
✓ Dans l'espace, le produit scalaire comporte trois termes : u⋅v = 3 − 2 + 20 = 21. Oublier le terme en z fait conclure faussement à une orthogonalité. Et xx′ + yy′ + zz′ n'est valable qu'en base orthonormée.
✗ Aire du triangle = ‖u∧v‖  ·  volume du tétraèdre = 13|(u∧v)⋅w|
✓ ‖u∧v‖ est l'aire du parallélogramme ; le triangle en est la moitié, 12 ‖u∧v‖. Le tétraèdre vaut 16|(u∧v)⋅w| : 13 pour la pyramide, 12 parce que sa base est un triangle.
✗ u∧v = v∧u  ·  on écrit u∧v∧w
✓ Le produit vectoriel est anticommutatif : v∧u = − u∧v. L'ordre est sans effet sur une aire (les normes sont égales) mais change le sens du vecteur normal. Il n'est pas associatif : (u∧v)∧w et u∧(v∧w) diffèrent, d'où les parenthèses.
✗ (i, k, j) est directe puisqu'elle contient les mêmes vecteurs que (i, j, k)
✓ Echanger deux vecteurs inverse l'orientation ; seules les permutations circulaires la conservent. (j, k, i) et (k, i, j) sont directes, (i, k, j) est indirecte.
✗ d(M, (D)) = |AM⋅u|‖u‖ pour une droite de vecteur directeur u
✓ Les deux formules ne se mélangent pas : droite → vecteur directeur et produit vectoriel, d = ‖AM∧u‖‖u‖ ; plan → vecteur normal et produit scalaire, d = |AM⋅n|‖n‖. Regarder ce que l'énoncé fournit avant de choisir.
✗ Le plan a pour équation 2x − y + 2z = 3, donc d(A, (P)) = |2xA − yA + 2zA|3
✓ La formule exige zéro au second membre. On écrit d'abord 2x − y + 2z − 3 = 0, puis d = |2xA − yA + 2zA − 3|3.
✗ ‖u∧v‖ = ‖u‖ × ‖v‖ toujours
✓ ‖u∧v‖ = ‖u‖ ‖v‖ sin θ ≤ ‖u‖ × ‖v‖, avec égalité seulement si u et v sont orthogonaux. Le produit scalaire, lui, fait intervenir cos θ.
A SAVOIR PAR COEUR AVANT LE DEVOIR
  1. Repère orthonormé : ‖u‖ = √x2 + y2 + z2, AB = √(xB − xA)2 + (yB − yA)2 + (zB − zA)2, diagonale d'un pavé √a2 + b2 + c2 ; milieu : moyenne des coordonnées.
  2. Produit scalaire : u⋅v = xx′ + yy′ + zz′ = ‖u‖ ‖v‖ cos θ ; u ⊥ v ⇔ u⋅v = 0 ; cos θ = u⋅v‖u‖ × ‖v‖, à valeurs dans [−1 ; 1] ; le signe donne aigu, droit ou obtus.
  3. Produit vectoriel : u∧v = (yz′ − zy′ ; zx′ − xz′ ; xy′ − yx′), orthogonal à u et v ; v∧u = − u∧v ; = 0 ⇔  colinéaires ; ‖u∧v‖ = ‖u‖ ‖v‖ sin θ.
  4. Orientation : base directe = main droite ; permutation circulaire conserve, échange de deux vecteurs inverse ; i∧j = k, j∧k = i, k∧i = j.
  5. Aires et volumes : parallélogramme ‖u∧v‖, triangle 12 ‖u∧v‖ ; parallélépipède |(u∧v)⋅w|, tétraèdre 16|(u∧v)⋅w| ; hauteur d'un tétraèdre 3Vaire de base ; produit mixte nul ⇔ coplanaires.
  6. Distances : point-droite ‖AM∧u‖‖u‖ (directeur) ; point-plan |AM⋅n|‖n‖ (normal), soit |ax0 + by0 + cz0 + d|√a2 + b2 + c2, avec zéro au second membre.
  7. Plans : ax + by + cz + d = 0 a pour vecteur normal n(a ; b ; c) ; par trois points non alignés, n = AB∧AC.
  8. Réflexes : scalaire = nombre, vectoriel = vecteur ; vérifier (u∧v)⋅u = 0 ; triangle 12, tétraèdre 16 ; donner l'unité (m, m2, m3).
