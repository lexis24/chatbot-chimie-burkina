Leçon 1 : Intégrale d'une fonction continue

Soit f continue sur un intervalle contenant a et b, et F une primitive de f sur cet intervalle.

DEFINITION DE L'INTEGRALE
∫ab f(x) dx = F(b) − F(a) = [F(x)]ab

Le nombre obtenu ne dépend pas de la primitive choisie ; a est la borne inférieure, b la borne supérieure, et a < b n'est pas exigé. La variable est muette : ∫ab f(x) dx = ∫ab f(t) dt ; dx dit par rapport à quelle variable on intègre. La continuité doit valoir sur tout l'intervalle qui joint a à b : x ↦ 1x ne s'intègre pas de part et d'autre de 0.

CAS PARTICULIERS ET LIEN AVEC LES PRIMITIVES
∫aa f(x) dx = 0     ∫ba f(x) dx = −∫ab f(x) dx
Intégrale et primitive. La primitive de f qui s'annule en a est la fonction x ↦ ∫ax f(t) dt : ici t est muette, x est la vraie variable.

Interprétation par l'aire

Si f est positive et continue sur [a ; b] (avec a < b), alors ∫ab f(x) dx est l'aire, en unités d'aire, de la région comprise entre la courbe de f, l'axe des abscisses et les droites x = a et x = b.

Unité d'aire (U.A.) : dans un repère orthogonal, aire du rectangle construit sur les unités des deux axes. Si l'unité vaut 1 cm sur (Ox) et 2 cm sur (Oy), alors 1 U.A. = 2 cm2 : on convertit dans l'unité demandée.

Fonction négative ou de signe variable

  • f négative sur [a ; b] (a < b) : l'intégrale est négative et l'aire vaut 𝒜 = ∫ab(−f(x)) dx = −∫ab f(x) dx.
  • f change de signe : l'intégrale fait le bilan, le dessus de l'axe comptant positivement, le dessous négativement. Pour l'aire géométrique, on découpe aux points où f s'annule et on additionne les valeurs absolues.

Leçon 2 : Propriétés de l'intégrale et valeur moyenne

CHASLES : f CONTINUE SUR I, a, b, c DANS I
∫ab f + ∫bc f = ∫ac f

Vraie quel que soit l'ordre des trois nombres. Elle sert à découper (changement d'expression ou de signe) et à recoller des intégrales partielles données.

LINEARITE : f, g CONTINUES, α ET β REELS
∫ab(αf(x) + βg(x)) dx = α∫ab f(x) dx + β∫ab g(x) dx

On sépare les sommes et on sort les constantes : jamais un produit ni un quotient de fonctions.

Positivité et comparaison : a < b

  • f ≥ 0 sur [a ; b] ⇒ ∫ab f(x) dx ≥ 0. La réciproque est fausse.
  • f ≤ g sur [a ; b] ⇒ ∫ab f ≤ ∫ab g : l'intégrale conserve l'ordre.
  • Valeur absolue : |∫ab f(x) dx| ≤ ∫ab|f(x)| dx.
INEGALITE DE LA MOYENNE : SI m ≤ f ≤ M SUR [a ; b]
m(b − a) ≤ ∫ab f(x) dx ≤ M(b − a)
si |f| ≤ M :  |∫ab f(x) dx| ≤ M(b − a)

Parité, imparité, périodicité

SYMETRIES : f CONTINUE
f paire, a > 0 : ∫−aa f(t) dt = 2∫0a f(t) dt
f impaire, a > 0 : ∫−aa f(t) dt = 0
f de période T, pour tout réel a : ∫aa+T f(t) dt = ∫0T f(t) dt

Ces trois égalités reposent sur une symétrie : l'intervalle doit être centré en 0, ou de longueur exactement T.

Valeur moyenne

VALEUR MOYENNE DE f SUR [a ; b], AVEC a < b
μ = 1b − a∫ab f(x) dx

Hauteur du rectangle de base [a ; b] de même aire que la région sous la courbe. Si m ≤ f ≤ M, alors m ≤ μ ≤ M : contrôle du résultat.

Leçon 3 : Techniques de calcul et intégration par parties

FORMES COMPOSEES : u DERIVABLE, A DERIVEE CONTINUE
u′eu → eu     u′u → ln |u|  (u ≠ 0)
u′uα → uα+1α + 1  (α ≠ −1)
u′cos u → sin u     u′sin u → −cos u

Le facteur u′ est ce qu'il faut repérer en premier. Composition affine : si F est une primitive de f, alors une primitive de x ↦ f(ax + b) est x ↦ 1aF(ax + b), avec a ≠ 0.

Deux formes voisines. u′u est le cas exclu de u′uα, celui où α = −1. L'exposant α peut être négatif ou fractionnaire : 1√x = x−1/2 → 2√x et 1x2 = x−2 → −1x.

Intégration par parties (IPP)

IPP : u ET v DERIVABLES SUR [a ; b], A DERIVEES CONTINUES
∫ab u(x)v′(x) dx = [u(x)v(x)]ab − ∫ab u′(x)v(x) dx

Pour un produit qu'aucune forme composée ne permet de lire directement : x ex, x cos x, x ln x, ou ln x seul, lu 1 × ln x. Prendre pour u le facteur dont la dérivée est plus simple (x, x2, ln x), pour v′ celui que l'on sait intégrer ; si la nouvelle intégrale reste du même type, recommencer.

Leçon 4 : Equations différentielles linéaires

Une équation différentielle est une équation dont l'inconnue est une fonction y et où figurent une ou plusieurs de ses dérivées ; son ordre est celui de la dérivée la plus élevée. La résoudre (ou l'intégrer) sur un intervalle, c'est déterminer toutes les fonctions qui la vérifient sur cet intervalle. Elle est linéaire à coefficients constants et sans second membre quand elle s'écrit y′ + ay = 0 ou y″ + ω2y = 0. Les lettres changent selon la discipline (t pour le temps, q, N, V, C pour la fonction) : l'équation, elle, ne change pas.

PREMIER ORDRE : SOLUTIONS SUR ℝ DE y′ + ay = 0
y(x) = C e−ax,  C ∈ ℝ

Existence et unicité. Pour tout couple (x0 ; y0), une unique solution vérifie la condition initiale y(x0) = y0 : remplacer x par x0 dans la forme générale, puis résoudre en C.

Formes à reconnaître. y′ = ky s'écrit y′ − ky = 0, donc a = −k et y = Cekx. Toute équation se divise d'abord par le coefficient de y′. Si a > 0 la solution décroît vers 0 (radioactivité, refroidissement) ; si a < 0 elle croît ; C = 0 donne la fonction nulle, toujours solution.

SECOND ORDRE : SOLUTIONS SUR ℝ DE y″ + ω2y = 0, AVEC ω > 0
y(x) = A cos(ωx) + B sin(ωx),  A, B ∈ ℝ
y′(x) = −Aω sin(ωx) + Bω cos(ωx)
y(0) = A     y′(0) = Bω

Forme admise. Deux constantes exigent deux conditions, en général y(x0) et y′(x0). ω est la racine carrée positive du coefficient de y : dans y″ + 9y = 0, ω = 3. Solutions périodiques de période 2πω : les oscillations.

Leçon 5 : Encadrements, valeurs approchées et volumes

Encadrer une intégrale

On applique l'inégalité de la moyenne : m(b − a) ≤ ∫ab f(x) dx ≤ M(b − a). On obtient m et M par le sens de variation : si f croît, m = f(a) et M = f(b) ; si elle décroît, c'est l'inverse. L'amplitude (M − m)(b − a) diminue quand l'intervalle raccourcit : découpé en n tranches, l'encadrement voit son amplitude divisée par n si f est monotone.

Valeurs approchées par découpage

On partage [a ; b] en n tranches de même longueur h = b − an, de bornes x0 = a, x1 = a + h, …, xn = b.

MéthodeAire d'une tranche (largeur h)
Rectangles (à gauche / à droite)h × f(xk)  ou  h × f(xk+1)
Point milieuh × f(xk + xk+12)
Trapèzesf(xk) + f(xk+1)2 × h

Si f est monotone, les deux sommes de rectangles encadrent l'intégrale et la somme des trapèzes en est la moyenne. Les trois méthodes sont de précision croissante et s'améliorent quand n augmente.

Aire entre deux courbes

AIRE ENTRE DEUX COURBES : f ≤ g SUR [a ; b]
𝒜 = ∫ab(g(x) − f(x)) dx  (en U.A.)

f et g continues. On soustrait toujours la courbe du bas à la courbe du haut. Si elles se croisent, on découpe aux intersections et on additionne. Seule compte leur position relative : la formule vaut même sous l'axe des abscisses.

Volumes par intégration

VOLUME PAR LES SECTIONS ET VOLUME DE REVOLUTION
V = ∫ab S(x) dx  (en unités de volume)
rotation autour de (Ox) :  V = ∫abπ[f(x)]2 dx

Formules admises. Le solide est compris entre les plans d'abscisses a et b ; S(x), aire de la section d'abscisse x, est continue sur [a ; b]. Pour une révolution, cette section est un disque de rayon |f(x)|. Le facteur π se sort par linéarité ; conclure avec l'unité.

PIEGES ET ERREURS FREQUENTES
✗ ∫01x2ex dx = (∫01x2)(∫01ex)
✓ L'intégrale d'un produit n'est pas le produit des intégrales. Contre-exemple : ∫01x×x dx = 13 alors que (∫01x dx)2 = 14. Ici, deux IPP successives.
✗ f change de signe sur [a ; b], donc ∫ab f est l'aire de la région
✓ L'intégrale n'est l'aire que si f ≥ 0 : sinon les parties sous l'axe comptent négativement. Avant d'écrire le mot « aire », étudier le signe de f.
✗ ∫ab f ≥ 0, donc f ≥ 0 sur [a ; b]
✓ La positivité n'a pas de réciproque : ∫−122t dt = 3 ≥ 0 alors que 2t < 0 sur [−1 ; 0[. Une intégrale positive signifie seulement que le bilan l'est.
✗ Une primitive de e2x est e2x  ·  une primitive de 1x2 est ln x2
✓ En dérivant e2x on obtient 2e2x : il faut diviser par le coefficient de x, d'où 12e2x. Et 1x2 = x−2 relève de u′uα, non de u′u : sa primitive est −1x.
✗ La solution de y′ − 2y = 0 est y = Ce−2x  ·  dans 2y′ + 6y = 0, a = 6
✓ Dans y′ + ay = 0, l'exposant est l'opposé de a : ici a = −2, donc y = Ce2x, croissante. Et il faut ranger l'équation d'abord : 2y′ + 6y = 0 donne y′ + 3y = 0, a = 3 et y = Ce−3x.
✗ y″ + 16y = 0 a pour solutions Acos 16x + Bsin 16x
✓ ω est la racine carrée du coefficient de y, pas ce coefficient : ω = 4 et y = Acos 4x + Bsin 4x. Deux constantes exigent deux conditions.
✗ L'aire entre les courbes de f et g est ∫ab(f − g)
✓ On soustrait dans le bon sens : 𝒜 = ∫ab(g − f) lorsque f ≤ g, sinon le résultat est négatif, ce qu'aucune aire ne peut être. Si les courbes se croisent, on découpe aux intersections.
✗ Le volume de révolution vaut ∫abπf(x) dx  ·  oubli du signe − dans l'IPP
✓ La section est un disque de rayon |f(x)|, donc d'aire π[f(x)]2 : on intègre le carré. Et dans l'IPP, la seconde intégrale est précédée d'un signe moins : l'oublier est l'erreur mécanique la plus fréquente.
A SAVOIR PAR COEUR AVANT LE DEVOIR
  1. ∫ab f(x) dx = F(b) − F(a) = [F(x)]ab avec f continue ; ∫aa f = 0 et ∫ba f = −∫ab f ; variable muette.
  2. Si f ≥ 0 sur [a ; b] (a < b), l'intégrale est l'aire en U.A., et 1 U.A. = (unité Ox) × (unité Oy). Si f change de signe : découper et additionner les valeurs absolues.
  3. Chasles ∫ab + ∫bc = ∫ac (ordre quelconque) · linéarité sur les sommes et les constantes, jamais sur un produit · f ≤ g ⇒ ∫f ≤ ∫g ; positivité sans réciproque.
  4. Inégalité de la moyenne : m ≤ f ≤ M donne m(b − a) ≤ ∫ab f ≤ M(b − a) · valeur moyenne μ = 1b − a∫ab f, toujours comprise entre m et M.
  5. Symétries : f paire, ∫−aa f = 2∫0a f ; f impaire, ∫−aa f = 0 ; f de période T, ∫aa+T f = ∫0T f.
  6. Formes composées : u′eu → eu, u′u → ln|u|, u′uα → uα+1α + 1 (α ≠ −1), f(ax + b) → 1aF(ax + b). IPP : ∫abuv′ = [uv]ab − ∫abu′v, avec u′ plus simple que u.
  7. Equations différentielles : ranger d'abord, puis y′ + ay = 0 ⇒ y = Ce−ax (une condition fixe C) et y″ + ω2y = 0 ⇒ y = Acosωx + Bsinωx avec y(0) = A, y′(0) = Bω (deux conditions).
  8. Aires et volumes : entre deux courbes (f ≤ g), 𝒜 = ∫ab(g − f) · V = ∫ab S(x) dx · révolution autour de (Ox), V = ∫abπ[f(x)]2 dx. Valeurs approchées : rectangles, point milieu, trapèzes, du moins précis au plus précis.
