L'ESSENTIEL

Leçon 1 : Langage des événements

Une expérience aléatoire a plusieurs résultats possibles ; leur ensemble est l'univers Ω (fini ici). Un événement est une partie de Ω ; un événement élémentaire ne contient qu'un seul résultat. L'événement certain est Ω, l'événement impossible est ∅.

Soit A et B deux événements d'un même univers Ω :

  • « A ou B » = A ∪ B (réunion) ; « A et B » = A ∩ B (intersection) ;
  • A et B sont incompatibles si A ∩ B = ∅ : ils ne peuvent pas se produire ensemble ;
  • l'événement complémentaire de A, noté A, est « A ne se produit pas » ; A ∩ A = ∅ et A ∪ A = Ω.

Un événement et une partie de Ω sont le même objet dit dans deux langages : traduire change une question de mots en un comptage. Contrôle : A et A redonnent tout Ω, sans élément commun.

Leçon 2 : Probabilité et équiprobabilité

Définition. L'univers étant Ω = {ω1, ω2, …, ωn}, définir une probabilité p sur Ω, c'est associer à chaque événement élémentaire {ωi} un réel pi ≥ 0 tel que p1 + p2 + … + pn = 1. La probabilité d'un événement A est la somme des probabilités des événements élémentaires qui le composent. p est donc une application qui, à chaque partie de Ω, associe un nombre de [0 ; 1] : p(A) ∈ [0 ; 1], p(Ω) = 1, p(∅) = 0.

PROPRIETES : A ET B EVENEMENTS D'UN MEME UNIVERS Ω
cas général : p(A ∪ B) = p(A) + p(B) − p(A ∩ B)
A et B incompatibles : p(A ∪ B) = p(A) + p(B)
p(A) = 1 − p(A)   ·   A ⊂ B ⇒ p(A) ≤ p(B)

Le cas général contient les trois autres. La propriété du complémentaire est la plus rentable : dès qu'un énoncé porte les mots « au moins un », calcule « aucun » et retranche à 1.

EQUIPROBABILITE : TOUS LES EVENEMENTS ELEMENTAIRES ONT LA MEME PROBABILITE
p(A) = nombre de cas favorablesnombre de cas possibles = card(A)card(Ω)

Chaque issue vaut alors 1n : ce quotient est une conséquence de la définition, non une définition concurrente. Le droit de l'employer est donné par les mots « dé équilibré », « au hasard », « indiscernables au toucher » ; leur absence est un signal d'alarme. Le travail devient un dénombrement : préciser d'abord la nature du tirage.

Pour les cardinaux : card(A ∪ B) = card(A) + card(B) − card(A ∩ B).

Leçon 3 : Conditionnement, Bernoulli et loi binomiale

PROBABILITE CONDITIONNELLE : AVEC p(B) > 0
pB(A) = p(A | B) = p(A ∩ B)p(B)
probabilités composées : p(A ∩ B) = p(B) × pB(A), et  = p(A) × pA(B) si p(A) > 0

Savoir que B est réalisé rétrécit l'univers : B devient le nouveau tout, d'où la division par p(B). L'information dont on dispose est en indice dans pB(A), après la barre dans p(A | B).

  • Cas particuliers : si B ⊂ A, alors pB(A) = 1 ; si A ⊂ B, alors pB(A) = p(A)p(B).
  • Pour B fixé, A ↦ pB(A) est elle-même une probabilité sur Ω : les propriétés de la Leçon 2 s'appliquent, en particulier pB(A) = 1 − pB(A) (sur l'événement placé devant la barre, jamais sur celui qui est derrière).
PROBABILITES TOTALES : B1, …, Bk PARTITION DE Ω, DE PROBABILITES NON NULLES
p(A) = p(B1) pB1(A) + … + p(Bk) pBk(A)
partition {B ; B} : p(A) = p(B) pB(A) + p(B) pB(A)

Partition : événements deux à deux incompatibles, de réunion Ω. On découpe Ω en cas, on traite chaque cas, on recolle les morceaux.

Arbre pondéré. Le premier niveau porte les probabilités non conditionnées et forme une partition, le second les conditionnelles. Les branches issues d'un même point ont pour somme 1. On multiplie le long d'un chemin, on additionne les chemins qui réalisent l'événement, et la somme de tous les chemins vaut 1.
INDEPENDANCE DE DEUX EVENEMENTS
A et B indépendants ⇔ p(A ∩ B) = p(A) × p(B)
et, lorsque p(B) > 0, ⇔ pB(A) = p(A)

Savoir que B s'est produit ne change pas la probabilité de A. L'indépendance se démontre en calculant les deux membres, ou bien l'énoncé l'affirme (tirages avec remise) : elle ne se devine pas. Indépendants n'est pas incompatibles : deux événements incompatibles de probabilités non nulles ne sont jamais indépendants.

INDEPENDANCE DE n EXPERIENCES : Ai LIE A LA i-EME EXPERIENCE
p(A1 ∩ A2 ∩ … ∩ An) = p(A1) × p(A2) × … × p(An)

Schéma de Bernoulli et loi binomiale

Une épreuve de Bernoulli a deux issues : succès (probabilité p) ou échec (probabilité q = 1 − p). La répéter n fois de façon indépendante, c'est un schéma de Bernoulli ; si X est le nombre de succès, X suit la loi binomiale B(n ; p).

LOI BINOMIALE : POUR 0 ≤ k ≤ n
p(X = k) = Cnk pk (1 − p)n − k

Trois conditions avant d'écrire B(n ; p) : deux issues seulement (sinon regrouper en un événement et son complémentaire) ; même probabilité de succès à chaque répétition ; répétitions indépendantes. Dans la formule, pk(1 − p)n − k est la probabilité d'un chemin et Cnk compte les chemins donnant k succès. Réflexe : p(X ≥ 1) = 1 − p(X = 0).

Leçon 4 : Variables aléatoires

Définition. Associer à chaque éventualité de Ω un nombre réel définit une variable aléatoire numérique X : c'est une application de Ω dans ℝ. C'est une règle fixe, décidée d'avance ; le hasard est dans l'issue qui sort.

L'événement « X prend la valeur xi » se note (X = xi) : ce n'est pas une équation, c'est l'ensemble des issues auxquelles X attribue xi. L'ensemble des valeurs prises est l'univers-image X(Ω), qui compte en général moins d'éléments que Ω.

Loi de probabilité. Associer à chaque valeur xi la probabilité pi = p(X = xi) définit la loi de probabilité de X, présentée dans un tableau. Les (X = xi) forment une partition de Ω, donc ∑pi = 1 : c'est le contrôle de la loi.

Fonction de répartition

C'est la fonction F définie sur ℝ tout entier par F(x) = p(X ≤ x). Pour les valeurs ordonnées x1 < … < xn de probabilités p1, …, pn, F est en escalier, croissante de 0 à 1 :

  • F(x) = 0 pour x < x1 ; F(x) = 1 pour x ≥ xn ;
  • palier : F(x) = p1 + … + pi pour xi ≤ x < xi+1, somme des probabilités des valeurs déjà atteintes.

La hauteur du saut en xi est pi, et le saut a lieu à partir de xi, cette valeur comprise, puisque le signe ≤ figure dans p(X ≤ x).

CONSEQUENCE : POUR TOUS REELS a < b
p(a < X ≤ b) = F(b) − F(a)

Espérance, variance, écart-type

INDICATEURS D'UNE VARIABLE ALEATOIRE
E(X) = ∑xi pi
V(X) = ∑pi (xi − E(X))2 = E(X2) − (E(X))2
σ(X) = √V(X)   ·   si X suit B(n ; p) : E(X) = np, V(X) = np(1 − p)

L'espérance est la moyenne attendue, pondérée par les probabilités ; l'écart-type mesure la dispersion et s'exprime dans l'unité de X, ce que la variance, faite de carrés, ne fait pas. La première écriture de V(X) dit ce que la variance signifie, la seconde, formule de Koenig, sert à la calculer : on ajoute au tableau la ligne des xi2, on en prend la moyenne pondérée, on retranche le carré de l'espérance.

Contrôles finaux. ∑pi = 1 · E(X) comprise entre la plus petite et la plus grande valeur de X · V(X) ≥ 0 · F croissante, de dernier palier 1 · toute probabilité dans [0 ; 1].
PIEGES ET ERREURS FREQUENTES
✗ « A ou B » exclut le cas où les deux se produisent ensemble
✓ Le « ou » mathématique est inclusif : A ∪ B contient A ∩ B. En écrivant « roi ou cœur », on garde le roi de cœur. Les deux sens ne coïncident que si A et B sont incompatibles ; contrôle : relire la réunion en ajoutant « ou les deux ».
✗ Le complémentaire de « obtenir au moins un roi » est « obtenir au plus un roi »
✓ C'est « n'obtenir aucun roi » : on nie A tout entier. Test : card(A) + card(A) = card(Ω).
✗ p(A ∪ B) = p(A) + p(B), toujours
✓ Seulement si A et B sont incompatibles. Sinon p(A ∪ B) = p(A) + p(B) − p(A ∩ B) : sans ce retranchement, l'intersection est comptée deux fois.
✗ Deux issues possibles, donc chacune a pour probabilité 12
✓ Le quotient favorablespossibles n'est valable qu'en équiprobabilité : une punaise lancée 1000 fois donne 0,62, pas 0,50. Si les issues qui viennent à l'esprit ne sont pas également probables, change d'univers (numérote les objets, distingue les boules de même couleur).
✗ p(D | A) = 0,05 donc p(A | D) = 0,05
✓ Elles n'ont ni le même dénominateur ni le même sens : p(D | A) se calcule parmi les articles de la machine A, p(A | D) parmi les articles défectueux, avec p(A | D) = p(A ∩ D)p(D). L'information dont on dispose va derrière la barre, sa probabilité au dénominateur.
✗ Tirage sans remise : « X suit B(n ; p) »  ·  pour B(n ; p), E(X) = p
✓ Sans remise, la composition change à chaque tirage : la probabilité du succès n'est plus constante, les répétitions ne sont pas indépendantes, la loi binomiale ne s'applique pas et l'on revient à l'arbre pondéré. Et E(X) = np : B(10 ; 0,2) a pour espérance 2, pas 0,2.
✗ V(X) = (E(X))2 − E(X2), ou E(X2) confondu avec (E(X))2
✓ V(X) = E(X2) − (E(X))2 : dans E(X2) on élève au carré avant de faire la moyenne, dans (E(X))2 après ; on peut avoir 1,3 d'un côté et 0,01 de l'autre. Une variance est une moyenne de carrés : V(X) ≥ 0, un résultat négatif signale l'inversion.
✗ F n'est définie qu'aux valeurs prises par X  ·  p(a < X ≤ b) = F(b) + F(a)
✓ F est définie sur ℝ tout entier : F(1,7) a un sens. Et l'on retranche : F(b) − F(a). Le palier change à partir de chaque valeur, celle-ci incluse : se tromper de bord revient à oublier toute la probabilité d'une valeur.
A SAVOIR PAR COEUR AVANT LE DEVOIR

  2. p(A) = 1 − p(A) · p(A ∪ B) = p(A) + p(B) − p(A ∩ B), sans le dernier terme si incompatibles · A ⊂ B ⇒ p(A) ≤ p(B). « Au moins un » → passer au complémentaire.
  3. Equiprobabilité (et seulement dans ce cas) : p(A) = card(A)card(Ω). Dénombrement : np · Anp = n!(n − p)! · n! · Cnp = Anpp!.
  4. Conditionnelle : pB(A) = p(A ∩ B)p(B) avec p(B) > 0 · composées (probabilités non nulles) : p(A ∩ B) = p(B) pB(A) = p(A) pA(B) · B ⊂ A ⇒ pB(A) = 1 · ne jamais échanger les deux lettres.
  5. Probabilités totales avec une partition, en particulier {B ; B} : p(A) = p(B) pB(A) + p(B) pB(A). Arbre : produit le long d'un chemin, somme des chemins, branches d'un même point de somme 1.
  6. Indépendance : p(A ∩ B) = p(A) × p(B), soit pB(A) = p(A) ; pour n expériences indépendantes, la probabilité de l'intersection est le produit des probabilités.
  7. Loi binomiale B(n ; p), après les trois conditions : p(X = k) = Cnk pk(1 − p)n − k · E(X) = np · V(X) = np(1 − p) · p(X ≥ 1) = 1 − p(X = 0).
