Leçon 1 : Forme algébrique et conjugué

ℂ contient ℝ, prolonge ses opérations et contient un élément i tel que i2 = −1. Tout complexe z s'écrit de façon unique sous la forme algébrique z = a + bi, avec a, b réels : a = Re(z) partie réelle, b = Im(z) partie imaginaire, toutes deux réelles. z est réel si b = 0, imaginaire pur si a = 0 et b ≠ 0.

IDENTIFICATION : L'UNICITE DE L'ECRITURE, a, b, a′, b′ REELS
a + bi = a′ + b′i ⇔ a = a′ et b = b′    a + bi = 0 ⇔ a = b = 0
OPERATIONS : z = a + bi, z′ = c + di
z ± z′ = (a ± c) + (b ± d)i    z z′ = (ac − bd) + (ad + bc)i

Le produit ne s'apprend pas : on développe, puis on remplace i2 par −1. Puissances : i0 = 1, i1 = i, i2 = −1, i3 = −i, i4 = 1, puis de 4 en 4.

Conjugué, inverse et quotient

Conjugué de z = a + bi : z = a − bi (on change le signe de la seule partie imaginaire).

PROPRIETES DU CONJUGUE : z′ ≠ 0 POUR LE QUOTIENT
z + z′ = z + z′   z z′ = z z′   (z / z′) = z / z′
z + z = 2 Re(z)   z − z = 2i Im(z)   z z = a2 + b2

z z est un réel positif ; conjuguer deux fois redonne z. Outils de preuve : z réel ⇔ z = z ; z imaginaire pur ⇔ z = −z.

QUOTIENT : multiplier par le conjugué du dénominateur
1z = za2 + b2 (z ≠ 0)    zz′ = z z′c2 + d2 (z′ ≠ 0)

Leçon 2 : Plan complexe et module

Le plan est muni d'un repère orthonormé direct (O, u, v) ; à z = a + bi correspond son image M(a ; b), et z est l'affixe de M.

  • Les réels ont pour images les points de l'axe des réels (O, u) ; les imaginaires purs, ceux de l'axe des imaginaires (O, v).
  • Affixe de AB : zB − zA (arrivée moins départ) ; milieu I de [AB] : zI = zA + zB2.
  • Le point d'affixe z est le symétrique de M par rapport à l'axe des réels ; celui d'affixe −z, par rapport à O.
MODULE ET DISTANCE
|z| = √a2 + b2 = OM    |z|2 = z z    AB = |zB − zA|
|z z′| = |z| |z′|   |zz′| = |z||z′| (z′ ≠ 0)   |zn| = |z|n
|z| = |−z| = |z|    |z + z′| ≤ |z| + |z′| (inégalité triangulaire)

|z| ≥ 0 et |z| = 0 ⇔ z = 0. Le module traverse produits, quotients et puissances, mais pas les sommes. De |z|2 = z z vient 1z = z|z|2, donc 1z = z lorsque |z| = 1.

Premiers ensembles de points. |z − zA| = R (R > 0) : cercle de centre A, de rayon R · |z − zA| = |z − zB| : médiatrice de [AB] · z ↦ z + a : translation de vecteur d'affixe a. Un module se traduit en distance ; lire |z − 1 − i| comme |z − (1 + i)|.

Leçon 3 : Argument et formes trigonométrique et exponentielle

Pour z non nul d'image M, un argument de z est une mesure de l'angle orienté (u, OM). Il est défini modulo 2π : ce sont les θ + 2kπ, k ∈ ℤ. Le nombre 0 n'a pas d'argument.

ARGUMENT ET FORMES : r = |z| > 0
cos θ = ar  et  sin θ = br
z = r(cos θ + i sin θ) = r eiθ
z = z′ ⇔ |z| = |z′| et arg(z) = arg(z′) + 2kπ

Seul le couple détermine θ : le cosinus laisse deux angles opposés, le sinus tranche. Module d'abord, argument ensuite. eiθ abrège cos θ + i sin θ et |eiθ| = 1 ; une forme trigonométrique correcte a un facteur positif, un + et le même angle aux deux places.

Propriétés des arguments

POUR z, z′ NON NULS, n ∈ ℕ ET k ∈ ℤ
arg(z z′) = arg(z) + arg(z′) + 2kπ   arg(zz′) = arg(z) − arg(z′) + 2kπ
arg(z) = −arg(z) + 2kπ   arg(−z) = arg(z) + π + 2kπ   arg(zn) = n arg(z) + 2kπ
r eiθ × r′ eiθ′ = r r′ ei(θ + θ′)   r eiθr′ eiθ′ = rr′ ei(θ − θ′)   r eiθ = r e−iθ

Une phrase suffit : on multiplie les modules et on additionne les arguments. Arguments remarquables (r > 0) : r = r ei 0, −r = r eiπ, ri = r eiπ/2, −ri = r e−iπ/2. Pour z non nul : réel ⇔ arg(z) = kπ ; imaginaire pur ⇔ arg(z) = π / 2 + kπ. L'ensemble des M tels que arg(z) = α + 2kπ est la demi-droite ouverte d'origine O et d'angle α (O exclu).

Leçon 4 : Formules de Moivre et d'Euler

MOIVRE ET EULER : n ∈ ℕ, θ REEL
(cos θ + i sin θ)n = cos(nθ) + i sin(nθ)
(eiθ)n = einθ    z = r eiθ ⇒ zn = rn einθ
cos θ = eiθ + e−iθ2    sin θ = eiθ − e−iθ2i

Moivre : le module est élevé à la puissance n, l'argument multiplié par n. Euler : le dénominateur du sinus est 2i, jamais 2.

Linéariser cosnθ ou sinnθ : passer aux exponentielles, développer, puis regrouper eikθ avec e−ikθ (qui donne 2 cos(kθ)) : on obtient une somme de cos(kθ) et sin(kθ).

PRODUIT EN SOMME, SOMME EN PRODUIT
cos a cos b = 12[cos(a + b) + cos(a − b)]
sin a cos b = 12[sin(a + b) + sin(a − b)]
cos p + cos q = 2 cos p + q2 cos p − q2
sin p + sin q = 2 sin p + q2 cos p − q2

Leçon 5 : Equations dans ℂ

z2 = k, k réel. k > 0 : z = ±√k · k = 0 : z = 0 (double) · k < 0 : deux imaginaires purs opposés z = ±i√−k.

SECOND DEGRE : az2 + bz + c = 0, a ≠ 0, Δ = b2 − 4ac
coefficients réels, Δ < 0 :  z = −b ± i√−Δ2a , racines conjuguées
coefficients complexes :  δ tel que δ2 = Δ, puis z = −b ± δ2a

Coefficients réels et Δ ≥ 0 : les solutions réelles habituelles. Tout trinôme a donc deux racines dans ℂ, confondues si Δ = 0. Contrôle : z1 + z2 = −b / a et z1z2 = c / a. Avec des coefficients complexes, les racines ne sont plus conjuguées.

Racines carrées d'un complexe et racines n-ièmes

Tout complexe non nul A a exactement deux racines carrées, opposées. On pose z = x + iy (x, y réels) et l'on traduit z2 = A :

SYSTEME DES RACINES CARREES DE A
x2 − y2 = Re(A)    x2 + y2 = |A|    2xy = Im(A)

Les deux premières donnent x2 et y2 par somme et différence ; la troisième ne sert qu'aux signes : Im(A) > 0 donne x et y de même signe, Im(A) < 0 de signes contraires.

RACINES n-IEMES : w = r eiθ ≠ 0, n ≥ 1
zn = w  a pour solutions  zk = n√r ei(θ + 2kπ)/n,  k = 0, 1, …, n − 1

Exactement n solutions, régulièrement réparties sur le cercle de centre O et de rayon n√r, séparées par 2π / n : un polygone régulier à n côtés.

Retours au second degré. Bicarrée az4 + bz2 + c = 0 : poser Z = z2, résoudre en Z, puis prendre les racines carrées de chaque Z : quatre solutions. Degré 3 avec une racine z0 indiquée : factoriser P(z) = (z − z0)(z2 + pz + q) et trouver p, q par identification. Un degré n a au plus n solutions.

Leçon 6 : Complexes et géométrie du plan

Soit A, B, C d'affixes a, b, c, deux à deux distincts.

INTERPRETATION DU QUOTIENT : SOMMET A
|c − ab − a| = ACAB    arg(c − ab − a) = (AB, AC) + 2kπ

Le sommet étudié est celui dont l'affixe est soustraite partout ; l'angle va de AB vers AC.

Configurations. A, B, C alignés ⇔ quotient réel · angle droit en A ⇔ imaginaire pur non nul · isocèle en A ⇔ module 1 · rectangle isocèle en A ⇔ quotient i ou −i · équilatéral ⇔ |b − a| = |c − a| = |c − b|. Pour construire un point, écrire la condition à l'envers.

Ensembles de points

Cercle de centre A, de rayon R > 0 : |z − a| = R · médiatrice de [AB] : |z − a| = |z − b| · demi-droite ouverte d'origine O, d'angle α : arg(z) = α + 2kπ, z ≠ 0.

LE QUOTIENT Z : pour z ≠ b et A ≠ B
Z = z − az − b    |Z| = MAMB    arg(Z) = (MB, MA)

|Z| = 1 : médiatrice de [AB] · Z réel : droite (AB) privée de B · Z imaginaire pur : cercle de diamètre [AB] privé de A et de B. Les exclusions font partie de la réponse : B annule le dénominateur, et A donne Z = 0, réel mais sans argument.

Ecritures complexes des transformations

TransformationEcriture complexe
Translation, vecteur d'affixe az′ = z + a
Rotation, centre Ω(ω), angle α · centre Oz′ − ω = eiα(z − ω) · z′ = eiαz
Symétrie, axe des réels · axe des imaginairesz′ = z  ·  z′ = −z
Symétrie, centre O · centre Ω(ω)z′ = −z  ·  z′ = 2ω − z
Homothétie, centre Ω(ω), rapport k réel non nulz′ − ω = k(z − ω)

Toujours : ramener le centre en O, multiplier, remettre le centre. Multiplier par i, c'est tourner de π / 2. Translations, rotations et symétries conservent les distances. Parallélogramme ABCD : zD = zA + zC − zB.

PIEGES ET ERREURS FREQUENTES
✗ √−4 √−9 = √36 = 6  ·  i = √−1
✓ La règle √a √b = √ab est fausse pour les négatifs et √ reste réservé aux réels positifs : de z2 = −4 on tire z = ±2i. Pas d'ordre non plus dans ℂ.
✗ |2 + 3i| = 2 + 3 = 5  ·  Im(4 − 7i) = −7i  ·  le conjugué de 3 − 5i est −3 + 5i
✓ |2 + 3i| = √22 + 32 = √13, et sur une somme seule l'inégalité |z + z′| ≤ |z| + |z′| est vraie. La partie imaginaire est un réel : Im(4 − 7i) = −7. Et seule la partie imaginaire change de signe : 3 − 5i = 3 + 5i.
✗ arg(z) = arg(z)  ·  cos θ = −√22 donc θ = 3π4
✓ arg(z) = −arg(z) + 2kπ : l'image de z est le symétrique par rapport à l'axe des réels. Le cosinus seul ne suffit jamais : le couple (cos θ ; sin θ) choisit entre 3π4 et −3π4.
✗ (eiθ)3 = e3i  ·  le module de (1 + i)8 vaut 8√2
✓ L'exposant porte sur tout iθ : (eiθ)3 = e3iθ, l'argument est 3θ. Le module est élevé, l'argument multiplié : |(1 + i)8| = (√2)8 = 16.
✗ z3 = 8 donc z = 2  ·  z2 − (3 + i)z + 2 + 2i = 0 : racines conjuguées
✓ zn = w a exactement n solutions : il en manque deux, 2 e2iπ/3 et 2 e4iπ/3. Et « conjuguées » exige des coefficients réels : ici les racines sont 2 et 1 + i, obtenues via une racine carrée δ de Δ.
✗ Rotation de centre Ω(ω) : z′ = eiαz  ·  c − ab − a imaginaire pur donc A, B, C alignés
✓ Cette écriture ne vaut que si le centre est O ; sinon z′ − ω = eiα(z − ω) : l'oubli du centre est l'erreur reine du chapitre. Et c'est le quotient réel qui donne l'alignement, l'imaginaire pur l'angle droit en A.
