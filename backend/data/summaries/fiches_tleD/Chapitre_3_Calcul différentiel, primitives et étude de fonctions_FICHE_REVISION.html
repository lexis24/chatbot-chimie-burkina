Leçon 1 : Dérivabilité, singularités, dérivées successives

Soit f définie sur un intervalle contenant a : f est dérivable en a lorsque le taux d'accroissement a une limite finie quand x → a ; cette limite est le nombre dérivé f′(a).

NOMBRE DERIVE ET TANGENTE : LIMITE FINIE EXIGEE
f′(a) = limx→a f(x) − f(a)x − a = limh→0 f(a + h) − f(a)h
tangente en A(a ; f(a)) :  y = f′(a) (x − a) + f(a)

Dérivable en a ⇒ continue en a ; réciproque fausse. Approximation affine (h voisin de 0) : f(a + h) ≈ f(a) + h f′(a).

Dérivées à droite et à gauche : singularités

f′d(a) est la limite finie du taux quand x → a+, f′g(a) celle quand x → a−. f est dérivable en a ⇔ les deux existent et sont égaux.

  • Point anguleux : les deux existent mais diffèrent ; deux demi-tangentes, de coefficients directeurs f′d(a) et f′g(a).
  • Tangente verticale : le taux tend vers ±∞ ; tangente d'équation x = a, et f n'est pas dérivable en a.

Lectures du nombre dérivé, dérivées successives

f′(a) est la vitesse de variation instantanée en a : coefficient directeur de la tangente ; vitesse x′(t) et accélération x″(t) en physique ; coût marginal C′(x) en économie, coût approché du (x + 1)-ième objet.

Si f′ est dérivable sur I, sa dérivée est la dérivée seconde f″ ; de même f‴, f(4)… Notation de Leibniz : f′ = dfdx, f″ = d2fdx2.

ACCROISSEMENTS FINIS : f DERIVABLE SUR [a ; b], a < b
si m ≤ f′(x) ≤ M sur [a ; b], alors
m (b − a) ≤ f(b) − f(a) ≤ M (b − a)
si |f′(x)| ≤ M sur [a ; b] :  |f(b) − f(a)| ≤ M |b − a|

Leçon 2 : Dérivation des fonctions composées

Dérivée d'une bijection réciproque

f dérivable et strictement monotone sur I, avec f′ qui ne s'annule pas : f réalise une bijection de I sur f(I) et f−1 est dérivable sur f(I).

FORMULE ADMISE : POUR b = f(a)
(f−1)′(b) = 1f′(a) = 1f′(f−1(b))

Trouver d'abord le a tel que f(a) = b : on ne remplace pas b dans f′.

Leçon 3 : Primitives

Une primitive de f sur un intervalle I est une fonction F dérivable sur I telle que F′(x) = f(x) sur I. Existence (admise) : toute fonction continue sur I y admet des primitives. Leçon 4 : Etude complète d'une fonction

1. Ensemble de définition Df et continuité ; parité, périodicité, symétries (Leçon 5) pour réduire le domaine d'étude.  2. Limites aux bornes de Df ; asymptotes et branches infinies.  3. Tracé : asymptotes, points et tangentes remarquables, puis la courbe. Si le signe de f′ n'est pas immédiat, introduire une fonction auxiliaire, à signaler explicitement et à étudier complètement.

Signe de f′, variations et extremums

SUR UN INTERVALLE I : f DERIVABLE SUR I
f′ > 0 ⇒ strictement croissante  ·  f′ < 0 ⇒ strictement décroissante
f′ = 0 sur I tout entier ⇒ f constante sur I

Conclusions maintenues si f′ s'annule en des points isolés. Extremum local : f′ s'annule en x0 en changeant de signe ⇒ extremum, maximum de + à −, minimum de − à + ; tangente horizontale.

Asymptotes et position de la courbe

ASYMPTOTES A LA COURBE (Cf)
limx→a f(x) = ±∞ ⇒ verticale x = a
limx→±∞ f(x) = ℓ (réel) ⇒ horizontale y = ℓ
limx→±∞ [f(x) − (ax + b)] = 0, a ≠ 0 ⇒ oblique y = ax + b

Position : elle se lit sur le signe de d(x) = f(x) − (ax + b) : positif, la courbe est au-dessus ; négatif, au-dessous ; nul, elle coupe l'asymptote.

Pour une fraction rationnelle, écrire f(x) = ax + b + r(x) avec r(x) → 0 : le signe de r(x) donne la position.

Nombre de solutions de f(x) = λ

Une fonction continue et strictement monotone sur un intervalle I réalise une bijection de I sur l'intervalle image f(I) : l'équation f(x) = λ admet une solution et une seule dans I si λ ∈ f(I), aucune sinon.

En pratique : découper Df en intervalles de stricte monotonie (les colonnes du tableau), lire l'intervalle image de chacun, compter ceux qui contiennent λ ; f(x) ≥ λ se lit de même. Localiser : changement de signe de f(x) − λ entre deux entiers voisins.

Leçon 5 : Symétries, périodicité et branches infinies

Parité. Df doit d'abord être symétrique par rapport à 0 : x ∈ Df entraîne −x ∈ Df.

PARITE : POUR TOUT x DE Df
f(−x) = f(x) : f paire, symétrie d'axe (Oy)
f(−x) = −f(x) : f impaire, symétrie de centre O

On réduit l'étude à [0 ; +∞[ ∩ Df, puis on complète par la symétrie.

Périodicité

f est périodique de période T (T > 0) lorsque, pour tout x de Df, x + T ∈ Df et f(x + T) = f(x) : la courbe est invariante par la translation de vecteur T i. La période est le plus petit réel strictement positif convenable ; on étudie f sur un intervalle de largeur T : [0 ; T], ou [−T2 ; T2] si f est de plus paire ou impaire.

Périodes usuelles : sin et cos, 2π ; tan, π ; sin(ax + b) et cos(ax + b), a ≠ 0 : T = 2π|a|. Pour une somme : ppcm des périodes.

Axe et centre de symétrie

Df doit être symétrique par rapport à a : x ∈ Df entraîne 2a − x ∈ Df.

CRITERES : POUR TOUT x DE Df
droite x = a axe de (Cf) ⇔ f(2a − x) = f(x)
point A(a ; b) centre de (Cf) ⇔ f(2a − x) + f(x) = 2b

L'étude se réduit à [a ; +∞[ ∩ Df ; a = 0 et a = b = 0 redonnent parité et imparité.

Concavité, point d'inflexion, branches infinies

f deux fois dérivable sur I : f″ > 0 donne une courbe convexe (concavité vers le haut, au-dessus de ses tangentes), f″ < 0 une courbe concave (au-dessous). Point d'inflexion : la tangente y traverse la courbe, qui change de concavité ; il y en a un en x0 si f″ s'y annule en changeant de signe.

Branches infinies en +∞ (même méthode en −∞). Si limx→+∞ f(x) est finie, c'est une asymptote horizontale. Si elle vaut ±∞, on étudie limx→+∞ f(x)x :

  • ±∞ : branche parabolique de direction (Oy) (exemple x2) ;
  • 0 : branche parabolique de direction (Ox) (exemple √x) ;
  • a réel non nul : étudier limx→+∞ [f(x) − ax]. Limite finie b : asymptote oblique y = ax + b ; limite infinie : branche parabolique de direction y = ax. En cas d'asymptote, étudier ensuite la position de la courbe (Leçon 4).
