L'ESSENTIEL

Leçon 1 : Repère cartésien, coordonnées et milieu

Le repère. Un repère du plan est formé d'une origine O et de deux axes gradués sécants en O, chacun portant son unité : le premier, souvent horizontal, est l'axe des abscisses ; le second, souvent vertical, l'axe des ordonnées. Dans un repère cartésien, les axes ne sont pas forcément perpendiculaires.

Coordonnées. Tout point M est repéré par un unique couple (x ; y) : x est l'abscisse de M, y son ordonnée. On note M(x ; y), abscisse en premier, les deux nombres séparés par un point-virgule.

MILIEU DE DEUX POINTS : M milieu de [AB]
xM = xA + xB2     yM = yA + yB2

Ce sont deux moyennes : une sur les abscisses, une sur les ordonnées, signes compris. La moyenne de −4 et de +2 vaut −1.

Lire un point dans les quatre régions

Les deux axes découpent le plan en quatre régions : le signe des deux coordonnées suffit à reconnaître la bonne.

en haut à gauche (− ; +)en haut à droite (+ ; +)
en bas à gauche (− ; −)en bas à droite (+ ; −)
  • Pour lire un point d'une figure, trace deux traits en pointillés, vers l'axe horizontal puis vers l'axe vertical : ne devine jamais à l'œil.
  • Point de l'axe horizontal : ordonnée nulle, (x ; 0). Point de l'axe vertical : abscisse nulle, (0 ; y). Origine : O(0 ; 0).
Milieu de [AB]. Ecris A et B avec leurs signes, moyenne des deux abscisses, puis des deux ordonnées ; place M : il tombe entre A et B.

Leçon 2 : Repère orthogonal, placer un point

Repère orthogonal : ses deux axes sont perpendiculaires. Si, en plus, ils portent la même unité, il est orthonormé : c'est le cas du papier quadrillé.

PLACER LE POINT M(x ; y) : en partant de O
de x à l'horizontale : droite si x > 0, gauche si x < 0
puis de y à la verticale : haut si y > 0, bas si y < 0

Longueur d'un segment horizontal ou vertical

DANS UN REPERE ORTHONORME
même ordonnée : AB = |xA − xB|
même abscisse : AB = |yA − yB|
  • Même ordonnée : ligne horizontale ; même abscisse : ligne verticale. On retrouve une seule droite graduée. Ainsi A(−2 ; 3) et B(5 ; 3) : AB = |−2 − 5| = 7 unités.
  • La règle sert à reconnaître un carré ou un rectangle dont les côtés suivent le quadrillage. Pour un segment oblique, la longueur ne se calcule pas encore : ce sera en 3ème.

Symétrique d'un point

SYMETRIQUE DE M(x ; y)
axe des abscisses → (x ; −y)    axe des ordonnées → (−x ; y)
origine O → (−x ; −y)
  • On replie la figure le long de l'axe : par rapport à l'axe horizontal l'abscisse ne bouge pas et l'ordonnée change de signe ; par rapport à l'axe vertical, c'est l'inverse.
  • Par rapport à l'origine, O est le milieu du segment joignant les deux points : les deux signes changent. Pour A(4 ; 2) : (4 ; −2), (−4 ; 2) et (−4 ; −2).
PIEGES ET ERREURS FREQUENTES
✗ A(4 ; 2) est le même point que (2 ; 4)  ·  on écrit A(4 , 2)
✓ L'abscisse s'écrit toujours en premier, l'ordonnée ensuite, séparées par un point-virgule : (4 ; 2) et (2 ; 4) sont deux points différents.
✗ xM = xB − xA2  ·  xM = xA + xB  ·  −6 + 22 = −4
✓ Le milieu est une demi-somme, jamais une demi-différence, et la division par 2 ne s'oublie pas. On fait d'abord la somme, avec les signes : −6 + 2 = −4, puis on divise par 2, d'où −2.
✗ « C(0 ; −3) est sur l'axe horizontal. »
✓ Son abscisse est nulle : C est sur l'axe vertical, l'axe des ordonnées. L'abscisse se lit sur l'axe horizontal, l'ordonnée sur l'axe vertical.
✗ Symétrique de A(4 ; 2) par rapport à l'axe des abscisses : (−4 ; 2)
✓ Par rapport à l'axe des abscisses, c'est l'ordonnée qui change de signe : (4 ; −2). Par rapport à l'axe des ordonnées, c'est l'abscisse : (−4 ; 2).
✗ A(1 ; 2) et B(5 ; 7) : AB = |1 − 5| = 4
✓ AB = |xA − xB| ne vaut que si les deux points ont la même ordonnée. Ici le segment est oblique : sa longueur ne se calcule pas en 4ème.
✗ « Tout repère orthogonal est orthonormé. »  ·  « Dans un repère cartésien, les axes sont perpendiculaires. »
✓ Orthogonal : axes perpendiculaires. Orthonormé : perpendiculaires et de même unité. Dans un repère cartésien, les axes sont seulement sécants.
A SAVOIR PAR COEUR AVANT LE DEVOIR
  1. Un repère = une origine O + deux axes gradués sécants en O, chacun avec son unité : abscisses (souvent horizontal), ordonnées (souvent vertical).
  2. M(x ; y) : couple unique, abscisse d'abord, point-virgule. Axe horizontal : (x ; 0) ; axe vertical : (0 ; y) ; origine : O(0 ; 0).
  3. Milieu de [AB] : xM = xA + xB2 et yM = yA + yB2 : deux moyennes, signes compris.
  4. Quatre régions par les signes : (+ ; +) en haut à droite, (− ; +) en haut à gauche, (− ; −) en bas à gauche, (+ ; −) en bas à droite.
  5. Orthogonal = axes perpendiculaires ; orthonormé = perpendiculaires et même unité. Placer M : x à l'horizontale depuis O, puis y à la verticale, en suivant les signes.
  6. Longueurs (orthonormé) : même ordonnée → AB = |xA − xB| ; même abscisse → AB = |yA − yB| ; oblique : pas encore calculable.
  7. Symétriques de (x ; y) : axe des abscisses → (x ; −y) ; axe des ordonnées → (−x ; y) ; origine → (−x ; −y).
