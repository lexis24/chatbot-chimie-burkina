L'ESSENTIEL

Leçon 1 : Qu'est-ce qu'un nombre réel ? Rationnels et irrationnels

  • Un nombre rationnel s'écrit sous forme de fraction ab, avec a et b entiers et b ≠ 0. Son écriture décimale est finie ou périodique.
  • Un nombre irrationnel a une écriture décimale illimitée et non périodique : il ne peut pas s'écrire sous forme de fraction. Exemples : √2, √3, √5, π.
  • L'ensemble des nombres réels, noté ℝ, réunit tous les rationnels et tous les irrationnels. Tout réel se place sur une droite graduée, et tout point de cette droite correspond à un réel.
EMBOITEMENT DES ENSEMBLES DE NOMBRES
ℕ ⊂ ℤ ⊂ 𝔻 ⊂ ℚ ⊂ ℝ

L'inclusion de ℚ dans ℝ est stricte : il existe des réels qui ne sont pas rationnels.

La racine carrée

RACINE CARREE : pour a positif
√a est le nombre positif dont le carré vaut a
√a × √a = a
  • √a se lit « racine carrée de a » : c'est la longueur du côté d'un carré d'aire a.
  • Si a est un carré parfait (1, 4, 9, 16, 25, 36, 49, 64, 81, 100…), alors √a est un entier, donc un rationnel. Sinon, √a est irrationnel.

Reconnaître un rationnel ou un irrationnel

  • Nombre écrit en fraction, nombre entier ou décimal : c'est un rationnel.
  • Ecriture décimale finie (0,75) ou périodique (0,123 123 123…) : c'est un rationnel.
  • Ecriture √a : on regarde a. Carré parfait → rationnel ; sinon → irrationnel.
  • π est irrationnel ; 3,14 et 227 n'en sont que des valeurs approchées, et elles, elles sont rationnelles.
Placer √2 sur la droite graduée. On trace le carré de côté 1 posé sur la droite à partir de l'origine : sa diagonale mesure √2. Pointe du compas en O, on reporte cette longueur sur la droite. Le point obtenu est exact, alors que 1,414 n'est qu'une valeur approchée.

Leçon 2 : Opérations et puissances dans les nombres réels

Dans ℝ, l'addition et la multiplication ont les mêmes propriétés que dans ℚ.

PROPRIETES DE L'ADDITION ET DE LA MULTIPLICATION
a + b = b + a  commutativité
(a + b) + c = a + (b + c)  associativité
a × (b + c) = a × b + a × c  distributivité

Eléments neutres : 0 pour l'addition, car a + 0 = a ; 1 pour la multiplication, car a × 1 = a. Le nombre 0 est absorbant pour la multiplication : a × 0 = 0.

Les puissances

REGLES DES PUISSANCES : comme dans ℚ
am × an = am+n     am ÷ an = am−n
(am)n = am×n     (a × b)n = an × bn
a0 = 1  pour a ≠ 0
REGLE DES SIGNES : puissance d'un nombre négatif
exposant pair → résultat positif : (−3)2 = 9
exposant impair → résultat négatif : (−3)3 = −27

En pratique, pour un même nombre : produit → on ajoute les exposants ; quotient → on les soustrait ; puissance de puissance → on les multiplie. On applique ensuite la règle des signes, puis on calcule.

Racine carrée, produit et somme

LA RACINE TRAVERSE LE PRODUIT : pour a et b positifs
√a × b = √a × √b
mais en général √a + b ≠ √a + √b

Une racine carrée ne se distribue pas : elle porte sur tout ce qui est écrit sous le signe, et non sur chaque morceau. Contre-exemple : √9 + 16 = √25 = 5, alors que √9 + √16 = 3 + 4 = 7.

Leçon 3 : L'ordre dans les nombres réels

  • Dans ℝ, deux réels se comparent toujours : sur la droite graduée, le plus petit est à gauche du plus grand.
  • Encadrer un réel x, c'est trouver deux nombres a et b tels que a ≤ x ≤ b : a est la borne inférieure, b la borne supérieure.
  • Valeur approchée par défaut : un peu plus petite que le nombre ; par excès : un peu plus grande. L'amplitude est la différence des deux bornes : plus elle est petite, plus l'encadrement est précis.
  • Encadrer x par deux entiers consécutifs : l'entier juste en dessous et l'entier juste au-dessus. Pour une fraction, on effectue la division : la partie entière du quotient donne la borne inférieure.
ENCADRER UNE RACINE PAR DEUX ENTIERS
si n2 < a < (n + 1)2, alors n < √a < n + 1

On cherche les deux carrés parfaits qui entourent a : de 4 < 7 < 9 on tire 2 < √7 < 3.

CONSERVATION DE L'ORDRE
si a ≤ b, alors a + c ≤ b + c  pour tout réel c
l'ordre est aussi conservé si l'on multiplie les deux membres par un nombre positif

Resserrer un encadrement

On part de l'unité, puis on découpe en dixièmes, en centièmes… en essayant les carrés :

Encadrement de √2DéfautExcèsAmplitude
à l'unité121
au dixième  1,4 × 1,4 = 1,96  ·  1,5 × 1,5 = 2,251,41,50,1
au centième1,411,420,01

Chaque tour ajoute une décimale exacte et ne s'arrête jamais : c'est la signature d'un irrationnel.

Comparer, encadrer, ranger

  • Pour comparer deux réels écrits différemment, ramène-les à une même forme, en général l'écriture décimale.
  • Pour encadrer une fraction par deux entiers consécutifs, effectue la division.
  • Pour encadrer une racine, cherche les deux carrés parfaits voisins du nombre écrit sous le radical.
  • Pour ranger une liste, place chaque nombre sur la droite graduée, puis écris la chaîne d'inégalités de gauche à droite.
PIEGES ET ERREURS FREQUENTES
✗ « Tout nombre s'écrit sous forme de fraction. »  ·  π = 3,14  ·  π = 227
✓ √2 et π sont des réels irrationnels : leur écriture décimale est illimitée et non périodique, aucune fraction ne les donne. 3,14 et 227 sont seulement des valeurs approchées de π.
✗ « Dès qu'il y a un signe √  , le nombre est irrationnel. »
✓ √9 = 3 et √16 = 4 sont des rationnels. Ce n'est pas le signe qui décide, c'est le nombre écrit dessous : carré parfait, la racine est un entier.
✗ √9 + 16 = √9 + √16 = 7  ·  (3 + 4)2 = 32 + 42 = 25
✓ Ni la racine ni le carré ne traversent une addition : √9 + 16 = √25 = 5 et (3 + 4)2 = 72 = 49. La racine ne traverse que le produit : √a × b = √a × √b.
✗ (−3)2 = −9  ·  (−2)4 = −16
✓ Exposant pair d'un nombre négatif : le résultat est positif, (−3)2 = 9 et (−2)4 = 16. Le résultat n'est négatif que si l'exposant est impair : (−3)3 = −27.
✗ a5 × a3 = a15  ·  (a5)3 = a8
✓ Dans un produit de puissances d'un même nombre, on ajoute les exposants : a5 × a3 = a8. C'est pour une puissance de puissance qu'on les multiplie : (a5)3 = a15.
✗ « 7 est compris entre 6 et 8, donc √7 est compris entre 6 et 8. »
✓ On encadre par les deux carrés parfaits voisins : 4 < 7 < 9, donc 2 < √7 < 3. Et pour comparer une fraction et un décimal, ramène-les d'abord à une même forme.
✗ De 2 ≤ x ≤ 5 on tire −2 ≤ −x ≤ −5
✓ Multiplier un encadrement par un nombre négatif retourne l'ordre : −5 ≤ −x ≤ −2. L'ordre n'est conservé que par l'addition et par la multiplication par un nombre positif.
A SAVOIR PAR COEUR AVANT LE DEVOIR
  1. Rationnel : fraction ab avec a, b entiers et b ≠ 0 ; écriture décimale finie ou périodique. Irrationnel : écriture décimale illimitée et non périodique, par exemple √2, √3, √5, π.
  2. ℝ réunit tous les rationnels et tous les irrationnels : ℕ ⊂ ℤ ⊂ 𝔻 ⊂ ℚ ⊂ ℝ, l'inclusion de ℚ dans ℝ étant stricte. Chaque réel est un point de la droite graduée, et chaque point un réel.
  3. Pour a positif, √a est le nombre positif dont le carré vaut a : √a × √a = a. Elle est rationnelle si a est un carré parfait, irrationnelle sinon.
  4. Dans ℝ : commutativité, associativité, distributivité ; 0 neutre pour l'addition, 1 neutre pour la multiplication, 0 absorbant pour la multiplication.
  5. Puissances : am × an = am+n, am ÷ an = am−n, (am)n = am×n, (a × b)n = an × bn, a0 = 1 pour a ≠ 0. Base négative : exposant pair, résultat positif ; impair, négatif.
  6. Pour a et b positifs, √a × b = √a × √b ; en revanche √a + b ≠ √a + √b, et (a + b)2 ≠ a2 + b2.
  7. Encadrer : a ≤ x ≤ b, amplitude = b − a ; par défaut la borne du bas, par excès celle du haut. Pour √a, on encadre a par deux carrés parfaits : n2 < a < (n + 1)2 donne n < √a < n + 1.
  8. L'ordre est conservé par l'addition et par la multiplication par un nombre positif ; il se retourne si l'on multiplie par un nombre négatif.
