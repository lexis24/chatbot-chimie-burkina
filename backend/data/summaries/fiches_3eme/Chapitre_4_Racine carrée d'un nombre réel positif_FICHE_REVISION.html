L'ESSENTIEL

Leçon 1 : Racine carrée et carrés parfaits

DEFINITION : pour a ≥ 0
√a est le nombre positif dont le carré vaut a
√a × √a = a     (√a)2 = a
  • √a n'existe que si a ≥ 0 : un nombre négatif n'a pas de racine carrée.
  • √0 = 0  ·  √1 = 1  ·  pour tout a ≥ 0 : √a2 = a.
  • Géométriquement, √a est le côté d'un carré d'aire a : chercher une racine, c'est chercher un côté connaissant une aire.
  • Un carré parfait est un nombre dont la racine carrée est un entier.
LES CARRES PARFAITS : A RECITER DANS LES DEUX SENS
1 • 4 • 9 • 16 • 25 • 36 • 49 • 64 • 81 • 100 • 121 • 144

Décimaux, grands nombres, encadrement

La même liste sert pour les décimaux, à condition de compter les chiffres après la virgule par paires ; pour les grands nombres, on compte les zéros par paires.

√0,49 = 0,7    √0,04 = 0,2    √1,44 = 1,2    √3 600 = 60

Si a n'est pas un carré parfait, on l'encadre entre les deux carrés parfaits voisins : on obtient √a entre deux entiers consécutifs. Ainsi 25 < 30 < 36 donne 5 < √30 < 6.

Leçon 2 : Calculs sur les radicaux

PRODUIT ET QUOTIENT : JAMAIS LA SOMME
√a × b = √a × √b  (a ≥ 0, b ≥ 0)
√ab = √a√b  (a ≥ 0, b > 0)

Simplifier un radical, c'est en extraire le plus grand facteur carré parfait : √18 = √9 × 2 = 3√2. Le nombre restant sous le radical ne doit plus avoir aucun facteur carré parfait.

SOMME DE RADICAUX SEMBLABLES
a√c + b√c = (a + b)√c

On n'additionne que des radicaux portant le même nombre sous le radical : c'est la règle de 3x + 5x, où √2 joue le rôle de la lettre.

Simplifie avant de conclure. √8 et √18 semblent étrangers, mais valent 2√2 et 3√2 : leur somme se réduit en 5√2.

Leçon 3 : Comparaison par les carrés

PROPRIETE : POUR a ET b POSITIFS SEULEMENT
a < b si et seulement si a2 < b2
a < b si et seulement si √a < √b
  • Pour comparer deux nombres positifs écrits avec des radicaux, on compare leurs carrés : les radicaux disparaissent.
  • La racine carrée conserve l'ordre des nombres positifs.
  • Cas d'un radical et d'un entier : le carré du radical est le nombre écrit dessous. Pour √30 et 5, on compare 30 et 52 = 25, d'où √30 > 5.
  • Propriété fausse pour des négatifs : −3 < 2, alors que (−3)2 = 9 > 4 = 22.

Leçon 4 : Racine carrée et valeur absolue

RACINE CARREE D'UN CARRE : POUR TOUT REEL a
√a2 = |a|
  • Si a ≥ 0 : √a2 = a. Si a < 0 : √a2 = −a, l'opposé de a, qui est positif.
  • Pour toute expression A : √A2 = |A|. Il faut étudier le signe de A pour supprimer les barres ; tant que ce signe est inconnu, on les garde.
  • Pour connaître ce signe, on encadre le radical : 1 < √3 < 2, donc 1 − √3 est négatif et |1 − √3| = √3 − 1.
Quand l'expression est négative, sa valeur absolue s'obtient en échangeant les deux termes de la soustraction.

Leçon 5 : Expression conjuguée ; rendre rationnel un dénominateur

Rendre rationnel un dénominateur, c'est écrire une fraction sans radical au dénominateur. Le numérateur, lui, peut en garder un.

CAS SIMPLE : UN SEUL RADICAL EN BAS (b > 0)
a√b = a√bb
EXPRESSION CONJUGUEE : ON CHANGE LE SIGNE DU MILIEU
(a + √b)(a − √b) = a2 − b
(√a + √b)(√a − √b) = a − b

Pour ca + √b, on multiplie le numérateur et le dénominateur par le conjugué a − √b, puis on développe le bas avec l'identité ci-dessus et l'on simplifie. Rien de nouveau : les fractions égales et (a + b)(a − b) = a2 − b2.

Leçon 6 : Résolution de l'équation x2 = a

Signe de aSolutions de x2 = a
a > 0deux solutions : x = √a ou x = −√a
a = 0une seule solution : x = 0
a < 0aucune solution : un carré n'est jamais négatif
  • On isole d'abord x2 : 3x2 = 27 donne x2 = 9, puis x = 3 ou x = −3.
  • Dans un problème de longueur, d'aire ou de masse, on ne garde que la solution positive, et on le dit explicitement.
  • Deux écritures voisines : √a désigne un nombre, toujours positif ; x2 = a pose une question, dont la réponse comporte deux nombres.
PIEGES ET ERREURS FREQUENTES
✗ √−9 = −3  ·  √49 = 7 ou −7
✓ Un nombre négatif n'a pas de racine carrée : √−9 n'a aucun sens, car aucune aire n'est négative. Et √a est toujours positif : √49 = 7, un seul nombre. « Les nombres dont le carré vaut 49 », 7 et −7, est une autre question (leçon 6).
✗ √a + b = √a + √b
✓ Faux : la règle vaut pour le produit et le quotient, jamais pour la somme. Contre-exemple : √9 + 16 = √25 = 5, alors que √9 + √16 = 3 + 4 = 7.
✗ 3√2 + 5√3 = 8√5  ·  « √8 + √18 ne se réduit pas »
✓ On n'additionne que des radicaux ayant le même nombre dessous, et l'on ajoute alors les coefficients : 3√2 + 5√3 reste tel quel. Mais simplifie d'abord : √8 + √18 = 2√2 + 3√2 = 5√2.
✗ √48 = 2√12, annoncé comme simplifié
✓ Simplification incomplète : 12 contient encore le carré 4. On extrait le plus grand carré parfait : √48 = √16 × 3 = 4√3. Contrôle : le nombre restant sous le radical n'a plus aucun facteur carré parfait.
✗ −5 < −2, donc (−5)2 < (−2)2
✓ La comparaison par les carrés ne vaut que pour des nombres positifs : ici 25 > 4, l'ordre s'est retourné. Vérifie le signe des deux nombres avant d'élever au carré.
✗ √(−5)2 = −5  ·  √A2 = A sans regarder le signe
✓ L'erreur la plus fréquente du chapitre. √a2 = |a| : le résultat est positif, donc √(−5)2 = √25 = 5. L'égalité √a2 = a n'est vraie que si a est positif.
✗ 21 + √3 = 2(1 − √3)1 + 3
✓ Deux fautes. On multiplie le haut et le bas par le conjugué, sinon la fraction change de valeur ; et le produit vaut a2 − b, ici 1 − 3 = −2, un nombre négatif dont il faut tenir compte : 21 + √3 = √3 − 1.
✗ x2 = 49 donc x = 7  ·  x2 = −4 donc x = −2
✓ Pour a > 0, l'équation a deux solutions, √a et −√a : x = 7 ou x = −7. Pour a < 0, il n'y a aucune solution. Si x est une longueur, seule la solution positive est retenue : dis-le, au lieu de faire disparaître l'autre.
A SAVOIR PAR COEUR AVANT LE DEVOIR
  1. √a est le nombre positif dont le carré vaut a ; il n'existe que pour a ≥ 0, et (√a)2 = a. Les carrés parfaits : 1, 4, 9, 16, 25, 36, 49, 64, 81, 100, 121, 144.
  2. Produit et quotient seulement : √a × b = √a × √b (a, b ≥ 0) et √ab = √a√b (a ≥ 0, b > 0). Jamais sur une somme.
  3. Simplifier : extraire le plus grand carré parfait, √18 = 3√2. Additionner : a√c + b√c = (a + b)√c, à radicaux identiques, après simplification.
  4. Pour a et b positifs : a < b si et seulement si a2 < b2 ; a < b si et seulement si √a < √b. Hors de ce cas, l'ordre peut se retourner.
  5. Encadrer : entre les deux carrés parfaits voisins. 25 < 30 < 36 donne 5 < √30 < 6.
  6. √a2 = |a| pour tout réel a : a si a ≥ 0, −a si a < 0. Etudier le signe de A avant de supprimer les barres de √A2 = |A|.
  7. Dénominateur rationnel : a√b = a√bb ; sinon, multiplier haut et bas par le conjugué, avec (a + √b)(a − √b) = a2 − b.
  8. x2 = a : deux solutions √a et −√a si a > 0 ; une seule, 0, si a = 0 ; aucune si a < 0. Longueur : on garde la positive.
