L'ESSENTIEL

Leçon 1 : Définition, ensemble de définition, image et antécédents

FONCTION RATIONNELLE : P et Q polynômes
f(x) = P(x)Q(x)
  • Une fonction rationnelle est le quotient de deux polynômes : P est le numérateur, Q le dénominateur.
  • Une valeur interdite est une valeur de x qui annule le dénominateur : pour elle le quotient n'existe pas, car on ne divise jamais par zéro.
  • L'ensemble de définition de f, noté D, est l'ensemble de tous les réels sauf les valeurs interdites.
ENSEMBLE DE DEFINITION
D = ℝ \ {valeurs interdites}
se lit « ℝ privé de… »

Trouver les valeurs interdites

Le numérateur n'interdit rien : on regarde le dénominateur seul et l'on résout Q(x) = 0.

Dénominateur Q(x)Ensemble de définition
x − 3  (premier degré)D = ℝ \ {3}
(x − 1)(x + 2)  (produit nul)D = ℝ \ {−2 ; 1}
x2 − 4 = (x − 2)(x + 2)D = ℝ \ {−2 ; 2}
x2 + 1  (toujours  > 0)D = ℝ

Un produit est nul dès que l'un de ses facteurs est nul : autant de facteurs, autant de valeurs interdites. Si le dénominateur n'est ni du premier degré ni déjà en produit, on le factorise d'abord. Un carré étant positif ou nul, x2 + 1 ne s'annule jamais.

Déterminer D. Dénominateur seul → factoriser → résoudre Q(x) = 0 → écrire D. Avant tout calcul d'image, vérifier que le nombre demandé appartient bien à D.

Image et antécédent

  • L'image de a par f est le nombre f(a) obtenu en remplaçant x par a, à condition que a ∈ D. Une image, quand elle existe, est unique.
  • Un antécédent de y par f est un nombre x de D tel que f(x) = y : on le cherche en résolvant une équation. Un antécédent peut manquer.

Calculer une image, c'est partir d'un nombre autorisé et arriver au résultat. Chercher un antécédent, c'est faire le trajet en sens inverse : on connaît l'arrivée, on cherche le départ.

QUOTIENT NUL : ANTECEDENT DE ZERO
P(x)Q(x) = 0 si et seulement si P(x) = 0 et Q(x) ≠ 0

Un quotient est nul si et seulement si son numérateur est nul, le dénominateur ne l'étant pas. Ainsi, par la fonction 4x − 1, le nombre 0 n'a aucun antécédent : un quotient de numérateur 4 n'est jamais nul.

Leçon 2 : Simplification d'une fonction rationnelle

  • Simplifier une fonction rationnelle, c'est factoriser le numérateur et le dénominateur, puis supprimer les facteurs communs.
  • On ne simplifie que des facteurs, c'est-à-dire des expressions multipliées entre elles. On ne simplifie jamais les termes d'une somme : x + 2x + 3 ne se simplifie pas.
  • La simplification n'est valable que sur D : on détermine donc D avant de simplifier, sur l'écriture de départ.
  • L'ensemble de définition ne change pas après simplification : les valeurs interdites du début restent exclues, même si le nouveau dénominateur ne les fait plus apparaître.
FACTEURS OPPOSES : pour x ≠ 5
x − 55 − x = −1  car  5 − x = −(x − 5)

Ce que l'on ne simplifie pas

Dans x + 2, le x est un terme d'une somme, non un facteur d'un produit. Le barrer revient à soustraire x en haut et en bas, ce qui change la valeur du quotient ; diviser en haut et en bas par un même nombre non nul, au contraire, ne la change pas.

Le contre-exemple qui tranche. Pour x = 1 : x + 2x + 3 = 34, alors que 23 en est loin. On ne barre jamais dans une somme : tant que le numérateur et le dénominateur ne sont pas écrits en produits, il n'y a rien à simplifier.

Les trois étapes, dans l'ordre

SIMPLIFIER UNE FONCTION RATIONNELLE
1. Ecrire D sur l'écriture de départ
2. Factoriser le numérateur, puis le dénominateur
3. Supprimer le facteur commun, en précisant « sur D »

Simplifier une fonction rationnelle, c'est simplifier une fraction de nombres, à une différence près : une lettre peut valoir zéro. D'où la mention « sur D », sans laquelle l'égalité serait fausse pour les valeurs interdites. Contrôle : avec une valeur autorisée, les deux écritures donnent le même nombre.

PIEGES ET ERREURS FREQUENTES
✗ Pour f(x) = 4x − 1, on écrit f(1) = 40 = 0  ·  « un numérateur nul est interdit lui aussi »
✓ 1 est une valeur interdite : f(1) n'existe pas, on ne divise jamais par zéro. Vérifie que le nombre appartient à D avant tout calcul d'image. Un numérateur nul, lui, est autorisé : il donne simplement une image nulle.
✗ « Toute fonction rationnelle a au moins une valeur interdite. »
✓ Faux : xx2 + 1 est définie sur ℝ tout entier. Un carré est positif ou nul, donc x2 + 1 > 0 : ce dénominateur ne s'annule jamais.
✗ Pour x − 1x2 − 4, on annonce D = ℝ \ {4}  ·  le dénominateur (x − 1)(x + 2) ne donne qu'une valeur interdite
✓ On factorise d'abord : x2 − 4 = (x − 2)(x + 2), donc D = ℝ \ {−2 ; 2}. Un produit s'annule dès que l'un de ses facteurs s'annule : (x − 1)(x + 2) donne donc deux valeurs interdites, 1 et −2.
✗ x + 2x + 3 = 23  ·  x2 + 9x + 3 = x + 3
✓ On ne barre que des facteurs, jamais les termes d'une somme. Pour x = 1, la première fraction vaut 34 et non 23. Et x2 + 9 n'est pas factorisable avec les identités du programme : ce quotient ne se simplifie pas.
✗ (x + 3)(x − 1)(x − 1)(x + 1) = x + 3x + 1, « donc f est définie en 1 »
✓ L'ensemble de définition se lit sur l'écriture de départ et ne change pas : 1 annulait le dénominateur initial, elle reste interdite. Ici D = ℝ \ {−1 ; 1}, et la forme simplifiée n'est valable que sur D.
✗ x − 55 − x = 1
✓ Les deux facteurs sont opposés, non égaux : 5 − x = −(x − 5), donc le quotient vaut −1. Contrôle pour x = 6 : 1−1 = −1.
✗ « Pour trouver l'antécédent de 0, on annule le dénominateur. »
✓ C'est le contraire : un quotient est nul si et seulement si son numérateur est nul, le dénominateur ne l'étant pas. On résout P(x) = 0, puis on vérifie que la solution appartient à D.
A SAVOIR PAR COEUR AVANT LE DEVOIR
  1. Une fonction rationnelle est un quotient de deux polynômes : f(x) = P(x)Q(x). Une valeur interdite annule le dénominateur ; on ne divise jamais par zéro.
  2. D = ℝ \ {valeurs interdites}. Pour l'obtenir : dénominateur seul, factorisé, puis Q(x) = 0. Le numérateur n'interdit rien.
  3. Produit nul : (x − 1)(x + 2) s'annule pour 1 et −2. Autant de facteurs, autant de valeurs interdites. Un dénominateur qui ne s'annule jamais, comme x2 + 1, donne D = ℝ.
  4. Image de a : le nombre f(a), calculé seulement si a ∈ D ; elle est unique. Antécédent de y : on résout f(x) = y dans D ; il peut ne pas exister.
  5. Un quotient est nul si et seulement si son numérateur est nul et son dénominateur non nul : c'est ainsi qu'on trouve l'antécédent de 0.
  6. Simplifier : factoriser en haut et en bas, puis supprimer les facteurs communs. On ne barre que des facteurs, jamais les termes d'une somme. Deux facteurs opposés donnent −1 : x − 55 − x = −1.
  7. D s'écrit avant de simplifier, sur l'écriture de départ, et ne change pas ensuite : les valeurs interdites restent exclues. Toute forme simplifiée se termine par « sur D ».
