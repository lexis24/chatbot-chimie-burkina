L'ESSENTIEL

Leçon 1 : Les intervalles de ℝ

Un intervalle est l'ensemble de tous les réels compris entre deux bornes a et b, avec a ≤ b. Un crochet tourné vers l'intérieur de l'intervalle inclut la borne ; un crochet tourné vers l'extérieur l'exclut.

NotationEnsemble des réels x tels que
[a ; b]a ≤ x ≤ b (bornes incluses)
]a ; b[a < x < b (bornes exclues)
[a ; b[a ≤ x < b (a inclus, b exclu)
]a ; b]a < x ≤ b (a exclu, b inclus)
[a ; +∞[x ≥ a (de a à l'infini)
]−∞ ; b]x ≤ b (de l'infini à b)
  • Le symbole ∞, qui se lit « infini », n'est pas un nombre : la borne infinie est toujours ouverte.
  • Ecrire un intervalle à partir d'une inégalité : repère les bornes, place la plus petite à gauche, puis mets un crochet fermé pour une borne incluse (≤ ou ≥), ouvert pour une borne exclue (< ou >) et pour l'infini.
  • Sur la droite graduée : place les deux bornes, colorie la portion comprise entre elles et dessine sur chaque borne le crochet dans le bon sens. Un intervalle non borné se prolonge par une flèche.

Intersection et réunion de deux intervalles

INTER ET UNION
E ∩ F : les réels qui appartiennent aux deux
E ∪ F : les réels qui appartiennent à au moins un
  • Méthode. Représente les deux intervalles sur une même droite graduée, un trait au-dessus, l'autre au-dessous. L'intersection est la zone couverte par les deux traits, la réunion celle couverte par au moins un.
  • Une borne appartient à l'intersection seulement si elle appartient aux deux intervalles.
Deux intervalles sans réel commun ont une intersection vide, notée ∅ : [5 ; 8] ∩ [0 ; 2] = ∅. Leur réunion n'est alors pas un intervalle : on garde l'écriture [0 ; 2] ∪ [5 ; 8].

Leçon 2 : Encadrement d'une somme et d'un produit

Encadrer un nombre, c'est l'enfermer entre deux valeurs : a ≤ x ≤ b.

SOMME : si a1 ≤ x ≤ a2 et b1 ≤ y ≤ b2
a1 + b1 ≤ x + y ≤ a2 + b2
PRODUIT : SEULEMENT POUR DES REELS POSITIFS
si 0 ≤ a1 ≤ x ≤ a2 et 0 ≤ b1 ≤ y ≤ b2
a1 × b1 ≤ x × y ≤ a2 × b2

On additionne les bornes de même côté ; pour des nombres positifs, on multiplie les bornes de même côté.

Agir sur un encadrement

POUR a ≤ x ≤ b
a + c ≤ x + c ≤ b + c  (ajouter c)
si k > 0 : ka ≤ kx ≤ kb  (ordre conservé)
si k < 0 : kb ≤ kx ≤ ka  (ordre retourné)
en particulier : −b ≤ −x ≤ −a

Encadrer une différence

Une différence se ramène à une somme, puisque x − y = x + (−y) : on retourne d'abord l'encadrement de y, puis on additionne.

DIFFERENCE
si b1 ≤ y ≤ b2, alors −b2 ≤ −y ≤ −b1
a1 − b2 ≤ x − y ≤ a2 − b1

A gauche, le plus petit x moins le plus grand y ; à droite, le plus grand x moins le plus petit y.

Méthode. Ecris les encadrements l'un sous l'autre, bornes alignées. Somme : additionne les bornes de gauche, puis celles de droite. Différence : retourne l'encadrement de la quantité retranchée, puis additionne. Produit de positifs : multiplie les bornes de même côté. Termine par une phrase de réponse avec l'unité.

Leçon 3 : Valeur absolue et distance de deux réels

La valeur absolue d'un réel x, notée |x|, est sa distance à zéro. Elle est toujours positive ou nulle.

DEFINITION EN DEUX CAS
si x ≥ 0 : |x| = x
si x < 0 : |x| = −x, son opposé, qui est positif
  • Deux nombres opposés ont la même valeur absolue : |−5| = |5| = 5.
  • Pour tous réels k et x : |kx| = |k| × |x|. Un facteur ne sort de la valeur absolue qu'en valeur absolue.
  • Ecrire une expression sans valeur absolue : étudie le signe du contenu des barres. S'il est positif ou nul, enlève simplement les barres ; s'il est négatif, enlève les barres et prends l'opposé de tout le contenu.

Distance de deux réels

DISTANCE DE DEUX POINTS D'UNE DROITE GRADUEE
AB = |xB − xA| = |xA − xB|

La distance ne dépend pas du sens de parcours : soustraire dans l'autre ordre donne l'opposé, et la valeur absolue rend le même résultat. De −40 à 80 : |80 − (−40)| = |120| = 120.

Valeur absolue et intervalle centré

POUR UN RAYON r > 0
|x − a| < r signifie x ∈ ]a − r ; a + r[

C'est l'intervalle centré en a, de rayon r : « x est à moins de 0,5 de 2 » s'écrit |x − 2| < 0,5 et donne ]1,5 ; 2,5[. C'est ainsi que s'exprime une tolérance de fabrication ou une marge d'erreur.

PIEGES ET ERREURS FREQUENTES
✗ [3 ; +∞]  ·  « [2 ; 5] et [2 ; 5[ contiennent les mêmes nombres. »
✓ Du côté de l'infini, le crochet est toujours ouvert : on écrit [3 ; +∞[, car ∞ n'est pas un nombre. Et le sens du crochet change l'ensemble : 5 appartient à [2 ; 5], mais pas à [2 ; 5[.
✗ [0 ; 4] ∩ [2 ; 7] = [0 ; 7]  ·  [5 ; 8] ∪ [0 ; 2] = [0 ; 8]
✓ L'intersection ne garde que les réels communs : [0 ; 4] ∩ [2 ; 7] = [2 ; 4] ; c'est la réunion qui vaut [0 ; 7]. Et 3 n'appartenant à aucun des deux intervalles, la réunion de [0 ; 2] et [5 ; 8] ne se recolle pas : elle s'écrit avec le symbole ∪.
✗ Si 3 ≤ x ≤ 5 et 2 ≤ y ≤ 4, alors 1 ≤ x − y ≤ 1.
✓ Ne soustrais jamais les bornes de même côté. On retourne d'abord l'encadrement de y : −4 ≤ −y ≤ −2, puis on additionne : −1 ≤ x − y ≤ 3.
✗ Si −3 ≤ x ≤ 5, alors −6 ≤ −2x ≤ 10.
✓ Multiplier par un nombre négatif retourne l'ordre : −10 ≤ −2x ≤ 6. Contrôle avec x = 5 : −2x = −10, qui est bien la borne de gauche.
✗ Si −3 ≤ x ≤ 2 et 1 ≤ y ≤ 4, alors −3 ≤ xy ≤ 8.
✓ La règle « bornes de gauche entre elles, bornes de droite entre elles » n'est valable que si toutes les bornes sont positives : elle exige 0 ≤ a1 et 0 ≤ b1. Ici x peut valoir −3 et y valoir 4, d'où xy = −12 : la conclusion est fausse.
✗ |x| = −3 donne x = 3  ·  « Pour x = −7, |x| = −x est négatif. »
✓ Une valeur absolue est une distance : elle n'est jamais négative, donc |x| = −3 n'a aucune solution. Le signe moins de −x inverse le signe, il ne rend pas négatif : |−7| = −(−7) = 7.
✗ La distance de a à b vaut a − b  ·  |a + b| = |a| + |b|
✓ La distance s'écrit toujours avec des barres, sinon elle peut sortir négative : AB = |a − b| = |b − a|. Et seul le produit traverse les barres, avec |kx| = |k| × |x| : |−3 + 5| = 2, alors que |−3| + |5| = 8.
A SAVOIR PAR COEUR AVANT LE DEVOIR
  1. Crochet fermé : borne incluse ; crochet ouvert : borne exclue. [a ; b], ]a ; b[, [a ; b[, ]a ; b]. Du côté de l'infini, le crochet est toujours ouvert.
  2. ∩ : les réels qui sont dans les deux ; ∪ : ceux qui sont dans au moins un. Sans réel commun, l'intersection est vide, notée ∅. Trace les deux intervalles sur une même droite graduée.
  3. Somme : a1 + b1 ≤ x + y ≤ a2 + b2. Produit, pour des réels positifs seulement : a1b1 ≤ xy ≤ a2b2.
  4. Différence : retourne l'encadrement de la quantité retranchée, puis additionne : a1 − b2 ≤ x − y ≤ a2 − b1.
  5. Ajouter un nombre ou multiplier par k > 0 conserve l'ordre ; multiplier par k < 0 le retourne : kb ≤ kx ≤ ka, et −b ≤ −x ≤ −a.
  6. |x| = x si x ≥ 0 ; |x| = −x si x < 0. Une valeur absolue est toujours positive ou nulle, et deux opposés ont la même : |−5| = |5| = 5.
  7. Distance de deux réels : AB = |xB − xA| = |xA − xB|. Et |kx| = |k| × |x|.
  8. Pour r > 0 : |x − a| < r décrit l'intervalle ]a − r ; a + r[, centré en a.
