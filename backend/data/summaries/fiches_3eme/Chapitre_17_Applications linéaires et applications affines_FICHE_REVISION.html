L'ESSENTIEL

Leçon 1 : L'application linéaire

Une application linéaire est une application de la forme f(x) = ax, où a est un nombre réel fixé appelé coefficient de l'application. Elle traduit une proportionnalité : f(x) est proportionnel à x, et a est le coefficient de proportionnalité.

APPLICATION LINEAIRE : DEFINITION ET COEFFICIENT
f(x) = ax   ·   f(0) = 0
a = f(x)x   pour x ≠ 0
  • La représentation graphique est une droite qui passe par l'origine du repère.
  • Le coefficient est l'image divisée par le nombre de départ, jamais l'inverse.
  • Deux applications linéaires de coefficients différents sont différentes : le coefficient détermine entièrement l'application.

Reconnaître. L'expression doit s'écrire ax, un nombre multiplié par x, sans aucun terme constant ajouté. On conclut sous la forme f(x) = ax en remplaçant a par sa valeur, puis l'on contrôle en recalculant l'image donnée.

Leçon 2 : Les propriétés de l'application linéaire

Soit f l'application linéaire définie par f(x) = ax. Pour tous nombres x et y et pour tout nombre k :

LES DEUX PROPRIETES : RESERVEES AU CAS LINEAIRE
f(x + y) = f(x) + f(y)
f(kx) = k × f(x)
  • L'image d'une somme est la somme des images ; si le nombre de départ est multiplié par k, l'image est multipliée par k.
  • On écrit donc le nombre cherché comme une somme ou un multiple de nombres dont l'image est connue : f(3) donne aussitôt f(6), f(9) et f(30), sans calculer le coefficient.
Signe du coefficientSens de variation
a > 0croissante : quand x augmente, f(x) augmente
a < 0décroissante : quand x augmente, f(x) diminue
a = 0constante : toutes les images valent 0
Croissante ne veut pas dire « grande » : une application peut être croissante alors que toutes ses images sont négatives. Croissante signifie seulement que les images montent quand on avance sur l'axe des abscisses.

Leçon 3 : L'application affine et son sens de variation

Une application affine est une application de la forme f(x) = ax + b, où a et b sont deux nombres réels fixés.

APPLICATION AFFINE : LE ROLE DES DEUX NOMBRES
f(x) = ax + b
a : coefficient directeur  ·  b : part fixe, avec b = f(0)
  • Le sens de variation ne dépend que du signe de a, exactement comme pour une application linéaire : croissante si a > 0, décroissante si a < 0, constante si a = 0, et toutes les images valent alors b.
  • Une application linéaire est un cas particulier d'application affine, celui où b = 0.
ORDRE DES IMAGES : pour x1 < x2
f croissante → f(x1) < f(x2) : ordre conservé
f décroissante → f(x1) > f(x2) : ordre inversé

Etudier une application affine. Mettre l'expression sous la forme ax + b en développant et en réduisant, identifier a et b, préciser la nature (affine, linéaire si b = 0, constante si a = 0), puis conclure d'après le signe de a. Pour ranger des images, ranger d'abord les nombres de départ, puis conserver ou inverser l'ordre.

Leçon 4 : La représentation graphique d'une application affine

La représentation graphique de f(x) = ax + b est une droite.

  • Elle coupe l'axe des ordonnées au point de coordonnées (0 ; b) : c'est pourquoi b s'appelle aussi l'ordonnée à l'origine.
  • a est la pente : quand x augmente de 1, f(x) augmente de a. Si a est négatif, « augmenter de a » signifie descendre.
  • Deux points suffisent pour tracer : le point (0 ; b) et un second obtenu avec une valeur de x qui simplifie le calcul.
  • Deux applications affines de même coefficient directeur ont des représentations parallèles.
RESOUDRE GRAPHIQUEMENT L'EQUATION f(x) = m
tracer l'horizontale d'ordonnée m → repérer le point d'intersection → lire son abscisse
Contrôle du tracé. A partir d'un point de la droite, avance de 1 unité vers la droite : tu dois monter de a, ou descendre d'autant si a est négatif. Une lecture graphique se vérifie ensuite par le calcul.

Leçon 5 : L'application affine par intervalles

Une application affine par intervalles est définie par une expression affine différente sur chacun de plusieurs intervalles qui se suivent.

  • Pour calculer une image, repérer d'abord l'intervalle auquel appartient le nombre de départ, puis utiliser son expression.
  • La représentation graphique est formée de morceaux de droites, un par intervalle : on ne trace chaque morceau que sur son intervalle, sans le prolonger.
  • Le sens de variation se donne morceau par morceau, d'après le signe du coefficient directeur de chacun. Une même application peut être croissante sur un intervalle et décroissante sur un autre.
VALEUR ABSOLUE : DEUX CAS, DONC DEUX INTERVALLES
|A| = A si A ≥ 0   ·   |A| = −A si A < 0

Toute expression contenant une valeur absolue se ramène ainsi à une application affine par intervalles. La valeur critique sépare les deux intervalles : on l'obtient en résolvant l'équation qui annule l'expression entre les barres.

Leçon 6 : Déterminer une application affine et résoudre des problèmes

Une application affine est entièrement déterminée par les images de deux nombres différents.

COEFFICIENT DIRECTEUR : pour x1 ≠ x2
a = f(x2) − f(x1)x2 − x1
  • C'est la différence des images divisée par la différence des nombres de départ, les deux prises dans le même ordre.
  • On obtient ensuite la part fixe b en remplaçant x et f(x) par l'un des deux couples connus dans f(x) = ax + b, puis l'on vérifie avec l'autre couple, celui qui n'a pas servi.
  • Une équation f(x) = m se résout par le calcul ou graphiquement.

Comparer deux tarifs

On trace les deux droites. Le point d'intersection donne la valeur pour laquelle les deux tarifs sont égaux ; de part et d'autre, c'est la droite la plus basse qui correspond au tarif le plus avantageux.

Le coefficient directeur est un prix par unité : des francs divisés par des kilos, jamais des kilos divisés par des francs.
PIEGES ET ERREURS FREQUENTES
✗ f(x) = 2x + 3 est une application linéaire
✓ Une application linéaire s'écrit ax, sans terme constant, et vérifie f(0) = 0. Ici l'image de 0 vaut 3 : l'application est affine. La présence d'un terme constant, même petit, change la nature de l'application, et sa droite ne passe plus par l'origine.
✗ f(x + y) = f(x) × f(y)
✓ L'image d'une somme est la somme des images, pas leur produit : f(x + y) = f(x) + f(y). Avec f(x) = 5x : f(2 + 3) = f(5) = 25, alors que f(2) × f(3) = 10 × 15 = 150.
✗ Pour g(x) = 2x + 3, on écrit g(1 + 2) = g(1) + g(2)
✓ Ces propriétés sont réservées aux applications linéaires. Ici g(3) = 9 tandis que g(1) + g(2) = 5 + 7 = 12 : la part fixe a été comptée deux fois.
✗ « f(x) = −3x + 10 est croissante parce que 10 est positif »
✓ C'est a, et lui seul, qui décide du sens de variation. Ici a = −3 est négatif, donc f est décroissante. La part fixe s'ajoute de la même façon à toutes les images : elle ne change pas l'ordre entre elles.
✗ Pour f(x) = 4x, la droite coupe l'axe des ordonnées au point d'ordonnée 4
✓ L'ordonnée à l'origine est l'image de zéro, pas le coefficient : b = f(0) = 0. La droite passe par l'origine, puisque la part fixe est nulle.
✗ Pour résoudre f(x) = 5, on part de 5 sur l'axe des abscisses
✓ On part de 5 sur l'axe des ordonnées et l'on cherche une abscisse. Partir de 5 sur l'axe des abscisses reviendrait à calculer f(5), qui est la question inverse.
✗ |2x − 3| = 2x − 3 pour tout x  ·  on calcule f(−1) avec « f(x) = x − 2 si x ≥ 3 »
✓ Pour x = 0, le membre de gauche vaut 3 et celui de droite −3 : une valeur absolue n'est jamais négative, alors que l'expression entre les barres peut l'être. Et l'on n'utilise que l'expression de l'intervalle qui contient le nombre de départ : −1 n'appartient pas à cet intervalle.
✗ a = f(x1) − f(x2)x2 − x1  ·  on conclut « f(x) = 150x » alors qu'il reste 500 FCFA de mise en route
✓ Les différences se prennent dans le même ordre en haut et en bas, sinon on obtient l'opposé du bon coefficient. Et une fois a trouvé, il reste à chercher la part fixe : ici f(x) = 150x + 500.
A SAVOIR PAR COEUR AVANT LE DEVOIR
  1. Linéaire : f(x) = ax, a le coefficient ; f(0) = 0 et la droite passe par l'origine. Connaissant une image, a = f(x)x pour x ≠ 0 : l'image divisée par le nombre de départ.
  2. Propriétés valables pour les seules applications linéaires : f(x + y) = f(x) + f(y) et f(kx) = k × f(x).
  3. Affine : f(x) = ax + b, a le coefficient directeur, b la part fixe avec b = f(0). Une linéaire est une affine avec b = 0.
  4. Sens de variation : le signe de a seul. a > 0 croissante, a < 0 décroissante, a = 0 constante. La part fixe b n'y joue aucun rôle.
  5. Si x1 < x2 : une application croissante conserve l'ordre, une décroissante l'inverse et donne f(x1) > f(x2).
  6. Graphique : une droite coupant l'axe des ordonnées en (0 ; b) ; a est la pente (avancer de 1, monter de a) ; deux points suffisent ; même coefficient directeur → droites parallèles. Pour f(x) = m, partir de m sur l'axe des ordonnées.
  7. Par intervalles : repérer l'intervalle du nombre de départ avant tout calcul, tracer un morceau de droite par intervalle et donner le sens de variation morceau par morceau. Valeur absolue : |A| = A si A ≥ 0, |A| = −A si A < 0.
  8. Deux images connues déterminent l'application : a = f(x2) − f(x1)x2 − x1 (même ordre en haut et en bas), puis b avec un couple et vérification avec l'autre. Deux tarifs : la droite la plus basse est la plus avantageuse.
